## فحص ملفات التسليم

- `python verify-trial.py`: تحقق مستقل من رؤوس WAV وPCM وعدد العينات والبصمات،
  وتطابق الصوت المضمن في HTML بايتًا ببايت مع الملفات الثلاثة، وعدم وجود نموذج
  أو سكريبت أو مصدر صوت خارجي في الصفحة. فك FFmpeg المحلي الملفات الثلاثة دون أخطاء.
- Chromium/Linux فعلي، دون اتصال: **54فحصًا عند360/768/1366**؛ تحميل مدد العينات
  الثلاث وتشغيلها وإيقافها مؤقتًا والانتقال داخلها ووصولها للنهاية، وعدم التشغيل
  التلقائي، وفتح النص واستجابة العرض. لا أخطاء أو طلبات HTTP/HTTPS.
- هذا يثبت قابلية تشغيل **الناتج المسلّم** هنا، ولا يثبت طبيعية النطق أو عمل
  محرك التوليد على Windows. لم تُغيّر هذه الفحوص ملفات Nova Voice.

**النتيجة حتى الآن:** النموذج اشتغل وأنتج صوتًا فعليًا. الحكم على طبيعية الصوت

## إعادة التوليد للمطور فقط

المستخدم لا يحتاج هذه الخطوات للاستماع. `generate-samples.mjs` يقرأ مصدر Nabra
المبني وملفي النموذج من مسارين صريحين، ويتحقق من بصماتهما، ولا ينزل شيئًا.

1. احصل على مصدر Nabra عند الالتزام المثبت أعلاه، لا نسخة أخرى من `main`، ثم نفّذ
   `npm ci --ignore-scripts --no-audit --no-fund` و`npm test` و`npm run typecheck`
   و`npm run build` في مجلد ذلك المصدر. التثبيت يتطلب إنترنت ولا يتطلب حساب استدلال.
2. احتفظ بملفي النموذج المطابقين للبصمات خارج Git. لا تُنزّل نموذجًا عشوائيًا أو
   تحمّل مكونات Python/PyTorch بديلة غير مراجعة.
3. شغّل، مع استبدال المسارات المحلية فقط:

   ```text
   node generate-samples.mjs UPSTREAM_BUILT_DIRECTORY MODELS_DIRECTORY OUTPUT_DIRECTORY
   ```

   عند حذف المسار الثالث سيكتب النواتج بجوار المولد؛ استخدم مجلدًا جديدًا للحفاظ
   على العينات السابقة. لا تعيد تشغيله على النواتج المنشورة دون قصد.
4. `build-listening-page.py`، Python3.11+ ومكتبته القياسية فقط، يعيد بناء HTML من
   WAV وmanifest الموجودين بجواره دون تنزيل. لا ترفع HTML وحده بعد تغيير WAV؛
   أعد بناء الصفحة والبصمات وراجع التطابق.
