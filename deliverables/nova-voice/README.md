هذه **معاينة مصدر تجريبية**، لا EXE أو إصدارًا مستقرًا. المثال **مؤلف يدويًا**:
نفس الوصف الحرفي والشرح السابقين،10خطوات و16سطرًا،4مراحل مرسومة وسؤالان بإجابتيهما
المنفصلتين وخلاصة. ليس نتيجة استدلال حي أو قالبًا يختاره التطبيق من كلمة المادة.
العينة المرئية صامتة عمدًا؛ لا صوت بشري أو تلاوة جديدة داخلها.

## ما نُفّذ الآن

1. **طباعة كاملة A4/PDF**: كل الأهداف والخطوات والشرح والأسئلة وإجاباتها،8لقطات
   تحفظ مراحل الرسم حتى العناصر المؤقتة، مع الملاحظات والوصف الأصلي. خيار رسوم
   رمادية وتأكيد مراجعة جديد؛ Ctrl+P دون مراجعة يطبع تنبيهًا فقط. لا طباعة للخطوة
   المفتوحة وحدها ولا إخفاء لكل الرسومات كما كان في CSS السابق.
2. **حركة تعليمية خفيفة**: تتبع تدريجي للأشكال، ظهور الرموز بالتتابع، وحقل `motion`
   محدود للحركة/الإبراز/الثبات، من بيانات الخطة الحرة لا قوالب مواد. نفس ساعة السطر
   والإيقاف والتقديم والسرعة، مع خيار تعطيل وتقليل الحركة. ليست محاكاة/3D/مزامنة شفاه.
3. **فيديو محلي فعلي**: درس كامل أو خطوة،1280×720 ونحو20fps حسب الجهاز،سرعة1×،
   بالصوت المضمّن إن وجد أو صامتًا دونه. Canvas/MediaRecorder، لا تسجيل شاشة/ميكروفون
   أو Web Speech/شبكة. WebM، وMP4 فقط إن دعمه المتصفح. يُفحص MIME وترويسة الحاوية
   قبل تسمية الملف؛ لا إعادة تسمية WebM إلى MP4.

MP4 في متصفح الاختبار احتوى VP9/Opus؛ **ليس ضمان H.264/AAC أو توافق كل هاتف**.
في الدليل أمر FFmpeg اختياري للتحويل الفعلي محليًا إن كان مثبتًا لديك؛ ليس مضمّنًا
أو اعتماد تشغيل أو تنزيلًا تلقائيًا. أثناء التصدير أبقِ الصفحة ظاهرة؛15دقيقة/128MiB
حدود معاينة، لا إثبات أداء4GB. الإلغاء/الخطأ/إخفاء الصفحة ينظف الموارد دون تنزيل جزئي.

نسخ العربية من PDF قد يقلب مكونات لام-ألف في بعض قارئات PDF رغم سلامة الطباعة؛
لنسخ حرفي استخدم HTML/السكريبت الأصلي. العينة فُحصت بصريًا وفُحص وجود نصها وهوامشها،
ومطابقة السطور الحرفية فُحصت منفصلًا في DOM. لا ندّعي نسخ PDF حرفيًا في كل قارئ.

## تشغيل المصدر

فك **RAR كاملًا** وافتح `NovaVoice-Source`، ولا تشغّل من نافذة الأرشيف. اتبع
`START-HERE.txt` و[RUN-FIRST-AR.html](RUN-FIRST-AR.html) للإعداد السابق المتوافق، ثم
`LESSON-OUTPUT-AR.md` للميزة الجديدة. إنشاء HTML صامت لا يحتاج نموذجًا صوتيًا.
النطق المحلي يحتاج نموذج Piper ومطابقة لغته وحقوقه؛ Python/الأوزان البشرية غير مضمّنة.

المسارات القديمة باقية: الراوي/الحوار،MP3/WAV،الخطوتان،الألوان والأطفال واللغتان،
الممحاة والتوقيت المقاس والحفظ بالتخصيصات. [مرحلة التأليف من الوصف](../../desktop/nova-voice/FULL-LESSON-AR.md)
و[مشاهد السكريبت الموجود](../../desktop/nova-voice/SMART-SCENES-AR.md) محفوظتان.
حزم **0.7.0.dev1 و0.6.0 و0.5.1 ودليل الإعداد المنشور لم تتغير**.

## التحقق والحدود

- المصدر والأرشيف المفكوك: **681 Python ناجحًا/تخطي وحدتي Qt**، و**189 DOM ناجحًا**.
  JSDOM يحاكي الوسائط/الترميز، وليس دليلًا على فك فيديو أو جودة صوت.
- **23 فحص Chromium153 جديدًا** مع إنشاء عينتي PDF/الفيديو الكاملتين، ومنها SVG
  و360/768/1366px،طباعة كل السطور واللقطات،Blob→Python→فتحoffline ومراجعة جديدة،
  فك WAV وتقديم عكسي،WebM وMP4 فعليان وفكهما/تقديمهما وتشغيلهما،إلغاء دون ملف جزئي،
  فيديو صامت وتقليل الحركة. إعادة فحص22حالة من النسخة النهائية بعد التغليف نجحت أيضًا.
- **36 فحصًا سابقًا للدرس الكامل** أُعيدت بعد التحديث: نجحت، بلا تغيير الأصوات أو النصوص.
- صفر أخطاء متصفح أو طلبات HTTP خارجية في تلك الجولات. نغمة440/660Hz تشخيصية تثبت
  احتفاظ ساعة السطور في الخرج الاختباري، **لا نطقًا عربيًا/بريطانيًا بشريًا**.
- فُك فيديو العينة كاملًا مستقلاً بـFFmpeg: WebM/VP9،1280×720،بلا مسار صوت. PDF6صفحات
  A4 وهوامش النص سليمة؛ فحص استخراج كلماته يسمح فقط باختلاف ترتيب مكونات لام-ألف.
- فحص التسليم: **63 مسارًا عامًا** ببايتاته وMIME،3طلباتHEAD،22حالةRange/416
  و1875حالة لمحلل المدى،5مسارات خاصة404. **23 فحص متصفح لصفحة التسليم**،بما فيها
  تحميل RAR الفعلي وبصمته وتشغيل الفيديو والتقديم عبرHTTP Range،بلا أخطاء/طلبات خارجية.
- Ruff وcompileall وJS syntax وسلامة التغليف. لا EXE/Actions أو تعديل ERP أو الترجمة
  المقفلة/Workflows. لا تشغيل Qt/Windows/4GB أو جودة صوت بشري مثبتة هنا.

الاقتراح الشبكي المجاني اختياري كما كان، بموافقة جديدة وحساب مُعدّ بالغ ومفتاح لا
يُحفظ،بلا مسار مدفوع أو تخفيف الخصوصية. **لم يُجرَ استدلال حي** أو حساب/فوترة/شراء.
لا اعتماد منهج/خرائط/علوم أو صحة آيات/تجويد. وضع النصوص المقدسة: طباعة نصية محلية
مراجَعة فقط،لا توسعة/رسوم/تلاوة آلية/API أو فيديو جديد في هذا الوضع.
