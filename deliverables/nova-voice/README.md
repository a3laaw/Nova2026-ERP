معاينة مصدر فقط،لا EXE أو إصدارًا إنتاجيًا. المثال **مؤلف يدويًا**،بنفس الوصف
والنطق السابقين:10خطوات و16سطرًا،شرح وأسئلة وإجابات منفصلة وخلاصة. ليس نتيجة
استدلال حي أو قالبًا يختاره التطبيق من المادة. العينة الكاملة صامتة؛اختبار AAC
بنغمة تشخيصية منفصلة،لا صوت عربي/بريطاني بشري أو تلاوة جديدة.

## ما تطور

- **حركة مسارات متعددة النقاط ودوران بمحور صريح** وتسهيل smoothstep،ببيانات JSON
  محدودة لا SVG/JavaScript حرًا أو روابط. نفس ساعة السطر/الإيقاف/التقديم العكسي
  والسرعة وتقليل الحركة. ليست محاكاة/3D/شخصيات فيديو أو مزامنة شفاه.
- **الورق يشرح الحركة أيضًا**:بداية ووسط ونهاية المسار/الدوران كرسوم مستقلة مكتملة،
  لا نهاية فقط؛20لقطة بينها6مجموعات ثلاثية،وكل16سطرًا والأسئلة والإجابات والملاحظات
  والوصف الأصلي. PDF10صفحات A4،مع خيار رمادي كما كان. اختيار المراجعة جديد غير محفوظ.
- **تحويل H.264/AAC فعلي** بعد تنزيل فيديو HTML:تبويب خامس «MP4 متوافق»،أو
  `tools/convert_video.py` دون Qt. اختر FFmpeg تنفيذيًا موثوقًا محليًا وراجع النطق
  والحقوق؛لا اكتشاف/تنزيل/تثبيت تلقائي أو شبكة أو تغيير امتداد. H.264 Main3.1،
  yuv420p،1280×720،20fps،faststart،وصوت AAC-LC إن وجد فقط. المصدر الصامت يبقى صامتًا.
- يقرأ البرنامج بيانات الترميزات محليًا ثم **يفك الخرج كاملًا قبل الحفظ**. حدود
 128MiB/15دقيقة،مؤقت بجانب الوجهة ونشر ذري بإذن استبدال صريح،ومنع المسارات الأصلية
  والمراجع الخارجية،وإلغاء ينهي العملية الفرعية وينظف الموارد دون ملف جزئي.
- **حارس انشغال الجهاز** في HTML:تأخر إطار أو انحراف ساعة الصوت أكثرمن350ms يوقف
  العمل بدل نشر خرج مشكوك في تزامنه،مع تفضيلVP8 عند دعمه. ليس ضمانًا لكشف كل
  انقطاع داخل المشفّر أو إصلاح تزامن تالف. أغلق البرامج الثقيلة وابدأ بخطوة قصيرة.

MP4 المباشر من المتصفح ما زال حسب دعمه وقد يكون VP9/Opus؛تبويب التحويل هو مسار
H.264/AAC المحدد. لا ضمان لكل هاتف/واتساب/برنامج؛بعض Chromium لا يفك H.264،لذلك
وفرنا WebM للعرض. FFmpeg اختياري خارجي تختاره وترخيصه بنفسك؛غير مضمّن أو اعتماد تشغيل.
الواجهة الجديدة لم تُشغّل على Qt/Windows هنا؛الأداة والمحرك اختُبرا فعليًا على Linux.

## التحقق والحدود

- **770 Python ناجحًا مع FFmpeg التطويري المختار صراحة/تخطي3وحدات Qt**،و**237 DOM**.
  اختبارات الواجهة الأصلية مكتوبة لكن لم تنفذ بسبب مكتبات المضيف. DOM يحاكي الوسائط
  ولا يثبت الترميز أو الصوت.40متجه حركة مشتركة:6مقبولة و34مرفوضة.
- تحويل وفك فعليان للصامت/نغمة،وإلغاء عملية FFmpeg فعلية مع إعادة جنيها وحماية الملف
  السابق،ورفض مدة متجاوزة دون تسليم قص صامت. اختبارات حدود/سجلات/أسماء/روابط وسباق
  إنشاء وجهة قبل الحفظ،وMIME/حاوية/بصمات ومراجعة جديدة.
- **14 فحص Linux Chromium153 جديدًا** مع العينة الكاملة:360/768/1366px،دوران وإيقاف،
  طباعة16سطرًا/20لقطة،PDF،Blob→Python→فتحoffline ومراجعة جديدة،فك WAV وتقديم عكسي،
  WebM فعلي→CLI H.264/AAC وفك كامل ومحاذاة440/660Hz بالساعة المشفرة،تقليل الحركة،
  وتعطل خيط فعلي600ms يوقف التنزيل دون جزئي. لا دليل جودة صوت بشري أو هاتف/Windows.
- إعادة **22 فحص مخرجات و36 فحص درس كامل** سابقة نجحت. ضغط متوازٍ سابق فشل في
  مواعيد النغمة؛وُثق وأُضيف الحارس وأعيدت الجولة تسلسليًا. لا إخفاء للفشل أو عدّه نجاحًا.
- صفر أخطاء صفحة/console أو طلباتHTTP خارجية في الجولات الناجحة. Ruff/compileall/
  JS syntax/diff والتغليف. لا تعديل ERP أو ترجمة مقفلة/Workflows أو EXE/Actions.
- PDF الجديد10صفحات A4،كل كلمات الشرح والهوامش فُحصت،والسطور حرفيًا في DOM،ومراجعة
  مرئية لصفحات مختارة. بعض قارئات PDF تقلب مكونات لام-ألف عند النسخ رغم سلامة الشكل؛
  فحص وجود الكلمات يسمح فقط بهذا الاختلاف الموثق،والنسخ الحرفي من HTML/السكريبت.
- MP4 الجديد **72.6s،H.264 Main3.1/yuv420p،1280×720،20fps،بدون صوت**،فُك كاملًا
  مستقلاً وفُحصت إطارات مختارة. نغمة AAC في QA منفصلة ليست عينة نطق أو تلاوة.

لم يُجرَ استدلال حي أو حساب/فوترة/شراء. المسار الاختياري المجاني يبقى بموافقة
وحساب مُعدّ بالغ ومفتاح غير محفوظ،بلا مدفوع/fallback أو تخفيف خصوصية. لا صحة منهج/
خرائط/علوم/قرآن/تجويد معتمدة،ولا رفع صورة/OCR. وضع النصوص المقدسة طباعة نصية مراجعة
فقط،لا رسوم/توسعة/API/صوت آلي/فيديو جديد،ويعطل التحويل من تبويب التطبيق أيضًا.

## تشغيل المصدر والتسليم

فك RAR كاملًا وافتح `NovaVoice-Source`،ثم اتبع `START-HERE.txt` و
[RUN-FIRST-AR.html](RUN-FIRST-AR.html) للإعداد السابق المتوافق،و`VIDEO-MOTION-AR.md`
للجديد. HTML الصامت والطباعة لا يحتاجان نموذجًا. الصوت يحتاج Piper ومطابقة لغته
وحقوقه؛Python والأوزان البشرية وFFmpeg غير مضمّنة. الراوي/الحوار واللغتان والألوان
والأطفال والخطوتان والممحاة والصوت/HTML السابقة باقية.

حزمة0.9مستقلة؛**RAR0.8وعينتاPDF/WebM والأرشيفات0.7و0.6و0.5.1 ودليل الإعداد المنشور
لم تتغير بايتًا**. المخرجات الجديدة منفصلة عن المصدر وليست أوزانًا أو تطبيقًا جاهزًا.
تفاصيل RAR وبصمته بعد الفحص في القسم التالي؛البصمات اتساق لا توقيع أصالة أو اعتماد.
