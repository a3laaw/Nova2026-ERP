## ما تغيّر فعليًا

- `group` بأجزاء ومحاور محلية متداخلة و`sequence` بمفاتيح وتكرار محدود عبر الجمل؛
  انتقال الجسم لا يستبدل تحريك أطرافه. ساعة المصدر وحدها، بلا مؤقتات تراكمية.
- `curve` بيزيه، `sector` قطاع/حلقة، و`gradient` محلي. `sphere` بشبكة وتظليل وبقع
  توضيحية يدور سطحها وتُحجب جهتها الخلفية؛ **2.5D لا محرك3D عام/GIS أو خرائط معتمدة**.
- مراجعة مسماة لكل جزء وحركته وامتداده، مع حفظ النص والأدوار والبصمة والوقوف/الرجوع
  وتقليل الحركة. الورق يقرأ الأجزاء المتداخلة وتوقيت الجمل المقاس، حتى8 لقطات ممثلة
  لكل جملة لا كل إطار، والفيديو يستخدم المشغّل نفسه والتدرجات والإسقاط.
- حدود عودية للأجزاء والمفاتيح والكرات؛ المنع السابق للأكواد/الروابط/الصور الخام
  والإرسال دون إذن والبديل المدفوع وحماية النصوص المقدسة محفوظ. لا مكتبة أو أوزان
  أو تنزيل خفي جديد؛ السماح بإنترنت مجاني لا يعني ضمان خدمة مجانية غير محدودة.
