# Nova Voice 0.4 — التسليم الحالي

## ابدأ من هنا

1. حمّل **[NovaVoice-Source-v0.4.0.rar](NovaVoice-Source-v0.4.0.rar)**.
2. فك الحزمة كاملة وافتح مجلد `NovaVoice-Source`.
3. افتح **[RUN-FIRST-AR.html](RUN-FIRST-AR.html)** لشرح التجهيز والتشغيل.

الحزمة **مصدر وملفات تشغيل على Windows**، وليست EXE جاهزًا، ولا تتضمن Python
أو النماذج الصوتية البشرية. إنشاء السبورة لا يحتاج نموذجًا صوتيًا، أما الصوت
فيحتاج تثبيت النماذج المناسبة مرة واحدة.

## ترتيب الملفات

| الملف | وظيفته |
| --- | --- |
| `NovaVoice-Source-v0.4.0.rar` | حزمة المصدر الحالية؛ هذا هو الملف المطلوب تنزيله |
| `RUN-FIRST-AR.html` | نسخة من شرح التشغيل، يمكن قراءتها قبل فك الحزمة |
| `index.html` | واجهة واحدة للتحميل والشرح ومعاينة السبورة |
| `SHA256SUMS.txt` | بصمة RAR للتحقق من سلامة التنزيل |

## المصدر والنسخ القديمة

- [كود التطبيق](../../desktop/nova-voice/README.md)
- [مثال السبورة بلا صوت](../../desktop/nova-voice/examples/greetings-whiteboard.html)
- [أرشيف الإصدارات السابقة](../archive/README.md)

لا توضع ملفات RAR/ZIP أو النسخ المؤقتة في مجلد كود التطبيق بعد الآن.
من مجلد المصدر يمكن إعادة إنتاج الحزمة الحالية بالأمر:

```sh
python tools/package_source.py
```

يختار الأمر مجلد التسليم الصحيح داخل المستودع، أو `deliverables/` داخل نسخة
المصدر المستقلة بعد فكّها. لا يحتاج إنشاء RAR تثبيت WinRAR؛ يستخدم صيغة STORE
الحقيقية. اختبارات الكود لا تعني أن واجهة Windows أو الصوت البشري قد اختُبرا هنا.
