# Nova Voice 0.7.0.dev1 — معاينة مصدر لدرس كامل مرسوم

## ابدأ من هنا

1. حمّل **[NovaVoice-Source-v0.7.0.dev1.rar](NovaVoice-Source-v0.7.0.dev1.rar)**.
2. فك الحزمة كاملة وافتح مجلد `NovaVoice-Source`؛ لا تشغّل من نافذة RAR.
3. اتبع `START-HERE.txt` وشرح الإعداد [RUN-FIRST-AR.html](RUN-FIRST-AR.html).
   شرح الإعداد السابق متوافق؛ الميزة الجديدة وخطوات مراجعتها في
   [FULL-LESSON-AR.md](../../desktop/nova-voice/FULL-LESSON-AR.md).

هذه **معاينة مصدر تجريبية** لـWindows 10/11 x64، وليست EXE أو إصدارًا مستقرًا.
لا تتضمن Python أو أصواتًا بشرية أو حساب خدمة. لا تشغيل Qt/Windows/4GB مثبتًا هنا.
الحزمتان القديمتان 0.6.0 و0.5.1 محفوظتان دون أي تغيير؛ لا تنزّل القديمة لتجربة
مرحلة الوصف الجديدة. رقم التطبيق الحالي `0.7.0.dev1` لتمييز المصدر عن الحزمة القديمة.

## الوصف لم يعد يُعامل على أنه سطر الدرس الوحيد

في **النص والأصوات** افتح **من وصف قصير إلى درس كامل مرسوم**. الوصف والمادة والصف
بالنص الحر، لا قائمة قوالب دروس. يقترح الطلب أهدافًا ومراحل شرح مرسومة وأسئلة
وإجابات منفصلة وخلاصة. الوصف محفوظ حرفيًا خارج النطق، ولا يُستبدل سكريبتك القديم
أو صوتك تلقائيًا عند وصول الرد.

**مسودة ← مراجعة ومعاينة صامتة ← تأكيد نقلها للمحرر لراوٍ واحد ← اعتماد خطة الرسوم
← التصدير المعتاد.** يمكن تعديل رد JSON الخام ثم إعادة مراجعته؛ البصمات تُبنى
محليًا، والحزمة المحفوظة ترفض التغيير غير المتسق. لا تجاوز بعد تغير المسودة
بإلغاء الرسوم أو بزر الصوت فقط؛ فصل الارتباط تأكيد مستقل وواضح.

- [جرب المثال الكامل بلا حساب أو صوت](../../desktop/nova-voice/examples/complete-lesson-demo.html).
- [حزمة JSON المحلية](../../desktop/nova-voice/examples/complete-lesson-demo.json).
- [السكريبت الموسع](../../desktop/nova-voice/examples/complete-lesson-demo-script.txt).
- [دليل المسار والخصوصية وحدود الاختبارات](../../desktop/nova-voice/FULL-LESSON-AR.md).

المثال **مؤلف يدويًا أثناء التطوير، لا نتيجة AI حيّة**: 10 خطوات و16 سطرًا، أهداف،
4 مراحل مرسومة/50 عنصرًا، سؤالان بإجابتين منفصلتين، وخلاصة. HTML مستقل بعد التصدير،
بلا شبكة أو مفتاح/خادم أثناء العرض. الاحتفاظ بحزمة JSON يفيد في تعديل بنية التأليف لاحقًا.

## الإنترنت اختياري، مجاني فقط، ولم يُختبر حيًا

يمكن الاستيراد أو نسخ التوجيه أو تجربة المثال دون مفتاح API. الطلب المدمج اختياري
بحساب مُعدّ بالغ 18+ مؤهل وموافقة جديدة لكل طلب. يُرسل الوصف والمادة والصف فقط،
لا السكريبت القديم أو صوتًا أو صورًا. المفتاح داخل البرنامج فقط، لا في المحادثة
أو السكريبت، ولا يُحفظ أو يُصدّر. لا بيانات طلاب أو معلومات حساسة.

العميل يستخدم `openrouter/free` بسقف سعر صفر ومرشحات منع جمع البيانات وZDR، بلا
بديل مدفوع أو retry/repair أو redirects أو تخفيف للخصوصية. قد لا يوجد مزود يوافقها،
ولا ضمان للحصص/التوفر أو أهلية حساب غير ممول. لا شراء أرصدة أو استعلام فوترة.
**لم يُجرَ طلب استدلال حقيقي هنا؛ اختبارات النقل تستخدم ردودًا محاكاة.**

لا توثيق علمي/منهجي أو خرائط/GIS أو صحة تلقائية لكل المواد والمراحل. النصوص المقدسة
في وضع الحماية محلية فقط: لا توسعة من وصف حتى باستيراد يدوي، ولا API أو تلاوة Piper،
ولا كشف ديني تلقائي أو اعتماد آيات/تجويد. هذا لا ينجز مطلب القرآن الواسع بعد.

## ما بقي كما كان

- السكريبت العادي: الراوي أو الحوار والصوتان، MP3/WAV، الألوان والشخصيات وترتيب اللغتين.
- زر السبورة الموحّد ومسار الخطوتين؛ إضافة صوت لسبورة محفوظة تأتي من نصها وخطتها لا محرر آخر.
- توقيت السطور من عينات PCM، وداخل السطر تقريب، وتأخير MP3 السابق غير معوّض تخمينيًا.
- ممحاة 560ms والتقديم/الترجيع/السرعة وتقليل الحركة والحفظ بالتخصيصات.
- الأصوات المحلية المختارة؛ لا صوت مصري أو علاج مثبت لح في كريم أو إثبات UK/RP مسموع.
- خطط الرسم القديمة schema 1 ودروس schema 1/2. الخطة الممتدة schema 2 تضيف origin
  للاتساق فقط؛ ليست البصمة شهادة مصدر أو إثبات موافقة/صحة.

## التحقق والحدود

- 649 اختبار Python ناجحًا، وتخطي وحدتي Qt بسبب مكتبات GL النظامية الناقصة.
- 164 اختبار DOM ناجحًا، منها 20 حالة للدرس الكامل؛ JSDOM يحاكي الإعلام والقياسات.
- 36 فحصًا في Chromium 153 على 360/768/1366px، بما فيها SVG حقيقي وتنزيل Blob
  أثناء المسح وإعادة استيراده وفتحه offline، وفك WAV فعلي وتقديمه/ترجيعه وحفظ توقيته.
- صفر أخطاء متصفح أو طلبات HTTP خارجية. الصوت التجريبي **صمت من ONNX صغير**؛
  لا جودة صوت بشري أو فهم نموذج حي أو Windows/4GB مثبتة.
- Ruff وcompileall وJS syntax وفحوص سلامة الحزمة، دون EXE/Actions أو تعديل ERP أو
  الترجمة المقفلة/Workflows. تفاصيل النتائج في FULL-LESSON-AR.md.

يلزم قبل الاستخدام اليومي اختبار واجهة Windows ومراجعة درس حي إذا أردت خدمة الاقتراح،
والاستماع إلى صوتك الحقيقي وفحص ملاءمة المنهج؛ لا تجعل المثال المحلي بديلًا عنها.

## سلامة الحزمة الحالية

RAR حقيقي STORE: **138 ملفًا، 1,777,359 بايت**. فُحصت الترويسات وCRC
مستقلًا، وتطابقت كل ملفات المصدر بايتًا ببايت مع تطبيع BAT إلى CRLF. فُكّت الحزمة
وأُعيدت اختبارات Python/DOM منها؛ نفس النتائج (649/تخطي وحدتي Qt و164 DOM).
لا EXE أو بيئة أو أوزان بشرية أو صوت مولّد فيها، والنموذج الوحيد عينة اختبار 1602 بايت.
