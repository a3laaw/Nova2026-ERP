# Nova Voice 0.5.0 — التسليم الحالي

## ابدأ من هنا

1. حمّل **[NovaVoice-Source-v0.5.0.rar](NovaVoice-Source-v0.5.0.rar)**.
2. فك الحزمة كاملة وافتح مجلد `NovaVoice-Source`.
3. افتح **[RUN-FIRST-AR.html](RUN-FIRST-AR.html)** لشرح التجهيز والتشغيل.

الحزمة **مصدر وملفات تشغيل على Windows**، وليست EXE جاهزًا، ولا تتضمن Python
أو النماذج الصوتية البشرية. إنشاء السبورة لا يحتاج نموذجًا صوتيًا، أما الصوت
فيحتاج تثبيت النماذج المناسبة مرة واحدة.

## تنظيم الواجهات وبحث الصوت المصري

التحميل والتجهيز والمعاينة والبحث مفصولة بوضوح في `index.html`. في البرنامج توجد
تبويبات للنص والأصوات، والألوان والأطفال، والسبورات المحفوظة، والتصديرات الأخرى؛
زر التوليد والإلغاء ثابتان والنتيجة تفتح بعد النجاح. تشغيل HTML يسبق الأطفال، مع
أقسام قابلة للطي دون تغيير خريطة الصوت أو النص أو مكتبة الشخصيات.

[بحث الصوت المصري](../../desktop/nova-voice/EGYPTIAN-VOICES-AR.md): مرشحون فقط، لا
صوت مصري جاهز مثبت أو ضمان 4GB. لم يُبدّل المحرك أو تُضف خدمة إنترنت.
[تقرير التنظيم والتحقق](../../desktop/nova-voice/UI-ORGANIZATION-AR.md).

## جديد: النص والصوت بضغطة واحدة

في قسم السبورة يوجد الآن زر **توليد السبورة بالنص والصوت معًا**. اكتب السكريبت،
واختر الأصوات ولغاتها وMP3/WAV والتخصيصات، ثم اضغطه واختر اسم HTML مرة واحدة.
يحفظ السبورة والنص والصوت والتوقيت في الملف النهائي نفسه، دون طلب حفظ ملف وسيط.
مصدره النص الحالي في المحرر، مع خلفية وتقدم وإلغاء آمن وحماية الأصل. الزران 1 و2
باقيان للمراجعة أو استكمال سبورة محفوظة. الحزمة التالية تشمل هذا الزر بالفعل.

## تحديث 0.5.0 — التوقيت الفعلي للسطور

الحزمة الحالية تتضمن خريطة حدود كل سطر من عينات الصوت الفعلية، بعد توحيد التردد
ومع الفواصل. يبقى **ملف/مرمّز متدفق واحد لكل خطوة**، لا ملفات لكل سطر ثم دمجها.
القلم يتبع موضع الصوت عند الإيقاف والتقديم والترجيع و0.5×–2×. الكتابة **داخل السطر
تقريبية**؛ إذا غابت الخريطة أو فسدت يعمل التقدير السابق دون أخطاء. WAV أدق: قيس
تأخير MP3 بمقدار 1105 عينة مع مرمّز/مفكك الاختبار، ولا يطبّق تعويض متصفح تخميني.

[الدليل والاختبار اليدوي](../../desktop/nova-voice/WHITEBOARD-GUIDE.md) ·
[تقرير التحقق والملفات المتغيرة](../../desktop/nova-voice/TIMING-VERIFICATION-AR.md) ·
[سجل التغييرات](../../desktop/nova-voice/CHANGELOG.md).
لا نموذج صوتي جديد أو اعتماد تشغيل إضافي. بقي الإصدار **0.5.0**.

## محفوظ في 0.5.0 — الألوان والشخصيات

ألوان لكل دور ولكل مقطع معروض، ومكتبة 3 أولاد و3 بنات تعمل محليًا دون تنزيلات
إضافية. التخصيص من البرنامج أو من HTML، مع حفظ نسخة بالتخصيصات وإيقاف الحركة.
[دليل الأطفال والألوان](../../desktop/nova-voice/KIDS-GUIDE-AR.md) ·
[تجربة الشخصيات بلا صوت](../../desktop/nova-voice/examples/greetings-kids.html).
مع التحديث أيضًا: منع توجيه العربية لصوت إنجليزي والعكس، تقليل الوقفات بين سطور
الدور نفسه، وترتيب English فوق العربي أو في عمودين. هذا لا يثبت جودة النموذج
العربي أو طبيعية الصوت؛ لا نموذجًا بشريًا جديدًا أو اختبار استماع في الحزمة.

## إصلاح وسوم الحوار

الحزمة الحالية تتضمن إصلاح تبديل الأصوات داخل السطر، ودعم الإغلاق الاختياري
`[1] نص عربي [/1][2] English [/2]` دون عرض الوسوم أو نطقها.
البدء بـ`[/1]` أو إغلاق الدور الخطأ يوقف التوليد برسالة واضحة، ولا تُخمن الأصوات.
مثال جاهز داخل المصدر: `examples/greetings-inline-dialogue.txt`.
للسبورات القديمة التي تعرض الوسوم، أعد الخطوة 1 من النص المصحّح ثم الخطوة 2.

```sh
python tools/package_source.py
```

يختار الأمر مجلد التسليم الصحيح داخل المستودع، أو `deliverables/` داخل نسخة
المصدر المستقلة بعد فكّها. لا يحتاج إنشاء RAR تثبيت WinRAR؛ يستخدم صيغة STORE
الحقيقية. اختبارات الكود لا تعني أن واجهة Windows أو الصوت البشري قد اختُبرا هنا.
