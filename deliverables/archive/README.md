# أرشيف التسليمات السابقة

الملفات هنا نُقلت من مجلد المصدر أو من موقع التنزيل المؤقت السابق، ولم تُحذف.
هذه نسخ تاريخية وليست التسليم الحالي:

- `nova-voice/`: إصدارات ZIP السابقة وملف RAR الذي سُلّم قبل ترتيب مساحة العمل.
- `development-helpers/`: سكريبتات التعديل المؤقتة القديمة؛ ليست ملفات تشغيل للمستخدم.
- `temporary-download-site/`: نسخة موقع التحميل المؤقت السابقة خارج المستودع.

الأرشيفات التاريخية محفوظة محليًا ومستثناة من Git لتجنب خلط المخرجات القديمة
مع الكود والتسليم الحالي. لا تعتمد عليها بعد نقل المشروع إلى جهاز جديد.

**[الحزمة الحالية موجودة هنا](../nova-voice/NovaVoice-Source-v0.5.0.rar)**، وهي غير
مستثناة من Git ومرفقة بمساحة العمل. **[شرح التشغيل الحالي](../nova-voice/RUN-FIRST-AR.html)**.
