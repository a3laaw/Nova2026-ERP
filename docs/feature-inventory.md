
# خريطة ميزات نظام NovaFlow ERP السيادية 🇸🇦

## 1. إدارة المنصة (Platform Management - المطور)
- **بوابة التأسيس (Provisioning)**: تحويل طلبات الانضمام إلى منشآت حقيقية بضغطة زر.
- **إدارة التراخيص (Licensing)**: التحكم في حالة الشركة (Active/Suspended) وتواريخ انتهاء الاشتراك.
- **إدارة الهوية العالمية**: توحيد الهوية الرقمية لكافة المستخدمين عبر `global_users`.
- **سكربت هجرة الهوية**: أداة لصيانة وتصحيح أكواد الصلاحيات التالفة.

## 2. موديول الموارد البشرية والامتثال (HR Core)
- **سجل الموظفين الموحد**: دعم الموظفين الداخليين والعمالة الخارجية (الميدانية).
- **محرك الإجازات المطور**: فحص التداخل (Overlap) وتوزيع الأيام حسب قانون العمل.
- **توليد الرواتب الذكي**: دمج البصمة (XLSX) مع الرواتب والخصومات التلقائية.
- **حاسبة نهاية الخدمة**: تطبيق كامل لمواد قانون العمل الكويتي (41, 44, 51, 53).

## 3. العمليات الهندسية والميدانية (Engineering & Field)
- **رادار المواعيد المعماري**: جدولة لقاءات العملاء.
- **رادار العمليات الميدانية**: إدارة أطقم العمل والمعدات في المواقع.
- **محرك المقايسات (BOQ)**: إدارة جداول الكميات والأسعار المرجعية.
- **الأوامر التغييرية (VO)**: حقن بنود ومراحل جديدة في المشاريع الجارية.

## 4. المشتريات والمخازن (Procurement & Inventory)
- **سجل الموردين المعتمدين**: تقييم وتصنيف الموردين.
- **أوامر الشراء الذكية (PO)**: ربط المشتريات ببند المقايسة والمرحلة التنفيذية.
- **إدارة العهد الميدانية**: تتبع تسليم واستلام المعدات للموظفين.
