
# سجل تطوير مشروع NovaFlow ERP 🚀

## [2.3.0] - خريطة العلاقات السيادية (Relationship Atlas)
- **`docs/relationships.md`**: توثيق شامل لـ 76 مجموعة، 132 مفتاحاً أجنبياً، 27 علاقة دلالية، و10 خطوط أنابيب تشغيلية←مالية مع مخططات Mermaid.
- **`docs/relations.json`**: سجل مرجعي آلي (كيانات، aliases، فجوات G1–G9) أصبح مصدر المعنى الوحيد القابل للتحقق.
- **`scripts/check-relations.js`**: رقيب يمنع انحراف التوثيق عن الكود (٦ فحوصات) + توليد `docs/relations.generated.json`.
- **`GEMINI.md`**: قاعدة سادسة إلزامية تُلزم أي مطوّر/وكيل بتحديث السجل عند إضافة مجموعة أو حقل `xxxId`.
- **توثيق 9 فجوات بنيوية** أهمها: `purchase_orders_items` الوهمية (G1)، وكون `projects` مجرد عرض على `transactions` (G2).

## [2.2.0] - نظام التأسيس والترخيص السيادي (Sovereign Provisioning)
### ✅ التحديثات البرمجية
- **محرك التأسيس الآلي**: نقل منطق إنشاء الشركات والحسابات إلى لوحة تحكم المطور حصراً.
- **بوابة صالة الانتظار**: تحويل صفحة التسجيل إلى نظام "طلب انضمام" لحماية موارد Firebase Auth.
- **إدارة التراخيص الذكية**: تنفيذ نظام تجميد الحسابات (Suspend) وتمديد الاشتراكات (Trial, Monthly, Annual).
- **التوحيد القسري للهوية**: فرض حالة الأحرف الكبيرة في `roleCode` لضمان مطابقة القواعد الأمنية.
- **إصلاح نموذج التوظيف**: تمكين حفظ العمالة الخارجية دون قيود الحقول الإلزامية للموظفين الداخليين.
