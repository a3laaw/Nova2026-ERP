# Azure Speech اختياري — Nova Voice 0.15.0.dev1

**إضافة مصدر تجريبية، لا عينة Azure حيّة أو ضمان جودة/مجانية.** يبقى Piper/كريم
المحلي هو الافتراضي عند كل تشغيل، وملفاته واختياراته القديمة مستقلة. لا استبدال
لكريم، ولا دمج لمحرك Nabra؛ تجربة Nabra المنشورة منفصلة كما كانت.

## أين أضع المفتاح؟

بعد فك الحزمة وتجهيز المتطلبات وتشغيل `Run-Windows.bat`:

1. افتح **«النص والأصوات» ← «2 · اختر الأصوات»**.
2. من **محرك الصوت** اختر **«Azure Speech · سحابي بإذن لكل عملية»**. لا يُرسل
   شيء عند الاختيار أو إدخال المفتاح أو تغيير الصوت/السرعة.
3. أدخل **مفتاح مورد Azure Speech** في حقل كلمة المرور محليًا على جهازك. لا مفتاح
   حساب Azure العام أو OpenRouter. **لا ترسله في المحادثة أو GitHub أو السكريبت**.
4. أدخل **Region** كما يظهر في صفحة **Keys and Endpoint** للمورد، مثل `eastus`
   أو `westeurope` أو `uaenorth`، لا رابط Endpoint أو عنوان بريد. يلزم تطابق المنطقة
   مع مورد المفتاح. يدعم العميل نطاق خدمة Azure العام المعتاد فقط؛ لا endpoint مخصص.
5. افتح موردك في Azure وتحقق من **Pricing tier = Free F0**، ثم فعّل
   **«أؤكد أن مورد Speech هو Free F0»**. تغيير المفتاح أو المنطقة يمسح هذا التأكيد.
6. اختر الراوي، أو **حوار بين صوتين** ثم اختر كل دور على حدة. لا يلزم تنزيل ONNX
   لاستخدام Azure، لكن متطلبات التطبيق الأساسية تظل كما هي ولا يحذف نماذجك المحلية.

هذه الإضافة لا تنشئ حسابًا/موردًا أو اشتراكًا، ولا تقبل بطاقة أو شروط دفع نيابة عنك.
إن لم يكن لديك مورد Free F0 مؤهل، استمر بالصوت المحلي؛ لا حاجة للترقية من داخل التطبيق.

## مهم: المفتاح لا يثبت المجانية

صفحة Microsoft للتسعير تعرض **500,000 حرف Neural TTS شهريًا لفئة Speech Free F0**.
هذه ليست لكل حساب أو مورد S0 أو صوت HD/مخصص، وليست رصيدًا يقيسه هذا البرنامج.
حساب Azure التجريبي/رصيده لمدة30يومًا يختلف عن فئة مورد Speech؛ راجع شروط حسابك
وأهليته ومنطقته الحالية بنفسك. لا ننشئ حسابًا أو ننتقل إلى Pay-as-you-go.

**لا يمكن إثبات SKU أو رصيد الشهر باستخدام مفتاح Speech في هذا العميل.** مربع F0
إقرار منك، لا تحقق من Azure أو ضمان فاتورة صفر. إذا أدخلت مفتاح S0 وأكدت F0 بالخطأ،
**قد تحتسب Microsoft رسومًا**. البرنامج لا يغيّر فئة المورد أو يقبل ترقية، لكنه لا
يستطيع إبطال إعداد فوترة موجود في حسابك. لا تفعل الإرسال قبل التحقق من صفحة المورد.

العدد في نافذة المراجعة هو طول النص المقسّم في Python، **تقديري وليس عدّ Azure
للفوترة أو رصيد الحصة**. يشمل كل تكرار نطق في العملية؛ المعاينة طلب مستقل وقد تستهلك
الحصة أيضًا. البرنامج لا يرى الاستهلاك من أجهزة أو برامج أو جلسات أخرى.

عند0.85أو1.00حسب تفضيلك، ثم قارن من نفس النص وبسرعة ثابتة؛ لم نولّد هذه العينات هنا.

## ماذا يحدث قبل أي إرسال؟

1. راجع نص الدرس والمصطلحات والحقائق والإجابات والفرق بين **العرض والنطق**. مسودة
   الدرس الكامل والرسوم تحتاج مراجعتها واعتمادها كالمعتاد؛ اختيار Azure لا يعتمدها.
2. اضغط صراحةً أحد مسارات الصوت: **معاينة أول400حرف، توليد وحفظ الصوت، توليد
   السبورة بالنص والصوت معًا، الخطوة2للسبورة المحفوظة، أو إضافة الصوت إلى HTML**.
   الحفظ الصامت والخطوة1والاستيراد و«استدلال» والمعاينة المرئية لا ترسل إلى Azure.
3. بعد اختيار وجهة الحفظ إن كان المسار يحتاجها، تظهر نافذة **«مراجعة النص قبل إرساله إلى Azure»**:
   المنطقة، عدد المقاطع والحروف التقديري، و**المقاطع المنطوقة الفعلية مع الصوت
   والسرعة لكل مقطع**. لا تعرِض مجرد النص الخام قبل معالجة الفراغات والتقسيم.
4. اقرأها، ثم فعّل المربع غير المحدد مسبقًا **«راجعت النص وأوافق على إرساله لهذه
   العملية فقط»** واضغط **«أوافق وأبدأ هذه العملية»**. الافتراضي **«رجوع بلا إرسال»**.
   تغيير النص/الصوت/المفتاح/المنطقة/السرعة/السياسة أو المصدر أثناء المراجعة يلغي الإذن.
5. لا تُرسل إلا المقاطع الموافق عليها، بترتيبها وصوتها وسرعتها، عبر HTTPS إلى
   `{region}.tts.speech.microsoft.com/cognitiveservices/v1`. تُهرب XML وتُقسّم
   المقاطع حتى480حرفًا دون تبديل الصوت أو ترجمة النص. لا طلب لاكتشاف أصوات أو رصيد.

كل عملية جديدة، **حتى إعادة المعاينة نفسها**، تحتاج موافقة جديدة. لا اعتماد/نطق/
تصدير تلقائي بمجرد وصول مسودة أو استعادة سجل أو اختيار صوت. حماية النصوص المقدسة
تمنع Azure كما تمنع النطق المحلي؛ الحماية اختيار يدوي وليست كاشفًا آليًا أو شهادة تجويد.

### السبورة المحفوظة ليست المحرر الحالي

الخطوة2تقرأ **النطق الفعلي المحفوظ في ملف HTML الذي اخترته**، بما فيه اختلاف النطق
عن النص الظاهر في الخطة، لا النص الموجود حاليًا في المحرر ولا عناوين `#`/`##` أو وصف
الرسم أو أصل الوصف. يظهر هذا النطق في نافذة الإذن. تظل مراجعة الدرس المحفوظ المستقلة
قائمة؛ ملف HTML لا يحفظ اعتمادًا بشريًا. يتم فحص خطة الإرسال كاملةً قبل أول طلب،
ثم كل مقطع قبل إرساله. تغيير خطوة متأخرة لا يبرر إرسالها دون مراجعة.

في مسار **HTML خارجي**، تُرسل المقاطع الصوتية من السكريبت المراجع فقط، **لا محتوى
HTML**. إذا كتبت عنوانًا أو وصفًا داخل مقطع منطوق بنفسك، سيُرسل كجزء منه؛ ليس هناك
كشف دلالي يمنع كل معلومة شخصية. لا تضع بيانات طلاب حساسة في النص.

## المفتاح والخصوصية والإلغاء

- المفتاح محجوب، في ذاكرة النافذة للجلسة حتى **30دقيقة من آخر إدخاله**؛ استخدامه
  لا يجدد المدة. لا يُحفظ هو أو المنطقة أو اختيار Azure أو الموافقة في الإعدادات
  أو HTML أو سجل النسخ أو السجلات. الإعدادات القديمة تظل مسارات النماذج المحلية.
- زر **«نسيان مفتاح Azure الآن»** يمسح الحقل والإقرار. الرجوع للمحرك المحلي والإغلاق
  المعتاد وانتهاء المؤقت يمسحون المفتاح أيضًا. أثناء مهمة يعمل زر **الإلغاء** المشترك
  خارج التبويبات؛ إعدادات الصوت مقفلة حتى تنتهي المهمة.
- إسقاط المراجع ومسح الحقل **ليس محوًا آمنًا مضمونًا لكل بايت في الذاكرة**، ولا مسحًا
  لحافظة نظام التشغيل إذا لصقت منها المفتاح. التطبيق لا يقرأ الحافظة أو يملؤها بالمفتاح.
- الإلغاء/النسيان يمنع الطلبات اللاحقة؛ **قد يكتمل طلب أُرسل بالفعل ويستهلك الحصة**.
  قد يلزم انتظار مهلة اتصال/قراءة15ثانية؛ يوجد حد قراءة زمني يُفحص بين قراءات الشبكة.
- تقول وثيقة Microsoft إن **التوليد الفوري real-time** لا يخزن نص الإدخال أو الصوت
  الناتج. هذه ليست شهادة ZDR لكل Azure أو تعهدًا بعدم وجود بيانات تشغيل/فوترة، ولا
  تعميمًا على Batch/Long Audio أو Custom Voice. راجع سياسات حسابك وشروط الاستخدام.
- لا SDK أو telemetry جديدًا في العميل، ولا وكيل بيئة تلقائي أو إعادة توجيه أو إعادة
  محاولة أو مزود/صوت بديل. الأخطاء لا تعرض المفتاح أو جسم رد الخدمة ولا تسجلهما.

## الحصة والأخطاء والملفات

حد محلي محافظ **20محاولة/60ثانية داخل عملية البرنامج**؛ ليس حصة حساب ولا مزامنة
بين الأجهزة. قد ينتظر السكريبت الطويل، وقد يعيد Azure429رغم ذلك. الحد الأقصى للخطة
100,000حرف و1000مقطع؛ وقت جلسة المفتاح30دقيقة قد ينتهي قبل درس طويل جدًا. لا تقسيم
دروس طويل جديدًا أو توليد خلفي/استئناف تلقائيًا في هذه الإضافة.

- **401/403:** راجع المفتاح والمنطقة والمورد وفئة F0. لا شراء أو تخمين مفتاح/منطقة.
- **429/نفاد الحصة:** تتوقف العملية بلا إعادة/ترقية تلقائية. تحقق من لوحة موردك قبل
  الموافقة على عملية جديدة؛ لا يوجد استئناف خفي أو إعادة استخدام لموافقة قديمة.
- **مهلة/شبكة/رد غير صالح:** لا صوت آخر خفي أو تخفيف للخصوصية. السحابة تحتاج إنترنت؛
  للمحلي ارجع صراحةً إلى Piper/كريم واختره وابدأ عملية محلية جديدة.
- صوت Microsoft المطلوب **raw PCM16 mono/24kHz**. يتحقق العميل من نوع الاستجابة
  والحجم والمحاذاة وعدم فراغ الصوت؛ PCM الخام بلا توقيع يثبت معدله أو جودة الكلام.
  الفحوص البنيوية ليست اختبار نطق أو دقة عيّنة فعلية من الخدمة.
- الترميز المحلي نفسه يحفظ WAV أو MP3/192kbps، وخريطة السطور مبنية على عدد عينات
  PCM الفعلي لا أزمنة تخمينية. لا نموذج ONNX مزيفًا أو وسيطًا لكل سطر.
- الصوت الناتج يُحفظ محليًا بناءً على طلبك؛ مقاطع مؤقتة لتضمين HTML تُحذف عادةً عند
  الإكمال/الخطأ، وليست محوًا آمنًا. النتيجة النهائية لا تستبدل ملفًا سابقًا إلا بعد
  نجاح العملية والحفظ الذري؛ فشل خطوة لاحقة لا ينشر HTML جزئيًا.
- HTML الناتج يضم الصوت محليًا ولا يتصل بـAzure عند العرض، ولا يحتوي المفتاح أو
  endpoint أو موافقة. ملفات HTML الخارجية تظل محتفظة بأي موارد/سكربتات كانت فيها.

## ما اختُبر، وما يلزم على جهازك

اختبارات آلية **دون شبكة** بمفاتيح وهمية وHTTPS/PCM محقونين: XML/النص/الصوت/السرعة
والإذن، انتهاء المفتاح والإلغاء والانتظار، منع التوجيه والوكيل، أخطاء المصادقة/الحصة
والمهل، أحجام/أنواع الرد، عدم تسريب الخطأ، ترميز WAV/MP3 فعلي وفك MP3، السطور والتوقيت
والسبورة المحفوظة والتصدير الموحد وHTML. اختبارات Piper القديمة أعيدت أيضًا.

اختبارات الواجهة الأصلية مضافة، لكن **تُخطّى هنا إذا لم تتوافر مكتبات Qt النظامية
مثل libGL.so.1**؛ compile أو اختبارات المتصفح لا تثبت تشغيل Qt. لا مفتاح حقيقي أو
طلب Azure أو استماع Salma/Shakir/Sonia/Ryan أو Windows/4GB أو أهلية مورد/فاتورة مثبتة.

على جهازك: تحقق من F0والمنطقة، أدخل المفتاح محليًا، جرّب جملة غير حساسة، راجع نافذة
الإرسال ووافق، ثم استمع. جرّب إلغاء نافذة الإذن وإعادة العملية بإذن جديد، واحفظ
WAV قصيرًا وسبورة قصيرة وافتحها بعد فصل الإنترنت. **لا ترسل المفتاح للتشخيص**؛ يكفي
اسم الصوت والمنطقة ورسالة الخطأ العامة أو وصف النطق الذي يحتاج مقارنة.
