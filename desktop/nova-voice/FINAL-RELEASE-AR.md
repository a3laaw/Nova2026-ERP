# Nova Voice 0.6.0 التجريبية — مشاهد من السكريبت قابلة للمراجعة

**تقرير المصدر · 7 نوفمبر 2026**

## النطاق الفعلي، لا وعد بفهم كل المنهج

حزمة **مصدر وملفات تشغيل Windows**، وليست EXE جاهزًا. لا تشغيل GitHub Actions
أو تغيير ERP/Firebase/الترجمة أو تنزيل أوزان. الرسم والنطق وتصدير HTML محلية؛
أضيف **اقتراح شبكي اختياري** محدود المجانية، لا خدمة نطق سحابية أو نموذج AI محليًا.
لا اعتماد تشغيل Python جديد: العميل الشبكي يستخدم المكتبة القياسية.

المرحلة الأولى: سكريبت ← مسودة خطة وصفية ← تحقق بنيوي ← مراجعة المعلم ومعاينة
صامتة واعتماد صريح ← رسوم محلية ونطق محلي ← HTML ذاتي الاكتفاء offline.
لا قائمة قوالب دروس يختارها المعلم، لكن المحرك ليس رسامًا أو مرجعًا علميًا بلا حدود.
المادة والصف تلميحان اختياريان؛ ليس كل صف حتى الإعدادي أو كل مادة مختبرًا ومعتمدًا.

## ما أضيف

- خطة JSON مرتبطة ببصمة النص والوضع والصفوف وأدوار الصوت الأصلية. تستبقي السكريبت
  الحرفي؛ يمكن اقتراح عرض أقصر ونطق مستقل محدود، مثل رقم على اللوح وجملة عند القراءة.
- رسوم declarative: أشكال وخطوط وأسهم ومضلعات ومسارات ونصوص، وعشرة رموز محلية،
  وعمليات حسابية أربع محسوبة بكسور دقيقة، ومثلث قائم بأضلاع مرسومة بنسبة أبعاده.
  لا SVG/HTML خام أو كود مولّد أو تحميل صور/موارد من المقترح. حدود للبايتات والعناصر
  والأعداد والنصوص، ورفض مفاتيح مجهولة وJSON ملتبس/غير محدود ونطق فارغ/وسوم أدوار.
- استيراد/حفظ JSON محلي ذري، أو نسخ توجيه إلى الحافظة لخدمة يختارها المعلم، أو
  طلب واحد عبر `openrouter/free` بموافقة جديدة. أي تعديل للمصدر أو الخطة يلغي الاعتماد.
  CLI يعرض المراجعة ولا يكتب ملفًا دون `--approve-scenes` الصريح.
- العناصر تتبع ساعة عينات السطور الفعلية عند وجود الصوت؛ التقديم والترجيع/التوقف
  والسرعة لا تراكم مؤقتات. **صوت الدرس المرئي يرفض خريطة توقيت غير سليمة**، ولا يعود
  إلى توقيت تخميني. وقت المعاينة الصامتة وحدها تقديري من طول النطق المعتمد.
- الممحاة القديمة تمسح الرسم والكتابة معًا، حتى إذا ظهر الرسم قبل أول حرف. الحفظ
  أثناء المسح ينظف الحالة المؤقتة. تقليل الحركة مدعوم، بلا تشغيل صوت عند فتح HTML.
- مثال تفاحات ومثلث قائم ومنظر طبيعي. **مكتوب يدويًا لاختبار المحرك، لا مخرجات AI حيّة.**

## الشبكة والمجانية والخصوصية

الطلب الاختياري إلى عنوان ثابت ونموذج free-only، بحدود سعر صفر. لا مسار مدفوع،
لا إعادة محاولة أو إعادة توجيه أو تخفيف خصوصية تلقائيًا، ولا طلب شراء/أرصدة أو اكتشاف
نماذج. يطلب منع جمع البيانات وZDR، وقد لا يوجد مزود مجاني يلبي هذه القيود فيتوقف.
تُرفض استجابة غير مكتملة أو ذات تكلفة معلنة غير صفرية أو خطة لا ترتبط بالمصدر.

يتطلب حساب مُعدّ بالغ مؤهلًا، ومفتاحًا داخل التطبيق فقط، وموافقة لكل طلب بعد التنبيه
إلى إرسال السكريبت. لا بيانات طلاب أو بيانات حساسة. المفتاح لا يدخل التوجيه أو
الإعدادات أو التصدير؛ حقل كلمة المرور يُمسح بعد بدء الطلب وعند الإغلاق. أخطاء الشبكة
مُعقمة، والموافقة ليست إعدادًا محفوظًا. سياسة المزود/الاحتفاظ/المنطقة منفصلة وليست
ضمانًا قانونيًا أو ضمان عدم احتفاظ مطلقًا. شروط الحسابات والحصص والتوفر قد تتغير أو
تتطلب تمويلًا؛ لا شراء تلقائي ولا وعد بمجانية غير محدودة أو أهلية حساب بلا رصيد.

**لم يُجرَ أي طلب استدلال حقيقي أو إنشاء حساب أو استخدام مفتاح حقيقي هنا.**
اختبارات الشبكة بردود محاكاة تثبت تصرف العميل، لا قبول المزود للطلب أو جودته أو
توفر الخدمة في الكويت/مصر. الاستيراد والخطة المحلية يعملان دون API أو حساب.

## القرآن والجغرافيا

- اختيار حماية النصوص المقدسة محلي: لا إرسال أو رسوم أو إعادة صياغة أو نطق آلي
  في واجهة التطبيق، حتى «صوت فقط». الوصف يبقى عنوان المصدر. لا يقبل درس محمي
  تسجيلًا محقونًا. يعرض نص المعلم كما هو، **لا يوثّق الآيات أو التجويد ولا يوفّر
  تلاوة بشرية/آلية معتمدة**. ليست هذه تغطية كاملة لمطلب القرآن.
- الطبيعة/الخرائط رسوم توضيحية؛ لا GIS أو مصدر حدود موثق أو إسقاط خرائطي. المثلث
  والحساب محسوبان، لكن ذلك لا يثبت بقية المحتوى العلمي أو توافقه مع المنهج.
- البصمات تحقق اتساق المحتوى والتوقيت، وليست توقيع جهة أو إثبات حقيقة أو شهادة مراجعة.

## ما بقي محفوظًا

المسار العادي بلا خطة يحتفظ بـschema 1 وبصماته؛ schema 2 يربط المصدر والخطة
والنطق والتوقيت. الأدوار والوسوم والتحقق من لغة **النطق الفعلي**، الألوان والشخصيات
وترتيب اللغتين، زر التوليد الموحد والخطوتان المنفصلتان، مصدر الخطوة 2 من النص
والخطة داخل HTML المحفوظ، والإلغاء وحدود الإدخال باقية. الصوت فقط لا يستخدم اقتراح
النطق المرئي؛ الاستثناء هو اختيار الحماية الذي يمنع التوليد الآلي في الواجهة.
لم تتغير إعدادات أصوات المستخدم أو محرك Piper/الترميز أو فونيماته.

## التحقق المسجل للنسخة الحالية

- **578 اختبار Python ناجحًا** في التطبيق وخادم التسليم وتخطيط صفحة التنزيل؛
  **تخطي وحدة Qt واحدة** لغياب `libGL.so.1`. اختبارات الواجهة الأصلية، بما فيها
  الحالات الجديدة، لم تُنفذ. فحص ترجمة ملفاتها لا يثبت تخطيطها أو عملها على Windows.
- **139 اختبار DOM ناجحًا**، بينها 38 حالة للمشاهد والتحقق والتوقيت/الرجوع والحفظ
  والحماية. تستخدم DOM ووسائط قياس محاكاة؛ ليست اختبارات تخطيط أو فك صوت حقيقي.
- **12 حالة Chromium 153 فعلية على Linux**: الخطوات الثلاث على عروض **360 و768
  و1366px** دون تجاوز عرض أو تداخل بين مساحة الرسم وأول سطر؛ اختبار تشغيل/توقف
  وقراءة WAV صامت حقيقي مدته 12.7 ثانية، وتقديم/ترجيع وسرعة ومسح الرسم قبل النص؛
  تنزيل Blob أثناء المسح والتحقق بـPython وإعادة فتحه offline مع حفظ النطق واللون؛
  ومعرض الأنواع والرموز على الهاتف. **صفر أخطاء JavaScript أو طلبات HTTP خارجية**
  في هذه الحالات. راجعت لقطات الأمثلة؛ ليست دليل تعميم على مخرجات نموذج عشوائي.
- Ruff وفحص ترجمة Python وفحص صياغة JavaScript ناجحة. المثالان القديمان أُعيدا
  بالقالب الجديد مع بقاء بيانات الدرس والمظهر الأصليين. النماذج/الخدمات الحقيقية
  لم تدخل هذه الاختبارات.
- RAR STORE حقيقي، **117 ملفًا**؛ البصمة في `SHA256SUMS.txt` بجانب التنزيل.
  لا بيئة أو node_modules أو أدوات Chromium/لقطات/ملفات صوت مرفقة. نموذج الاختبار
  الاصطناعي القديم بحجم **1602 بايت** محفوظ؛ ليس صوتًا بشريًا صالحًا للتدريس.
  حزمة 0.5.1 السابقة بقيت بايتاتها كما هي.

ملف WAV في فحص المتصفح **صمت اصطناعي**، لا استماع أو تحقق نطق. اختبارات الخدمات
المحاكاة ليست طلبات حقيقية، واختبارات Chromium ليست اختبار التطبيق الأصلي أو Windows.

### حدود الصوت والأداء غير المحلولة

**لم يُثبت إصلاح ح في كريم**، ولا تُضاف كتابة لاتينية أو قاموس فونيمات لعلاجها.

لا اختبار استماع بالأوزان الحقيقية أو تشغيل Windows/ذاكرة 4GB. يجب اختبار Setup/Run
ودرس قصير بالأصوات المختارة على الجهاز المستهدف قبل التدريس، ومراجعة كل اقتراح
ورسم ونطق. لا تُقدَّم هذه القيود على أنها ميزات منجزة.
