# ألوان الجمل ومكتبة شخصيات الأطفال — Nova Voice 0.5.1

تخصيص محلي للسبورة التي يولّدها Nova Voice، وليس لصفحات HTML الخارجية عشوائيًا.
لا يحتاج الإنترنت أو خدمة صور أو نموذج ذكاء اصطناعي إضافيًا.

## المكتبة

| الأولاد | البنات |
| --- | --- |
| آدم | ليلى |
| عمر | نور |
| يوسف | سلمى |

ست شخصيات SVG أصلية مضمنة في المشروع، وليست شخصيات أفلام أو صورًا من الإنترنت.
يمكن إسناد شخصية لكل دور، أو اختيار **بدون شخصية**. في وضع الراوي الواحد تظهر
شخصية الدور الأول فقط. اختيار الشخصية لا يحدد جنس الصوت أو لغته، ولا يستنسخ صوتًا.

## من برنامج Windows، قبل إنشاء السبورة

1. جهّز السكريبت واختر الراوي الواحد أو الحوار كالمعتاد.
2. افتح تبويب **ألوان وشخصيات**؛ التوليد يظل متاحًا أسفل التبويبات.
3. اختر لون الدور 1 ولون الدور 2، والشخصية لكل دور. الحركة اختيارية.
4. للون مختلف لجملة بعينها افتح **تخصيص متقدم · لون جملة بعينها**، ثم اضغط
   **تحديث قائمة الجمل** واختر المقطع ولونه.
   يمكن إعادته إلى لون دوره بواسطة **لون الدور الافتراضي**.
5. اختر الأصوات واضغط **توليد السبورة بالنص والصوت معًا** لحفظ HTML واحد مباشرة
   بالمظهر والصوت. أو استخدم **1. توليد السبورة HTML** لإنشاء نسخة صامتة للمراجعة.
6. إذا اخترت النسخة الصامتة، افتحها وراجعها ثم أضف الصوت بالخطوة 2؛ يبقى المظهر.

المقاطع في قائمة الألوان هي الصفوف الناتجة بعد تقسيم الدرس للعرض؛ الجملة الطويلة
قد تمتد إلى أكثر من صف. لون الدور يطبق عليها كلها ما لم تختَر لونًا خاصًا لصف.
تغيير السكريبت أو وضع الراوي/الحوار يمسح تخصيصات الصفوف القديمة حتى لا تنتقل إلى
نص آخر، لكنه يحتفظ باختيارات الشخصيات والألوان العامة. حدّث القائمة مجددًا.
اختيارات المظهر محفوظة لكل ملف HTML، وليست حفظًا تلقائيًا لنص المحرر في الإعدادات.

## التخصيص داخل ملف السبورة نفسه

1. افتح HTML في متصفح حديث، ثم افتح **ألوان الجمل ومكتبة شخصيات الأطفال**.
2. غيّر ألوان الدورين، أو اختر جملة من **الخطوة الحالية** وحدّد لونها.
3. حدد الدور الذي تريد تغيير شخصيته، ثم تصفح **كل الشخصيات / الأولاد / البنات**.
4. اضغط صورة الشخصية لاختيارها. اختيار **بدون شخصية** يخفيها.
5. اضغط **تنزيل نسخة بالتخصيصات** للاحتفاظ بالاختيارات. التعديلات مؤقتة دون ذلك.
6. افتح النسخة المنزلة للتحقق. إذا كانت بلا صوت، اختر **هذا الملف الجديد** من
   **اختيار سبورة محفوظة** داخل البرنامج، ثم ولّد الصوت بالخطوة 2.

يمكن تخصيص نسخة بالصوت أيضًا؛ النسخة المنزلة تحتفظ بالمقاطع الصوتية دون تكرار
مصدر الصوت الحي. لإعادة توليد أصوات أخرى استخدم الأصل الصامت كالعادة.
تغيير الألوان لا يعيد تشغيل الصوت ولا يقفز إلى بدايته. الظهور والشخصيات مستقلان
عن الأصوات، ولا تُنطق أسماء الشخصيات أو أكواد الألوان.

## الحركة والأداء وإمكانية الوصول

- تلويح بسيط ورمش وميل الرأس أثناء التشغيل، خارج مساحة الكتابة حتى لا تغطي النص.
- الشخصية النشطة تتبع سطر الصوت عند وجود خريطة فعلية؛ دونها تستخدم التقدير القديم.
  توزيع الكتابة داخل السطر يظل تقريبيًا، وليس محاذاة كلمات دقيقة.
- ليست مزامنة شفاه، ولا فيديو مولدًا، ولا شخصية ثلاثية الأبعاد أو مولّد صور مفتوحًا.
- تتوقف الحركة مع الإيقاف المؤقت، أو إخفاء الشخصية، أو تعطيل خيار الحركة.
- يحترم الملف إعداد **تقليل الحركة** في النظام. معاينات المكتبة ثابتة وغير متحركة.
- رسوم SVG الست مجتمعة أقل من 25 كيلوبايت. لا فيديوهات، CDN، خطوط خارجية، أو
  نموذج كبير جديد. تستخدم الحركة CSS، ولا تضيف حلقة JavaScript للتوقيت.
- التصميم خفيف مراعاةً لجهاز 4 جيجا وكارت مدمج، لكن استهلاك الذاكرة والأداء على
  جهاز Windows بهذه المواصفات لم يُقاسا هنا. افتح درسًا قصيرًا أولًا.
- اختر ألوانًا داكنة واضحة على الورق الأبيض؛ الأصفر والألوان الفاتحة قد تصعّب القراءة.

## التوافق والحدود

- النسخ القديمة تظل قابلة للقراءة وإضافة الصوت؛ أعد توليد السبورة لتضمين أدوات المظهر
  الجديدة. مجرد تحديث البرنامج لا يضيف المكتبة تلقائيًا إلى HTML قديم محفوظ.
- بيانات المظهر منفصلة عن نص الدرس وبصمته؛ تعديلها لا يغيّر الكلام أو توزيع الأصوات.
  تُراجع الألوان ومعرفات الشخصيات والصفوف عند إعادة استيراد الملف، ولا يقبل البرنامج
  SVG أو روابط شخصيات خارجية. التطبيق لا ينفذ JavaScript الخاص بالصفحة المستوردة.
- تغيير المظهر نفسه لا يعالج طبيعية النموذج العربي. يتضمن التحديث إصلاحات مستقلة:
  منع إسناد الحروف العربية لنموذج إنجليزي والعكس، ومنع فواصل رد مصطنعة بين سطور الدور نفسه،
  وترتيب عرض اللغتين. ليست هذه ضمانًا لجودة صوت بشري أو لهجة مصرية.
- من **ترتيب اللغتين** اختر الإنجليزي فوق العربي أو عمودين أو ترتيب السكريبت.
  اكتب الإنجليزية ثم العربية المقابلة؛ لا تُنشأ ترجمات، ولا تتغير أدوار النطق.
  الأعمدة تتحول إلى ترتيب رأسي على الشاشة الصغيرة، والاختيار يُحفظ مع التخصيصات.
- تجربة جاهزة بلا صوت: [greetings-kids.html](examples/greetings-kids.html).
- لا تحتاج إنشاء السبورة أو التخصيص إلى نموذج صوتي. الحزمة مصدر فقط، وليست EXE.
