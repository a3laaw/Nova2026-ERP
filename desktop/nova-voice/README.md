## جديد0.12: مصدر مجاني ثانوي اختياري، لا بحث إنترنت مفتوح

المحرّك المحلي يبقى الأساس. بعد تفعيل الخيار، يقترح المخطّط من معنى السكريبت/الوصف
معرّفات ضمن **16 رسمًا ثابتًا مدققًا من Game-icons**، مع بدائل أصلية؛ لا تختار أنت
حيوانًا من كتالوج. **تجهيز من الذاكرة دون شبكة، أو تنزيل الملفات المقترحة فقط بإذن
مستقل لكل طلب**؛ SHA-256 وحجم وصيغة مقيدة وذاكرة ذرية، لا SVG/HTML خام أو كود.
عند الفشل يظهر البديل المحلي، بلا دفع أو مصدر مجهول. الاستيراد والمعاينة والنطق
والتصدير وHTML لا ينزّلون شيئًا. لا تثبيت Konva/Three أو تغيير للمحرّك أو الأصوات.

أي تجهيز يلغي الاعتماد ويعيد الخطة إلى مراجعة صامتة. أصل الوصف والبصمات محفوظان.
المؤلف والمصدر وCC BY3.0 والتغييرات ترافق JSON وHTML والطباعة وبطاقات نهاية الفيديو
الصامتة (7ثوانٍ لكل مورد مستخدم، ضمن حد15 دقيقة). صورة ظلية ليست مفاصل أو مشيًا أو
رسمًا علميًا موثقًا؛ عند حاجة المعنى للمفاصل تبقى الأجزاء الأصلية هي المسار المناسب.

## مرحلة 0.11.0.dev1 المحفوظة: الأجزاء والأفعال من السكريبت، لا من قائمة قوالب

البرنامج يوجّه مخطط المشاهد ليستنتج الأجزاء والمفاصل والأفعال من النص، بدل أن
يطلب منك اختيار حيوان أو شكل أو حركة. **مجموعة أجزاء متداخلة، تتابع مفاتيح عبر
الجمل وتكرار محدود، منحنيات، قطاع/حلقة وتدرجات، وسطح كروي مظلل يدور بإسقاط2.5D**.

هذه مفردات عامة، لا ثلاثة قوالب للموضوعات التي ذُكرت أمثلةً.

JSON المتقدم اختياري. راجع المقترح والأجزاء والجمل في النص العادي والمعاينة الصامتة،
ثم اعتمد قبل النطق/التصدير. ساعة الجمل نفسها تدير كل جزء؛ الوقف والرجوع وتقليل
الحركة والطباعة والفيديو والعمل دون إنترنت محفوظة. التحقق البنيوي لا يثبت المعنى
العلمي أو جودة فهم نموذج مجاني لسكريبت جديد؛ **لم يجرِ استدعاء استدلال حي هنا**.
لا مكتبة خارجية/أوزان أو تنزيل خفي جديد، ولا محرك3D عام أو خرائطGIS معتمدة.

## دليل «استدلال» الحالي: «استدلال» لكل إمكانات البرنامج

افتح **[استدلال مباشرة](INFERENCE-GUIDE-AR.html)** دون إنترنت أو خادم، أو التبويب السادس
**«استدلال»** في التطبيق. **90 قدرة ومسارًا في8 أقسام**: من محتوى الوزارة المراجع إلى
نص/وصف/حوار، وكل أنواع الرسم والحركة، والأصوات والألوان والأطفال، والمراجعة والملفات،
والطباعة/الفيديو والتحويل والخصوصية. ليست قوالب مواد، ولا شرح الحركات الست وحدها.

لكل قدرة: ما تطلبه، مثال مؤلف وشكل ناتج متوافق، أين تستخدمه، وخطواته وحدوده.
ابحث أو صفِّ، وألصق المصدر ثم ابنِ الطلب وانسخه أو نزّله TXT بطلبك. **الإعدادات المحلية
تعطي خطوات واجهة، لا أوامر زائفة داخل النطق**. متطلبات الرسم ملحق منفصل لتوجيه البرنامج
المرتبط بالمصدر؛ لا JSON/بصمات مخمّنة. لا نقل للمحرر أو إرسال/حفظ/اعتماد/نطق تلقائي.

لا قارئ PDF/OCR جديدًا؛ الاستخراج خارج البرنامج ثم المراجعة. النصوص المقدسة تعطّل
إعداد الطلب الخارجي وملحق الرسم وتعرض مراجعة محلية بلا إدراج نص الحقول. تغيير الحقول
أو القدرة أو السياسة يلغي النص المبني. الفهرس والعقود مشتركة بين HTML والتبويب الأصلي.
[دليل الاستخدام والتغطية والحدود](INFERENCE-GUIDE-AR.md). الأمثلة مؤلفة لا وزارة أو AI حي،
ولا إثبات جديد لصوت بشري أو Windows/4GB؛ الاختبارات لا تعادل مراجعة المحتوى.

## مرحلة 0.9.0.dev1 المحفوظة: حركة أغنى وتحويل MP4 فعلي

- **مسارات متعددة النقاط ودوران حول محور صريح**، مع smoothstep اختياري للانطلاق
  والتوقف. بيانات JSON مقيدة وساعة السطر نفسها؛ لا قوالب مواد أو كود مولّد. تقليل
  الحركة والتقديم العكسي محفوظان. الطباعة تحفظ بداية/وسط/نهاية الحركة برسوم منفصلة.
- تبويب خامس **«MP4 متوافق»** لتحويل فيديو HTML المنزّل، اختياريًا باستخدام FFmpeg
  موثوق تختاره محليًا: **H.264 Main/yuv420p وAAC-LC عند وجود صوت**،720p/20fps/faststart.
  لا تغيير امتداد،لا تنزيل تلقائي أو خدمة،ولا تحويل داخل المتصفح يستدعي Python.
  قراءة حاوية مستقلة وفك كامل قبل الحفظ،إلغاء دون ملف جزئي واستبدال ذري بإذن صريح.
- WebM يفضّل VP8 لتخفيف الحمل. حارس يتوقف إذا تأخر إطار/انحرفت ساعة الصوت أكثر
  من350ms بدل نشر خرج مشكوك في تزامنه. هذا لا يكشف كل عيب مشفّر أو يصلح صوتًا تالفًا.

## تنظيم الواجهة

- **النص والأصوات:** المحرر، مثال السبورة، اختيار الراوي/الحوار والنماذج والصيغة.
  السرعة والفواصل داخل **إعدادات إضافية**؛ لا تُمسح قيمها عند طيها.
  **من وصف قصير إلى درس كامل مرسوم** للتأليف، و**مشاهد ذكية** للرسوم والاعتماد؛
  قسمان اختياريان قابلان للطي، لا يستبدلان الأصوات أو التبويبات الأصلية الأربعة.
- **ألوان وشخصيات:** ترتيب اللغتين، الألوان والأطفال؛ لون الجملة داخل قسم متقدم.
- **سبورة محفوظة:** الزران 1 و2 لاختيار أصل صامت ومراجعته أو استكماله.
- **صوت فقط / HTML:** التصدير الصوتي العام وإضافة الصوت إلى صفحة خارجية.
- **MP4 متوافق:** فيديو موجود + FFmpeg موثوق + مراجعة جديدة؛ تحويل H.264/AAC اختياري.
- **مكتبة المنهج:** فهرس محلي لكل ما تتمه (أزرار فتح/تعديل/إضافة/حذف)، بستة حقول تعليمية حرة النص؛ «فتح للتعديل» يحمّل سكريبت الإدخال ويستبدل نفس الإدخال بعد التصديرات القادمة.

زر التوليد الموحّد والإلغاء والتقدم ثابتة أسفل مساحة التبويبات. **النتيجة والاستماع**
يفتح بعد النجاح، دون نقل النص أو تغيير الأصوات عند التنقل. صفحة السبورة تعرض أدوات
التشغيل قبل الأطفال؛ قائمة الخطوات قابلة للطي، والتخصيص في ثلاث مجموعات واضحة.
صفحة التسليم تفصل التحميل والتجهيز والمعاينة والبحث عن الصوت المصري.

## زر واحد: توليد السبورة بالنص والصوت معًا

اكتب أو الصق السكريبت، واختر الراوي أو أصوات الحوار ولغاتها وMP3/WAV، ثم اضغط
**«توليد السبورة بالنص والصوت معًا»**. تختار اسم ملف HTML **مرة واحدة**؛ يحتوي
الناتج على السبورة والنص والصوت المضمّن وتوقيت السطور والتحكم بالسرعة والألوان والأطفال.
لا تحتاج إنشاء ملف HTML مسبقًا. التوليد في الخلفية مع تقدم وإلغاء آمن.

هذا الزر يستخدم **النص الحالي في المحرر** وتخصيصات البرنامج؛ داخليًا تُنشأ سبورة
صامتة مؤقتة ثم تُقرأ للصوت وتُحذف بعد العملية. لا ملف وسيط مطلوب منك، ولا تُستبدل
السبورة الأصلية المحددة. الزران **1. توليد السبورة HTML** و**2. توليد صوت السبورة**
باقيان للمراجعة أو لاستكمال ملف محفوظ وتخصيصات المتصفح. زر التصدير نفسه لا يؤلف الدرس؛
مرحلة الوصف الجديدة تؤلف **مسودة منفصلة** قبل مراجعته واعتماده.

## تحديث 0.5.0: توقيت فعلي لكل سطر في السبورة

يُولّد المسار الموحّد والخطوة 2 **ملفًا صوتيًا واحدًا متدفقًا لكل خطوة** مع خريطة صغيرة لحدود كل

تشذيب المتصفح قد يختلف. انظر [القياس والاختبار اليدوي](WHITEBOARD-GUIDE.md)،

## ضبط اللغة وتقليل الوقفات المصطنعة في 0.5

- فحص **كل** المقاطع قبل تحميل النماذج أو استبدال الملف: العربية لا تُرسل إلى نموذج
  إنجليزي، والنص اللاتيني لا يُرسل إلى نموذج عربي. رسالة الخطأ تحدد الدور المطلوب
  تصحيحه. الدور 1 ليس عربيًا بالضرورة؛ يمكنك عكس الدورين باختيار النموذج المناسب.
- النص الذي يخلط حروفًا عربية ولاتينية في الدور نفسه يحتاج الفصل إلى دورين مناسبين.
  هذا فحص للحروف وبيانات لغة النموذج في JSON، لا تعرّف آليًا على اللهجة، ولا ترجمة
  أو تبديل خفي للأصوات.
- لا يُضاف فاصل ردود لمجرد التفاف الجملة أو تكرار الدور. المسار المقاس يحتفظ بكل
  سطر لقياسه، بلا فاصل إضافي بين صفوف الدور نفسه؛ المسار العام القديم يظل يدمجها.
  قد تختلف نبرة الوصل بين السطور لأن حدود طلبات TTS أصبحت مرتبطة بها، لا لأننا ندمج ملفات.
- اختيار **الإنجليزي فوق والعربي تحته** أو **عمودين** أو **ترتيب السكريبت**، قبل
  إنشاء السبورة أو من أدوات HTML. الأعمدة تعود لصفوف متتابعة على الشاشة الصغيرة.
  اكتب العبارة الإنجليزية ثم مقابلها العربي؛ البرنامج لا يستنتج ترجمات أو يعيد ترتيب حوارك.
- دعم الترقيم الواضح مثل `1. [2] Hello.[/2]` دون تعديل السكريبت يدويًا. الكلام الحر
  خارج الوسوم ما زال يُرفض، ولا تُحذف كلمات لتخمين صاحبها.
- فراغات التمارين من نقاط كثيرة أو شرطات سفلية تبقى مرئية وتتحول إلى وقفة قصيرة في
  نص النطق؛ لا يملأ البرنامج اسمًا أو عمرًا أو إجابة من عنده.

هذه إصلاحات لأسباب برمجية محددة، **وليست ضمانًا لصوت عربي طبيعي أو مصري**.
لا نموذج صوتي جديدًا في الحزمة. جودة الصوت الفعلية تحتاج الاستماع إلى نموذجك على
Windows؛ النموذج التجريبي في الاختبارات ينتج صمتًا فقط.

## ما الذي يقدمه؟

- إدخال/لصق السكريبت أو استيراد ملف TXT بترميز UTF-8 أو UTF-16.
- واجهة عربية RTL واختيار صريح بين العربية وEnglish والأصوات الأخرى المثبتة.
- وضع «راوٍ واحد» ووضع «حوار بين صوتين»: شخص يتكلم ثم الآخر يرد في ملف واحد.
- لغة ونموذج ومتحدث مستقل لكل شخص؛ وسوم `[1]` و`[2]` لا تُقرأ بصوت.
- فاصل ردود قابل للضبط وتوحيد ترددات النماذج محليًا دون تغيير طبقة الصوت.
- إضافة نموذج Piper من القرص أو USB؛ ينسخ الملفين إلى مساحة التطبيق المحلية.
- اختيار المتحدث في النماذج متعددة المتحدثين.
- سرعة من 0.60× إلى 1.60×، وفواصل فقرات قابلة للضبط.
- معاينة أول 400 حرف وتشغيل/إيقاف مؤقت وتقديم الصوت.
- حفظ السكريبت كاملًا بصيغة MP3 (192 kbps) أو WAV (PCM 16-bit mono).
- تقسيم النصوص الطويلة تلقائيًا؛ الحد الأقصى 100,000 حرف.
- التوليد والاستيراد في الخلفية مع مؤشر تقدم وإلغاء آمن.
- الكتابة إلى ملف مؤقت ثم الاستبدال بعد النجاح فقط؛ لا يُفسد الإلغاء ملفًا موجودًا.
- اختيار HTML مع السكريبت وتوليد **نسخة جديدة بالصوت المضمّن** ومشغّل يتحكم بالسرعة
  من 0.5× إلى 2×، مع ربط سرعة حركات CSS/Web Animations المدعومة اختياريًا.

ليست هذه أداة استنساخ أصوات أو غناء. جودة النطق، والجنس، واللهجة تعتمد على النموذج.
المثال العربي الموصى به **`ar_JO-kareem-medium` (كريم، الأردن)** وليس صوتًا كويتيًا.
يضم Piper تشكيلًا عربيًا محليًا؛ قد يساعد التشكيل اليدوي للكلمات الملتبسة أيضًا.

## 1. تشغيل المشروع على Windows

1. ثبّت **Python 3.12 x64** مع Python launcher؛ تدعم ملفات التشغيل 3.11–3.13 x64.
2. فك ضغط/انسخ هذا المجلد إلى مكان قابل للكتابة، مثل المستندات.
3. شغّل **`Setup-Windows.bat`** لتثبيت المتطلبات مرة واحدة؛ أعد تشغيله إذا كنت تحدّث نسخة 0.1.
4. على جهاز متصل، شغّل **`Download-Arabic-Voice.bat`** مرة واحدة لتنزيل نموذج كريم
   وملف إعداداته و`MODEL_CARD` من مستودع أصوات Piper الرسمي. يتحقق السكريبت من
   الحجم وبصمة MD5 المنشورة للملفين قبل إظهارهما للتطبيق؛ MD5 هنا لكشف التلف،
   وليس بديلًا عن التحقق من موثوقية المصدر وHTTPS.
5. للإنجليزية شغّل **`Download-English-Voice.bat`** واختر صراحةً **Alan أو Cori (UK)**.
   المسار البريطاني أولًا؛ Lessac وAmy أمريكيان (US) كبديل اختياري. لا اختيار صوت أو
   جنس نيابة عنك. يمكنك تنزيل الصوت الثاني من مجموعة UK/US نفسها للحوار.
   راجع [دليل UK/RP وحدود التحقق](BRITISH-ENGLISH-AR.md) قبل الاستخدام التعليمي.
6. شغّل **`Run-Windows.bat`**. من الآن يمكن فصل الإنترنت.
7. الصق النص، اختبر المعاينة، ثم اختر **توليد وحفظ الصوت**.

إذا كانت لديك الملفات مسبقًا، تجاوز الخطوة 4 واستخدم **إضافة نموذج** داخل التطبيق.
للتجربة يوجد نص في [`examples/arabic-script.txt`](examples/arabic-script.txt)، وحوارات في
[`bilingual-dialogue.txt`](examples/bilingual-dialogue.txt)،
[`arabic-dialogue.txt`](examples/arabic-dialogue.txt) و
[`english-dialogue.txt`](examples/english-dialogue.txt).

## حوار: صوت يقول جملة والآخر يرد

1. اختر **حوار بين صوتين** من نوع السكريبت.
2. في تبويب **الصوت 1** اختر لغة النموذج والنموذج والمتحدث الأول.
3. في تبويب **الصوت 2** اختر لغة النموذج والنموذج والمتحدث الثاني.
4. ضع وسمًا في بداية سطر كل مقطع، مثل:

```text
[1] مرحبًا، كيف أقدر أساعدك؟
[2] Hello! I have a question about this program.
[1] تفضل، ما سؤالك؟
[2] Can we save our conversation as a single audio file?
```

الوسمان لا يُقرآن ولا يظهران كنص على السبورة، والكلام يبقى بترتيب النص دون
تداخل. يمكن تبديل الصوت **داخل السطر نفسه** أيضًا، مع إغلاق اختياري متطابق:

```text
[1] مرحبًا بكم![/1][2] Greetings and introductions.[/2]
```

- ابدأ الكلام بوسم **`[1]` أو `[2]`**، لا بـ`[/1]` أو `[/2]`؛ الشرطة تعني الإغلاق.
- من دون إغلاق، يستمر الدور حتى وسم البداية التالي، بما فيه سطور الاستكمال.
- إذا أغلقت المقطع، ابدأ الكلام التالي بوسم جديد؛ لا يُخمن البرنامج صاحبه.
- الوسوم متتابعة لا متداخلة. الإغلاق غير المتطابق، الدور المجهول، أو المقطع الفارغ
  يُظهر خطأً قبل إنشاء السبورة أو تشغيل المحرك، بدل نطق الوسوم أو إسقاط الكلمات.
- صيغ `[1]` و`[2]` محجوزة لتحديد الأدوار حتى داخل الجملة، وليست نصًا حرفيًا للنطق.
  الأقواس العادية مثل `[example]` داخل الجملة تبقى جزءًا من الكلام.
- يُقبل كذلك `1:` و`2:` و`A:` و`B:` والأرقام العربية `١:` و`٢:` **في بداية السطر**،
  حتى لا تُفسر الأوقات مثل `10:30` كتبديل صوت.

مثال مصحّح لدرس التحيات مع وسوم متجاورة:
[`examples/greetings-inline-dialogue.txt`](examples/greetings-inline-dialogue.txt).
إذا كانت سبورة قديمة تعرض الوسوم، أعد الخطوة 1 بالسكريبت المصحّح، ثم الخطوة 2؛
الملف القديم لا يتغير تلقائيًا. يحتفظ HTML بالسكريبت داخل بياناته لإعادة التوليد،
لكن النص المعروض والمسلّم لمحرك النطق لا يتضمن وسوم الأدوار.

لإسناد فقرة موجودة، ضع المؤشر فيها واضغط **وسم الفقرة [1]** أو **وسم الفقرة [2]**
(`Ctrl+1` / `Ctrl+2`). لا يكدّس الزر الوسوم عند إعادة تعيين الفقرة. يوجد زر لإدراج
مثال عربي/إنجليزي بعد تأكيد استبدال النص. تغيير وضع السكريبت لا يعيد كتابة نصك.

المعاينة لأول 400 حرف **من الكلام**، مع حفظ المتحدثين وترتيبهم. قد تقتصر على
المتحدث الأول إذا كان دوره الأول طويلًا. الحفظ يصدر الحوار كاملًا في MP3 أو WAV
واحد. يمكن ضبط فاصل الردود من 0 إلى 2000 ملّي ثانية، وفواصل الفقرات بشكل مستقل.

### اللغتان وهوية الصوت

- فلتر العربية/English يرشّح **النماذج المثبتة**؛ لا يترجم النص ولا يحوّل نموذجًا
  إنجليزيًا إلى عربي. طابق لغة كل مقطع مع نموذج المتحدث المسند إليه.
- لحوار عربي كامل، اختر نموذجين عربيين؛ ولإنجليزي كامل اختر نموذجين إنجليزيين.
  ويمكن الجمع بين نموذج عربي ونموذج إنجليزي كما في المثال.
- يلزم **صوتان حقيقيان مختلفان** أو متحدثان مختلفان داخل نموذج متعدد المتحدثين.
  يرفض التطبيق نفس النموذج ونفس رقم المتحدث للدورين عندما يُستخدمان معًا.
- `kareem` وحده صوت عربي واحد. الصوت العربي الثاني يتطلب نموذج Piper عربيًا آخر
  متوافقًا تستورده، أو نموذجًا عربيًا متعدد المتحدثين. نسختان من كريم أو تغيير السرعة
  لا يصنعان صوت شخص آخر؛ ليس هناك ادعاء بوجود صوت عربي ثانٍ مرفق.
- تنزيل الإنجليزية يعرض Alan وCori (UK) أولًا، وLessac وAmy (US) اختياريًا.
  القوائم تميّز UK/US من بيانات النموذج؛ هذا ليس تحويل لهجة أو شهادة جودة/RP.
  اقرأ MODEL_CARD لكل صوت، واستمع إلى جملة قصيرة قبل التدريس.
- يُحمّل المحرك نموذجين كحد أقصى ويعيد استخدامهما بين الردود. عند اختلاف ترددات
  الأصوات يُستخدم libsoxr محليًا لتوحيدها إلى أعلى تردد مستخدم، مع الحفاظ على
  المدة والطبقة، بدل دمج ملفات MP3 جاهزة أو تغيير رؤوس WAV فقط.

## سكريبت ← سبورة HTML ← صوت، في خطوتين

لا تحتاج تجهيز ملف HTML مسبقًا. يمكنك استخدام الزر الموحّد الثابت أسفل الواجهة،
أو من تبويب **سبورة محفوظة** إبقاء مسار المراجعة القديم:

1. اكتب `# عنوان الدرس`، ثم `## عنوان الخطوة` ومحتواها، واضغط **1. توليد السبورة HTML**.
   يتولد ملف مستقل بكتابة القلم والتنقل والسرعة، **دون نموذج صوتي**.
2. راجع النتيجة واختر الأصوات، ثم اضغط **2. توليد صوت السبورة**. يقرأ البرنامج النص
   المحفوظ داخل السبورة نفسها، ويضيف مقطعًا لكل خطوة في **نسخة جديدة**.

لراوٍ واحد اكتب النص عاديًا، وللغتين أو حوار استخدم `[1]/[2]` واختر وضع الحوار.
العناوين والوسوم لا تُقرأ. يدعم أيضًا الفقرات المفصولة بسطر فارغ كخطوات افتراضية.
زر **مثال سكريبت سبورة** يدرج مثال التحيات، ويمكن اختيار سبورة محفوظة لاستكمال
إضافة الصوت بعد إعادة فتح البرنامج، دون إعادة إدخال السكريبت.

في النتيجة تتبع الكتابة موضع الصوت وسرعته من 0.5× إلى 2×، مع إيقاف واستكمال وتقديم
داخل الخطوة. **حدود كل سطر مقاسة من الصوت؛ الكتابة داخله تقريبية لا كلمة بكلمة**.
الملفات القديمة أو الخرائط الناقصة/التالفة تستخدم تقدير طول النص السابق. الانتقال التلقائي
بين الخطوات اختياري ومغلق افتراضيًا. المولّد قالب نصي، لا يولّد رسومات حرة أو
تمارين من تعليمات عامة بالذكاء الاصطناعي.

راجع [WHITEBOARD-GUIDE.md](WHITEBOARD-GUIDE.md). المثال الجاهز
[`examples/greetings-whiteboard.html`](examples/greetings-whiteboard.html) **بلا صوت مسبق**،
وسكريبته [`examples/greetings-lesson.txt`](examples/greetings-lesson.txt).

## HTML + السكريبت: صفحة بصوت وتحكم بالسرعة

من قسم **أضف الصوت إلى ملف HTML** اختر الصفحة، ثم أدخل السكريبت واختر الراوي أو
صوتي الحوار واضغط **توليد صفحة HTML بالصوت**. احفظ النسخة باسم جديد بجانب الأصل.
الصوت مضمّن داخل HTML، وليس رابطًا إلى ملف MP3 منفصل، وتظهر لوحة صوت قابلة للتصغير.

يمكن خفض سرعة الصوت إلى 0.5× وتطبيق النسبة نفسها على الحركات التي يتيحها المتصفح،
مع ربط الإيقاف/التشغيل اختياريًا. **مؤقتات JavaScript الخاصة ومطابقة الجمل مع المشاهد
ليست تلقائية**. كذلك لا تُنقل صور/مكتبات الصفحة الخارجية أو تُجعل محلية تلقائيًا.

راجع [HTML-GUIDE.md](HTML-GUIDE.md) للخطوات والقيود والخصوصية. للتجربة توجد صفحة
[`examples/animated-page.html`](examples/animated-page.html) بحركة CSS، دون صوت مسبق.

## 2. جهاز غير متصل نهائيًا

الطريقة الأبسط:

1. ابنِ نسخة EXE على جهاز Windows متصل (القسم التالي).
2. جهّز النموذج الصوتي على الجهاز المتصل.
3. انقل **مجلد NovaVoice المبني كاملًا** والنموذج إلى الجهاز غير المتصل عبر USB.
4. شغّل `NovaVoice.exe` واستورد النموذج. لا تحتاج Python على الجهاز المستهدف.

بديل للمطورين: جهّز المتطلبات على **Windows x64 بنفس إصدار Python** المستخدم في
الجهاز غير المتصل، وليس على Linux:

```powershell
py -3.12 -m pip download --only-binary=:all: -r requirements.txt -d wheelhouse
```

انقل هذا المشروع و`wheelhouse/` ومثبت Python x64 والنموذج بواسطة USB. بعد تثبيت
Python شغّل `Setup-Windows.bat`؛ عند وجود ملفات wheels يثبّتها بـ`--no-index`
دون الوصول إلى الشبكة. لبناء EXE دون اتصال أيضًا جهّز wheels من
`requirements-dev.txt` بدل `requirements.txt`.

## 3. إنشاء ملف EXE

**يتطلب بناء EXE نظام Windows؛ PyInstaller لا يبني Windows EXE من Linux.**

بعد الإعداد شغّل **`Build-Windows.bat`**؛ ينفّذ الاختبارات ثم يبني:

```text
dist/

    _internal/       # ضروري، لا تحذفه
```

احتفظ بالمجلد كاملًا. النموذج لا يدخل تلقائيًا في الحزمة؛ انسخه إلى
`dist/NovaVoice/voices/<voice-name>/` إذا أردت حزمة مجهزة دون اتصال، بعد مراجعة
ترخيصه. النسخة غير موقّعة رقميًا؛ قد يعرض SmartScreen تحذيرًا. افحص المصدر ولا
تعطّل حماية Windows على مستوى الجهاز.

## الخصوصية والتخزين

- لا يرسل الرسم/النطق المحلي النص أو الصوت إلى خدمة. **اقتراح المشاهد فقط** يمكنه
  إرسال نص الدرس إلى OpenRouter ومزوّد النموذج بعد إعداد وموافقة منفصلين لكل طلب.
  اختيارات البدائل ترسل الخطة السابقة وملاحظتك أيضًا، دون بيانات المورد الخام أو نسبته.
  لا إرسال عند الفتح/الكتابة/الاستيراد/المعاينة/التصدير، ولا إرسال ملفات الصوت.
  راجع SMART-SCENES-AR.md للشروط والحدود، ولا ترسل بيانات حساسة أو مفاتيح في النص.
- لا يحفظ العميل المفتاح في الإعدادات/السجل/الخطة/HTML؛ خانته سرية وتُمسح عند أخذ
  الطلب أو الإغلاق. جلسة البدائل اختيارية وموقوفة افتراضيًا، في الذاكرة فقط للسكريبت
  نفسه وحتى30دقيقة من إدخاله، مع نسيان صريح ودون تجديد بمجرد الاستخدام. كل محاولة
  بإذن مستقل؛ لا نعد بمحو ذاكرة النظام. راجع REVIEW-CHOICES-AR.md.
- التطبيق لا يحتاج خادمًا محليًا؛ HTML النهائي ومعاينة الرسم يُفتحان في المتصفح.
- سكريبت **`tools/download_voice.py`** منفصل واختياري وصريح، ويستخدم الإنترنت
  لتنزيل الأوزان فقط؛ لا يستورده تطبيق التحويل ولا يرسل إليه السكريبت.
- يتم تعطيل telemetry في ONNX Runtime قبل تحميل النماذج.
- لا يحفظ البرنامج نص السكريبت تلقائيًا؛ احفظه خارجيًا إذا أردت الاحتفاظ به.
- تحفظ الإعدادات، الأصوات المستوردة والسجل التشخيصي في
  **`%LOCALAPPDATA%\NovaVoice`**. لا يُكتب نص السكريبت إلى السجل.
- المعاينات WAV مؤقتة في مجلد Windows المؤقت، وتُنظف عند الإغلاق المعتاد. بعد
  تعطل قسري قد يبقى مجلد `nova-voice-preview-*`؛ يمكن حذفه عندما يكون البرنامج مغلقًا.
  معاينة المشاهد الصريحة تكتب HTML مؤقتًا في `nova-scene-review-*`، ويُنظف عادة عند
  الإغلاق. لا حفظ تلقائي لمسودة JSON؛ حفظ الخطة/HTML النهائي اختيار صريح منك.
- يمكن أن يحتوي الملف الصوتي على معلومات حساسة؛ اختر مجلد إخراج مناسبًا.
- يستهلك النموذج ذاكرة حسب حجمه. لا يلزم GPU؛ التحويل قد يكون أبطأ على الأجهزة القديمة.

## التطوير والاختبار

هذا تطبيق Python مستقل، **لا يغير Firebase أو Next.js أو مسارات ERP أو ملف الترجمة**.
من هذا المجلد:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe run.py --smoke-test
```

يعمل المحرك واختباراته أيضًا على Linux لأغراض التطوير. يحتاج Qt على Linux مكتبات
نظام مثل GL/EGL وxkbcommon وdbus، ومع اختبار headless استخدم
`QT_QPA_PLATFORM=offscreen`. لا يلزم ذلك على Windows؛ DLLs الخاصة بـQt تأتي مع wheels.

تمنع الاختبارات اتصالات Python الشبكية. يشغّل نموذج ONNX اصطناعي صغير مسار
Piper الحقيقي (بما فيه التشكيل العربي) واختبارات WAV/MP3، الإلغاء، حماية ملف
موجود، تقسيم النص، الاستيراد الذرّي والتنزيلات بمحاكاة HTTP. تشمل كذلك ترتيب
جمل الحوار، عدم نطق الوسوم، التشكيل العربي بجانب الإنجليزية، اختيار المتحدثين،
إعادة استخدام النموذجين، توحيد الترددات دون تغيير الطبقة وحماية الملف عند فشل الرد الثاني. **النموذج الاختباري
ينتج صمتًا ولا يقيس جودة صوت كريم أو أي نموذج مدرّب.** عند غياب مكتبات Qt المحلية
يتم تجاوز ملف اختبارات الواجهة؛ يجب تشغيله على Windows قبل اعتبار البناء جاهزًا.

لاختبارات لوحة HTML والسبورة الاختيارية (Node 22، ليست متطلب تشغيل للتطبيق):

```sh
npm ci --prefix web-tests --ignore-scripts
npm test --prefix web-tests
```

تستخدم هذه اختبارات DOM محاكاةً للصوت والحركات، وليست اختبار استماع أو عرض فعليًا.
توجد أيضًا حالات تربط HTML صادرًا فعليًا من Python مع لوحة المتصفح والسبورة.
اختبارات السبورة تفحص التشغيل والسرعة والتنقل وموضع الصوت وحماية النصوص، وحدود السطر
الفعلية، seek بالاتجاهين، 0.5×/2× بالمنزلق و`ratechange`، والتراجع عند فساد الخريطة.
اختبارات Python تفحص bytes الصوت المضمّن، حساب العينات بعد soxr والفواصل، ملكية قطع
السطر الطويل، قياس تأخير MP3 بفك ترميز محلي، وبصمة JSON، وحماية الأصل والإلغاء وCSP والترميز.
`miniaudio` مثبت في **متطلبات التطوير فقط**؛ التطبيق وHTML لا يستخدمانه. يمكن تحديد Python
لاختبار DOM عبر `NOVA_VOICE_PYTHON` إذا كان اسم أمر Python مختلفًا على جهازك.

راجع [THIRD_PARTY.md](THIRD_PARTY.md) و[LICENSE](LICENSE). ترخيص GPL يخص هذا
التطبيق الفرعي فقط، ولكل نموذج صوتي شروطه المستقلة.

تصدير السبورة يحفظ السكريبت داخل HTML؛ لا تشارك الملف إذا كان محتواه خاصًا.
