# بحث صوت مصري — Nova Voice 0.5.0

**تحديث0.15:** أضيف Azureاختياريًا بصوتي Salma/Shakirبمسمّى مصر، مع مفتاح محجوب وRegionوإذن كل عملية. كريم المحلي باقٍ؛ لا عينة Azureحيّة أو تقييم جودة/4GB. البحث المحلي التاريخي أدناه ما زال لا يثبت نموذج Piperمصريًا. [الإعداد والمجانية والخصوصية](AZURE-SPEECH-AR.md).

تاريخ مراجعة المصادر: **7 نوفمبر 2026**. هذا تقرير بحث، وليس نموذجًا مرفقًا أو
تجربة استماع أو ضمان أداء. لا يغير محرك البرنامج أو النماذج المختارة.

## الخلاصة لجهاز Windows بذاكرة نحو 4GB وكارت مدمج

- **لم أتحقق من نموذج Piper مصري جاهز ومتوافق مع هذا البرنامج.** قائمة Piper
  الرسمية ودليل مجلد العربية المفحوصين يعرضان `ar_JO` الأردنية، لا `ar_EG`.
  هذه نتيجة للمصادر المفحوصة، وليست ادعاءً بأنه يستحيل وجود نموذج آخر.
  [المصدر الرسمي](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/VOICES.md) ·
  [مجلد العربية](https://huggingface.co/rhasspy/piper-voices/tree/main/ar).
- توجد مشاريع مصرية فعلًا، أهم المرشحين في البحث **VoiceTut-TTS** و
  **NAMAA-Egyptian-TTS**، لكنهما ليسا نموذجَي Piper. يلزم دعم محرك آخر وتجربة
  مستقلة قبل إضافتهما. [1](https://github.com/MohammedAly22/VoiceTuT-TTS)
  [3](https://huggingface.co/NAMAA-Space/NAMAA-Egyptian-TTS)
- لا أستطيع وصف أي منهما بأنه مضمون على 4GB؛ لم تُنزّل أوزانهما أو تُشغّل على
  Windows أو تُقَس الذاكرة/السرعة أو تُسمع النتائج هنا. أرقام الناشر ليست قياسًا
  على جهازك، وحجم ملف التنزيل ليس مقدار RAM اللازم.
- **كريم الأردني أو الصوت الإماراتي ليسا بديلًا مصريًا تلقائيًا.** لا نغيّر اسم
  النموذج أو رمز البلد كي نعرضه كصوت مصري. لا تُضاف سحابة أو خدمة Edge/Azure
  تلقائيًا؛ الأصوات المستضافة ليست ملفات Piper أوفلاين.

## المرشح 1: VoiceTut-TTS — للمقارنة والاستماع أولًا

يصفه ناشره بأنه مخصص للمصرية والمزج العربي/الإنجليزي، ويوفر أصواتًا مرجعية
وعينات مقارنة. نأخذ هذه بوصفها معلومات ناشر، لا حكم جودة مستقلًا.
[1](https://github.com/MohammedAly22/VoiceTuT-TTS)

- **المحرك:** OmniVoice، أو نسخة GGUF عبر `audio.cpp`، وليست `.onnx` مع JSON
  لـPiper. لا يمكن استيرادها بزر «إضافة نموذج» الحالي.
  [3](https://huggingface.co/mohammedaly22/VoiceTut-TTS-GGUF)
- **الحجم المنشور:** نسخة Q8_0 نحو **1.26 GiB** وF16 نحو **1.53 GiB**. بطاقة
  GGUF تعرض قياسًا على **GTX 1660 Ti Laptop 6GB / WSL2** مع نحو **2.5GB VRAM**
  في أحد المسارات؛ هذا ليس إثبات تشغيل على RAM 4GB وكارت مدمج أو Windows أصلي.
  [3](https://huggingface.co/mohammedaly22/VoiceTut-TTS-GGUF)
- **الترخيص:** المشروع يعلن Apache-2.0، لكن بطاقة GGUF تنبه إلى شروط أوزان
  OmniVoice الأساسية (**CC-BY-NC منذ 2026-07-03**) وترخيص مكوّن الصوت
  **Boson Higgs Audio 2 Community License**. لا تعني رخصة كود الواجهة أن سلسلة
  الأوزان كلها متاحة تجاريًا؛ يجب تدقيق كل جزء وحقوق المرجع الصوتي قبل التوزيع.
  [1](https://github.com/MohammedAly22/VoiceTuT-TTS)
  [3](https://huggingface.co/mohammedaly22/VoiceTut-TTS-GGUF)
- **الاستماع:** [عينات الناشر](https://mohammedaly22.github.io/VoiceTuT-TTS/)، ورابط
  تجربة مستضافة من صفحة المشروع. الاستماع/التجربة على الموقع يحتاج الإنترنت،
  وليس تشغيل Nova Voice المحلي. لم يُجر اختبار استماع هنا.

**التقييم العملي:** مرشح مصري يستحق السماع والتجربة، وليس اختيارًا مثبتًا أو
توصية مضمونة لهذا الجهاز. لا اختيار مسبقًا لجنس الصوت، ولا استنساخ لصوت شخص.

## المرشح 2: NAMAA-Egyptian-TTS

- بطاقة النموذج تصفه بأنه مصري مبني على **Chatterbox Multilingual**، وتعرض
  نموذجًا نحو **0.5B** بمعاملات F32؛ ليس ملف Piper، ومثاله يستخدم PyTorch
  وChatterbox مع اختيار `cuda` أو `cpu`. [3](https://huggingface.co/NAMAA-Space/NAMAA-Egyptian-TTS)
- الناشر يعلن **MIT**. قبل دمجه يجب مراجعة المحرك وأوزان الأساس والبيانات
  وحقوق أي صوت مرجعي أيضًا، لا الاكتفاء بوسم رخصة واحد.
  [3](https://huggingface.co/NAMAA-Space/NAMAA-Egyptian-TTS)
- يذكر الناشر قيودًا في نطق القاف والأرقام واتساق النص مع الصوت بحسب المرجع.
  لا أدّعي جودة بشرية أو سلامة كل الجمل، ولا توجد هنا تجربة تثبت ملاءمته لـ4GB.
  [3](https://huggingface.co/NAMAA-Space/NAMAA-Egyptian-TTS)
- [بطاقة النموذج](https://huggingface.co/NAMAA-Space/NAMAA-Egyptian-TTS) تتضمن رابط
  تجربة؛ لم تُشغّل الخدمة ولم يُرسل إليها نص المستخدم.

## خيار تجريبي مستبعد من الإضافة الحالية: XTTS مصري

مشروع `abdullah-khaled/xtts-egyptian-arabic` يعلن لهجة مصرية، لكنه ينص صراحة على
**البحث والتجريب فقط** وعدم النشر الإنتاجي أو التجاري، ويذكر اعتماد CPML وبطء
CPU وتفضيل CUDA، مع أخطاء محتملة وتقييم رسمي غير منشور. لذلك ليس بديلًا ندمجه
كما هو في البرنامج. [4](https://huggingface.co/abdullah-khaled/xtts-egyptian-arabic)

## قبل اعتماد صوت جديد لاحقًا

1. الاستماع لعدة عينات مصرية قصيرة وطويلة، وأسئلة وأرقام وأسماء، لا الاعتماد على اسم البلد.
2. مراجعة الترخيص وحقوق بيانات التدريب والأصوات المرجعية. لا استنساخ دون موافقة صاحب الصوت.
3. اختبار Windows محليًا بعد فصل الإنترنت، وقياس أعلى RAM والوقت على الجهاز المستهدف.
4. الحفاظ على صوت إنجليزي مستقل والتناوب، وأسماء الأسطر قبل التقسيم، والتوليد المتدفق
   لكل خطوة والتوقيت الفعلي والحفظ الذري والإلغاء، دون ملفات لكل سطر أو تصحيحات زمنية تخمينية.
5. موافقة المستخدم على تغيير المحرك أو متطلبات الجهاز قبل أي تنفيذ أو تنزيل كبير.

**ما نُفذ الآن:** بحث وروابط وملاحظات توافق فقط، مع تنظيم الواجهات. لا نموذج جديد
في RAR، ولا محرك PyTorch/GGUF أو خدمة سحابية مضافة، ولا ادعاء بأن تعديل الواجهة
عالج الصوت الآلي/المقطّع.
