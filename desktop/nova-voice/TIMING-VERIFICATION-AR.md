# تقرير تحديث توقيت السطور — Nova Voice 0.5.0

## النتيجة ونطاق التغيير

الميزة الجديدة هي **خريطة فعلية لحدود كل سطر محفوظ في السبورة**، لا تغيير نموذج
الصوت أو محاذاة كلمات. تبقى الألوان والأطفال الستة والاتجاهات وترتيب اللغتين.
لم يتغير إصدار التطبيق **0.5.0**، ولم يُعدّل كود ERP أو ملف الترجمة.

- تُربط قطع TTS بالسطر قبل التوليد، ثم تُكتب PCM والوقفات بالتتابع في **مرمّز/ملف
  واحد لكل خطوة**؛ لا ملفات لكل سطر ثم دمجها ولا تخزين الصوت كله في الذاكرة.
- الحساب من عينات ما بعد soxr، وحدود السطر + الفواصل تغطي PCM المكتوب تمامًا.
- JSON بإصدار schema وبصمة تشمل الحدود وترتبط ببصمة الدرس، مع تهريب raw-text آمن.
  التحقق يرفض الأدوار/الحدود/الخطوات الناقصة وغير المتسقة.
- القلم يقرأ `audio.currentTime` في كل تحديث؛ لا يضربه مرة ثانية في سرعة الاستماع.
  توزيع الكتابة داخل السطر فقط يظل تقديريًا. الخريطة غير الصالحة ترجع للتقدير القديم.
- بقيت واجهتا `render` و`render_dialogue` وتجزئتهما كما هما. أضيف `render_lines`
  اختياريًا و`RenderResult.timing=None` افتراضيًا؛ المحرك القديم المحقون لا تُختلق
  له خريطة من مدة المقطع.
- حد HTML الأصلي 25 MiB قبل الصوت، وإجمالي الصوت 256 MiB قبل base64، كما سابقًا.
  الحفظ مؤقت ثم استبدال، والأصل والإلغاء وعامل الخلفية ومؤشر التقدم محفوظة.

## التحقق الآلي المنفّذ

البيئة: Linux، Python **3.11.2**، Node **22** وjsdom **26.1.0**، lameenc **1.9.0**،
miniaudio **1.72**. لم تُنزّل نماذج صوت مدرّبة لهذا التحديث. fixture Piper ينتج
**صمتًا لكل جملة**؛ استُخدم أيضًا PCM حتمي لضبط عينات الاختبارات.

| المرحلة | Python | DOM |
| --- | --- | --- |
| خط الأساس قبل التعديل | 303 ناجح، ملف Qt متجاوز | 38 ناجح |
| المحرك وحساب العينات | 325 ناجح، ملف Qt متجاوز | دون تغيير المتحكم آنذاك |
| دمج الخريطة في HTML والتحقق | 359 ناجح، ملف Qt متجاوز | 38 ناجح |
| المتحكم والإلغاء المقاس والتحقق النهائي | **366 ناجح، ملف Qt متجاوز** | **76 ناجح** |

- **8 اختبارات خادم التنزيل ناجحة**، إضافة إلى اختبارات التطبيق أعلاه.
- Ruff lint وformat check ناجحان. ملفات JavaScript تمر بفحص `node --check`.
- شُغلت الاختبارات القديمة مع الجديدة بعد مراحل التغيير؛ ليست الأعداد الجديدة
  بديلًا عنها. الإجمالي الجديد **63 حالة Python و38 حالة DOM** فوق خط الأساس.
- تغطي الاختبارات ترددين مختلفين وsoxr، قطع السطر الطويل وملكيته، الصمت والفقرات
  والردود، WAV وMP3، إعادة قراءة JSON والتلاعب بالبصمة، حدود الصوت والحفظ الذري
  والإلغاء أثناء التوليد والتضمين. تستخدم اختبارات المتحكم HTML صادرًا من Python.
- تغطي DOM التقديم والترجيع وpause/resume/restart و0.5×/2× بالمنزلق و`ratechange`
  الأصلي، عدم تمديد الخريطة بمدة المقطع، التفاف السطر/تغيير العرض، تقليل الحركة،
  حركة الشخصية في الفواصل، حفظ تخصيصات الملف وإعادة قراءتها في Python، جميع مفاتيح
  الخطوات الـ120، والتراجع الصامت للخرائط الغائبة/التالفة/الناقصة.

من مجلد المصدر لإعادة التحقق:

```sh
python -m pytest -q -rs
python -m ruff check nova_voice tests tools
python -m ruff format --check nova_voice tests tools
npm ci --prefix web-tests --ignore-scripts
npm test --prefix web-tests
python tools/measure_mp3_delay.py --output mp3-delay-local.json
```

على Windows استخدم Python داخل البيئة الافتراضية. قد تحتاج ضبط `NOVA_VOICE_PYTHON`
لاختبارات Node. تثبيت `requirements-dev.txt` هو الذي يضيف مفكك miniaudio الاختباري؛
لم يُضف إلى متطلبات التشغيل. خادم التنزيل اختياري في المستودع وليس جزءًا من التطبيق.

## التعديل الوحيد لاختبار قديم

في `tests/test_ui.py::test_whiteboard_audio_comes_from_saved_html_not_editor` انتقلت
نقطة المراقبة من `engine.render` إلى `engine.render_lines`، لأن توليد السبورة صار
يستخدم المسار المقاس. يجمع الاختبار `line.text` ويظل يطلب **Saved sentence.** من
الملف المحفوظ، لا النص المختلف في المحرر، مع نفس اختبارات النتيجة ومصدر الملف.
لم تُحذف assertions أو يُضعف شرط. **تعذّر تحميل Qt بسبب `libGL.so.1` محليًا، فتُجاوز الملف ولم يُنفّذ
الاختبار المعدّل هنا**؛ يجب تشغيله على Windows.

لم يُعدّل أي اختبار Python/Node قديم آخر. أُعيد توليد مثالي HTML المرفقين بالقالب
الحالي لكي تنجح اختبارات مطابقتهما الموجودة دون تغييرها.

## القياس والحدود المعروفة

1. **MP3:** فُكّت ملفات اختبار فعلية وقورنت بـWAV بترابط FFT. في الترددات التسعة
   8000–48000 Hz ظهرت إزاحة **1105 عينة** مع حشو نهائي متغير. التفاصيل في
   [جدول القياس](WHITEBOARD-GUIDE.md). لا نطبّق إزاحة تخمينية في المتصفح؛ MP3
   يُصرّح `encoder_delay_samples: null` و`clock: pcm`. **WAV أدق للعينات.**
2. السطر المقاس هو `step.rows` المحفوظ، لا كل سطر التفاف SVG أو كلمة. لا محاذاة
   phoneme/word أو كشف صوتي لبداية الحرف؛ قد يحتوي PCM نفسه صمتًا طبيعيًا من النموذج.
3. لملكية التوقيت تُحافظ طلبات TTS على حدود الصفوف بدل دمج صفوف الدور نفسه في
   طلب واحد. **لا فواصل رد إضافية بين الدور نفسه ولا ملفات سطور**، لكن نبرة الوصل
   قد تختلف؛ هذا التحديث ليس ضمانًا لصوت مصري طبيعي أو تقليل الروبوتية.
4. توليد الصوت من درس Nova قديم يبني نسخة بالقالب الحالي من الدرس والتخصيصات
   الموثقة. لا تُنقل تعديلات HTML/JavaScript اليدوية غير المدعومة؛ الأصل لا يتغير.
   المسار العام لإضافة الصوت إلى HTML خارجي لم يتغير.
5. البصمات checksums لكشف التلف/التغيّر، وليست توقيعًا أمنيًا ضد ناشر يعيد حسابها.
   لا تفتح ملفات HTML غير موثوقة.

من JSON وتجربة الخريطة الغائبة/التالفة والإلغاء.
