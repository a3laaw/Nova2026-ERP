# Nova Voice 0.11.0.dev1 — السكريبت يقود اقتراح الأجزاء والحركة

**معاينة مصدر، لا EXE أو إصدار إنتاجي.** المادة والصف نص حر، بما فيه الإعدادي، ولا حاجة إلى اختيار حيوان أو شكل أو حركة من كتالوج قبل طلب المشهد. هذه توسعة لأدوات المخطط والمشغّل؛ **ليست إثباتًا لفهم نموذج مجاني لأي سكريبت جديد** أو بديلًا عن مراجعة المعلم.

## المسار الفعلي

1. **سكريبت موجود:** الصقه في «النص والأصوات»، ثم افتح «مشاهد ذكية». المادة والصف اختياريان. يوجّه البرنامج المخطط ليستخلص المعنى والأجزاء والأفعال من المصدر مع حفظ تقسيم الجمل وأدوار الأصوات الأصلية.
2. **وصف قصير:** استخدم «من وصف قصير إلى درس كامل مرسوم». يقترح المخطط تقسيم الشرح والأهداف والمشاهد والأسئلة والإجابات والخلاصة. يظل الوصف الأصلي محفوظًا حرفيًا وغير منطوق، كما في [FULL-LESSON-AR.md](FULL-LESSON-AR.md).
3. اختر طلب الإنترنت الاختياري **بموافقة مستقلة لذلك الدرس**، أو انسخ توجيه البرنامج المرتبط بالمصدر الحقيقي إلى خدمة تختارها ثم استورد JSON. لا يختار البرنامج موضوعًا من كلمات مفتاحية أو قالب حيوان/خلية/كرة. حساب الخدمة وشروطها وتوفرها أمور منفصلة.
4. تصل **مسودة**. اقرأ ملخص الأجزاء المتداخلة والحركات والجمل الأصلية والعرض والنطق، وافتح **«معاينة الرسم بلا صوت»**. لا نقل أو اعتماد أو صوت/تصدير تلقائي. بيانات JSON داخل قسم متقدم اختياري؛ لا يلزم تعديلها أو تركيب الأجزاء يدويًا.
5. راجع صحة المحتوى ووضوح الرسم والمفاصل والتوقيت والتبسيط، ثم اعتمد صراحة. توليد النطق أو HTML أو الطباعة/الفيديو أفعال مستقلة. أي تعديل للمصدر أو الخطة يبطل اعتمادها السابق.

**المخطط يقترح، والمشغّل يرسم.** الأشكال والمجموعات والمفاصل مفردات داخلية عامة، لا مكتبة دروس يختارها المعلم. لا صور مرفوعة أو OCR أو كود مولّد أو تنزيل خامات/نماذج تلقائي. الطلب الشبكي ما زال واحدًا إلى `openrouter/free` بسقف سعر صفر، ومنع البديل المدفوع والتراجع عن مرشحات الخصوصية. لا ضمان حصة أو جودة أو مجانية غير محدودة. عند الرفض أو النتيجة غير الصالحة نتوقف، ولا نرسل طلب إصلاح خفيًا.

## ما أضيف إلى المشغّل

- **`group`**: شجرة من أجزاء مسماة، بإحداثيات ومحاور محلية. يمكن للجسم الانتقال وللأطراف/المفاصل تغيير زواياها بشكل مستقل. حركة الأب لا تمحو أو تعيد تتبع الأبناء.
- **`sequence`**: مفاتيح موحدة للانتقال والدوران والحجم والشفافية أو اللون، مع تكرار محدود وامتداد عبر عدة جمل. الوضع دالة من ساعة المصدر، لا مجموع إزاحات أو مؤقت لكل جزء؛ الإيقاف والرجوع لا يتركان وضعًا متراكمًا خاطئًا.
- **`curve`**: حركة بيزيه تربيعية أو تكعيبية مقيدة. لا سرعة فيزيائية ثابتة ولا نص SVG حر لمسار الحركة.
- **`sector`**: قطاع دائري/حلقي بزاوية صريحة، وتدرجات تعبئة خطية/شعاعية محلية `gradient`.
- **`sphere`**: سطح كروي بإسقاط متعامد، وشبكة وبقع توضيحية تحجب جهتها الخلفية وتظليل محلي. الخاصية `spin` تدوّر السطح، لا دائرة مسطحة حول نفسها. هذا **2.5D**، لا محرك 3D عام أو GIS أو كرة أرضية موثقة أو تصوير واقعي.

المشي لا يُختزل إلى صورة تنزلق؛ المخطط مُوجّه إلى تركيب أجزاء متحركة عند الحاجة. دوران سطح كروي لا يختزل إلى قرص. وكشف أجزاء رسم خلوي أو غيره **ترتيب شرح**، لا ادعاء بتكوّنه البيولوجي بهذا الترتيب. هذه أمثلة للمبدأ وليست أصنافًا حصرية أو مسارات كلمات مفتاحية.

لا مكتبة خارجية جديدة أو أوزان أو SDK في هذه التوسعة. استُخدم SVG المحلي نفسه للمحافظة على التشغيل دون إنترنت والطباعة وتصدير Canvas. السماح بمكتبات مجانية لا يجعلها خدمات فهم نص؛ عدم إضافة محرك 3D عام هنا قرار نطاق، لا وعد بقوته.

## عقد البيانات المختصر — للمراجعة المتقدمة فقط

**لا تلصق ما يلي في النص المنطوق.** لا تُنشئ جذر خطة أو بصمة يدويًا؛ استخدم توجيه البرنامج. المثال الجزئي يحتاج خطوة فيها جملتان على الأقل:

```json
{
  "kind": "group", "name": "أجزاء مرتبطة", "row": 0, "x": 300, "y": 80,
  "children": [
    {
      "kind": "rect", "name": "جزء يدور عند المفصل",
      "row": 0, "x": 0, "y": 0, "w": 25, "h": 100, "fill": "#FFB000",
      "motion": {
        "type": "sequence", "span": 2, "repeat": 2, "cx": 0, "cy": 0,
        "ease": "smooth",
        "frames": [{"at": 0, "angle": -20}, {"at": 500, "angle": 20}, {"at": 1000, "angle": -20}]
      }
    }
  ]
}
```

### المجموعات والتوقيت

- مساحة الرسم النهائية `1000×420`. إحداثيات الجزء داخل مجموعته في المجال نفسه، ثم تُضاف ترجمة المجموعة؛ المحاور محلية أيضًا. **التحقق البنيوي لا يضمن أن الشكل المحوّل كله داخل الشاشة**؛ يلزم مراجعة المعاينة.
- `name` وصف قصير حتى80 حرفًا، مطلوب للمجموعة. `children` من1 إلى20، وعمق أقصى3 بدءًا من0. الألوان ليست موروثة؛ تُحدد على الأجزاء المرئية.
- `row` **مؤشر جملة أصلي داخل الخطوة كلها**، لا يبدأ من0 مجددًا داخل كل مجموعة. `until` حصري. يرث الطفل حد عمر الأب إذا لم يحدده، ولا يتجاوز توقيته/امتداده هذا الحد.
- `group` و`sphere` ثابتان افتراضيًا، بينما يبقى افتراضي الأشكال السابقة `draw`. يمكن اختيار حركة صريحة. ظهور الأجزاء حسب الجمل يبقى عند تقليل الحركة.
- `sequence.frames`: من2 إلى8؛ `at` أعداد صحيحة تصاعدية من0 إلى1000، مع الطرفين. كل المفاتيح لها **مجموعة خصائص متطابقة وغير فارغة**.
- `dx ±300` و`dy ±180`، `angle/spin ±720` درجة، `scale 25..200%`، `opacity 0..100%`. `fill` لون سداسي مع لون أساس صريح، لا مع تدرج أو `group/icons/calculation`. `spin` للكرة فقط.
- `repeat` من1 إلى6، و`span` من1 إلى الجمل المرئية المتبقية. يبدأ التتابع عند بداية `row` وينتهي عند **نهاية آخر جملة في `span` وفق ساعة المصدر الفعلية**، بما فيها اختلاف مدد الجمل، ثم يثبت.
- عند تكرار التتابع يجب تطابق قيم الطرفين، عدا `angle/spin` يمكن فرق دورات360 كاملة. لا تكرار شفافية/لون يومض. لا يعني ذلك اعتمادًا طبيًا لسلامة كل تصميم.
- `cx/cy` محور محلي؛ افتراضيًا أصل المجموعة أو `x/y` للشكل. ترتيب التحويل: ترجمة المجموعة، ثم إزاحة التتابع، ثم المحور والدوران والحجم. `ease` خطي أو smoothstep بين المفاتيح.
- `curve.points`: ثلاث/أربع نقاط تحكم تبدأ`[0,0]`، وأخرى غير صفرية؛ الإزاحات ضمن حدود الحركة. زمنها جملة واحدة ثم تثبت. الاستيفاء بحسب معامل المنحنى، لا طوله.

### الشكل واللون والميزانية

- `sector`: مركز`x/y`، `r 1..200`، `inner 0..r-1`، `start ±360`، `sweep 1..360` درجة.
- `gradient`: `{color:"#RRGGBB",axis:"horizontal"|"vertical"|"radial"}`، من `fill` سداسي صريح. ليس للمجموعة/الرموز/الحساب، ولا URLs/أنماط/خامات خارجية.
- `sphere`: `r 20..180`، `longitude ±180`، `tilt ±45`، وشبكة منطقية اختيارية. حتى8 بقع؛ لكل بقعة لون سداسي و3–24 نقطة صحيحة `lon ±180 / lat ±85`، وامتداد كل محور≤120 وثلاث نقاط مختلفة على الأقل. البقع توضيحية صغيرة، وليست حدودًا جغرافية أو سطحًا ثلاثي الأبعاد عامًا.
- حتى**3 كرات في الخطوة**، بما فيها المتداخلة. **60 عقدة لكل خطوة و600 للخطة**، أو180 للدرس الموسع، مع احتساب **كل مجموعة وجزء** لا الغلاف العلوي وحده. تبقى خطة JSON حتى512KiB، وحدود السطور والأدوار وبصمة المصدر والحماية المقدسة كما كانت.

## الورق والفيديو والتوافق

- الطباعة تقرأ الأجزاء المتداخلة، لا غلاف المجموعة فقط. تختار **حتى8 لقطات ثابتة ممثلة لكل جملة** للتتابعات والمنحنيات، وتشمل مفاتيح من دورة ممثلة حتى لا تبدو حركة متكررة ساكنة بسبب أخذ البداية/المنتصف/النهاية فقط.
- تستخدم اللقطات ساعة الجمل المقاسة عند وجودها، لا افتراض تساوي مدد الجمل. كل النص والأسئلة وإجاباتها والملاحظات والأصل محفوظة. ليس المقصود طباعة كل إطار أو كل دورة؛ قد تزيد صفحات المشاهد المعقدة.
- فيديو Canvas يستخدم المشغّل نفسه، مع التدرجات والإسقاط الكروي والمفاصل، بلا WebGL أو شبكة أو صوت خفي. حد15دقيقة/128MiB وحارس تأخر350ms والإلغاء بلا تنزيل جزئي باقية. الإخراج يظل قريبًا من الزمن الحقيقي، وقد يلزم مشهد أبسط على جهاز ضعيف.
- تقليل الحركة أو إطفاؤها يعيد تحويلات/ألوان/شفافية الأساس مع إبقاء ظهور الجمل، لا تجميد وضع عشوائي منتصف الحركة. هذا يزيل حركة السطح الكروي أيضًا.
- لا تغيير في مخطط الدرس المصدر أو بصماته القديمة. خطط وأمثلة الأنواع السابقة محفوظة عند الاستيراد. الأنواع الجديدة **لا يُضمن استيرادها في نسخة أقدم**. لم تُعدّل أرشيفات التسليم القديمة.

## التحقق وحدود الدليل

- متجهات مشتركة لـPython/JavaScript: **30 تركيبًا مقبولًا و83 مرفوضًا**، إضافة إلى رياضيات المنحنى والمفاتيح/تقريب اللون والإسقاط. تشمل العمق والميزانيات وعمر الأب والتكرار والحقول الخارجية والحدود، وتماثل الحفظ وإعادة الاستيراد.
- اختبارات خاصة لتداخل المفاصل وعدم محو شفافية الطفل، والرجوع الحتمي، وتقليل الحركة، وإخفاء نصف الكرة الخلفي، والتدرجات المحلية وقطاع حلقي كامل، وتفادي التماثل المضلل في لقطات حركة متكررة.
- `web-tests/browser-graph.cjs`: متصفح Linux Chromium فعلي دون إنترنت، بثلاثة عروض360/768/1366، وحفظ Blob وإعادة فتحه، والطباعة وقياس توقيت غير متساوٍ. فيديو تشخيصي فعلي بمفاصل وسطح كروي، ثم تحويل H.264/AAC وفك كامل ومقارنة مناطق من الإطارات وتحقق توقيت نغمتين. **النغمات إشارات اختبار لا نطق بشري.** يلزم تزويد أدوات التطوير محليًا؛ لا ينزلها الاختبار.
- [المثال التفاعلي](examples/composition-demo.html)، [نصه](examples/composition-demo-script.txt)، و[خطة بياناته](examples/composition-demo.json) **مؤلفة يدويًا لاختبار المشغّل**. أربع مراحل وتسعة أسطر: أجزاء مترابطة، سطح كروي، كشف أجزاء، ومنحنى/قطاع. ليست استجابة API ولا دليل تعميم لغوي.
- دليل «استدلال» أصبح **73 قدرة ومسارًا/8 أقسام**، ويغطي الأجزاء والمفاتيح والمنحنى والقطاع والكرة والتدرج، مع بقاء كل أدواته السابقة. هو فهرس مساعدة اختياري، لا سير عمل يلزم اختيار حيوان أو حركة.

نتيجة الحزمة الحالية: **1128 اختبار Python ناجحًا مع FFmpeg محلي صريح وتخطي4 وحداتQt، و415 DOM**. اختبارات التركيب156 لكل من Python وDOM، و18 فحص متصفح فعليًا جديدًا. أُعيد13 فحصًا للحركة/التحويل السابقين و26 للدليل الحالي بكل73 بطاقة. PDF التحقق للمثال17 صفحةA4 و45لقطة؛ لم تُحذف أسطره التسعة. اختبارات Qt الإضافية مكتوبة ولم تُنفّذ؛ لا تُحسب ضمن الأعداد الناجحة.

**ما لم يُثبت هنا:** طلب استدلال حي على سكريبت جديد، جودة فهم نموذج مجاني أو صوته، Windows/Qt/جهاز4GB، الدقة العلمية أو خرائط أو منهج الوزارة، القرآن/التجويد. اختبارات Qt مرفقة وتحتاج مكتبات المضيف. لا اعتماد منهجي أو ديني؛ النصوص المقدسة تبقى محلية بلا توسعة/رسوم أو تلاوة آلية.
