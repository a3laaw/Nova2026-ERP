# الأصوات المحلية

ضع هنا نموذج Piper وملف إعداده المتطابقين، مثال:

```text
voices/
  ar_JO-kareem-medium.onnx
  ar_JO-kareem-medium.onnx.json
  MODEL_CARD
```

يمكن أيضًا الضغط على **إضافة نموذج** داخل التطبيق لاستيراد الملفين إلى:
`%LOCALAPPDATA%\NovaVoice\voices`.

لا يتضمن المشروع نموذجًا حقيقيًا ولا ينزّل التطبيق أي شيء تلقائيًا.
استخدم `Download-Arabic-Voice.bat` على جهاز متصل بالإنترنت مرة واحدة، أو
انقل الملفين من جهاز آخر بذاكرة USB. راجع `MODEL_CARD` لترخيص الصوت قبل استخدامه.


## العربية وEnglish والحوار

شغّل `Download-English-Voice.bat` للاختيار الصريح: Alan أو Cori (UK) أولًا،
أو Lessac أو Amy (US) اختياريًا. ثم يُعرض تنزيل الصوت الثاني من المجموعة نفسها.
تظهر UK/US بجانب النموذج في التطبيق. لا تُعاد تسمية US إلى UK ولا تتغير اختياراتك
السابقة تلقائيًا. راجع [دليل UK/RP](../BRITISH-ENGLISH-AR.md)؛ محوّل Alan هو
`en-gb-x-rp` لكن جودة/RP الصوت المسموع لم تُختبر. اقرأ MODEL_CARD وترخيص كل نموذج.
لكل نموذج مجلد مستقل يحفظ معه MODEL_CARD، ولا تحتاج الإنترنت أثناء التحويل.
اختَر لغة كل دور في تبويبات الصوت 1/2. يلزم صوتان مختلفان أو رقما متحدث مختلفان
داخل نموذج متعدد المتحدثين. كريم وحده صوت عربي واحد؛ لحوار بصوتين عربيين مختلفين
تحتاج استيراد صوت عربي آخر متوافق أو نموذج عربي متعدد المتحدثين.
