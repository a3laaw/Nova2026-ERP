# من وصف قصير إلى درس كامل مرسوم — معاينة مصدر 0.7.0.dev1

> **تحديث مصدر0.11:** الأجزاء والمفاصل والتتابعات والمنحنيات والقطاع/التدرج والإسقاط الكروي2.5D في [COMPOSITION-MOTION-AR.md](COMPOSITION-MOTION-AR.md). السكريبت يقود الاقتراح، لا قائمة حيوان/حركة. الأرقام والنتائج التالية تاريخية لمرحلتها ما لم يُذكر غير ذلك؛ الأرشيفات السابقة لم تتغير.

**7 نوفمبر 2026 · مصدر تجريبي فقط، لا EXE ولا اعتماد Windows/4GB.**

> هذا دليل مرحلة التأليف 0.7. المصدر الحالي0.8 يضيف الطباعة الكاملة والحركة والفيديو؛
> راجع [LESSON-OUTPUT-AR.md](LESSON-OUTPUT-AR.md). الأرشيف المنشور0.7 لم يتغير.

أُضيفت المرحلة التي كانت ناقصة: الوصف لا يمر إلى محلل السكريبت على أنه جملة الدرس
الوحيدة، بل إلى طلب **تأليف مسودة كاملة ورسوم** مستقل. ينتج الطلب أهدافًا وشرحًا
موسعًا ورسومًا وأسئلة وإجابات منفصلة وخلاصة. يبني البرنامج منها سكريبتًا جديدًا
قابلًا للمراجعة، ويبقي الوصف الحرفي خارج النطق. لا يُستبدل سكريبتك القديم تلقائيًا.

هذه المعاينة **ليست حزمة 0.6.0 المنشورة**؛ الملفان القديمان 0.6.0 و0.5.1 لم يتغيرا.
رقم هذه المرحلة `0.7.0.dev1`؛ المصدر الأحدث0.8 ليس إعلان إصدار مستقر أو خدمة مجانية مضمونة.

## ما الذي يعمل، وما الذي لم يُثبت؟

| الجزء | الحالة الصريحة |
| --- | --- |
| وصف ← توجيه لتأليف درس كامل + رسوم، بطلب مجاني واحد | منفذ، والنقل مختبر بردود محاكاة فقط |
| رد/استيراد JSON ← تحقق ← درس محلي كامل | مختبر؛ لا حاجة لمفتاح للاستيراد أو المثال |
| واجهة مستقلة للوصف، المراجعة، نقل المسودة ثم اعتماد الرسوم | منفذة برمجيًا؛ اختبارات Qt مكتوبة لكن تعذر تشغيلها هنا لغياب `libGL.so.1` ومكتبات نظام أخرى |
| مثال كامل: أهداف + 4 مراحل مرسومة + سؤالين وإجابتيهما + خلاصة | 10 خطوات و16 سطرًا، مؤلف يدويًا لا ناتج خدمة AI |
| عرض SVG فعلي وحفظ HTML وإعادة فتحه دون شبكة | 36 فحصًا في Linux Chromium 153، وصفر أخطاء أو طلبات HTTP خارجية |
| توليد/تضمين الصوت وتوقيته لهذا الدرس | مختبر بنموذج ONNX اختبار ينتج **صمتًا**، وفك WAV فعلي في المتصفح؛ ليس اختبار صوت بشري |
| فهم الوصف وجودة درس من نموذج مجاني حي | **لم يُختبر**؛ لا مفتاح خدمة مضبوطًا أو اتصال مزود متاحًا في هذه البيئة |
| Windows، جهاز 4GB، جودة كريم أو UK/RP، مطابقة منهج أو اعتماد علمي | **غير مثبتة** |

لا توجد تجربة شبكة حقيقية فاشلة نخفيها ولا تجربة ناجحة نفترضها: **لم تُجرَ محاولة
استدلال حي أصلًا**. لا حساب جديد أو أرصدة مشتراة أو بديل مدفوع أو إضعاف للخصوصية.

## الاستخدام من الواجهة

1. شغّل المصدر بالطريقة المعتادة. في تبويب **النص والأصوات** افتح
   **«من وصف قصير إلى درس كامل مرسوم · مسودة ومراجعة أولًا»**.
   اكتب وصفًا بين 1 و4000 حرف، والمادة والصف/العمر اختياريًا بالنص الحر؛ بما فيه الإعدادي.
   هذه ليست قائمة قوالب تختار منها درس ماء/مثلث/خريطة.
2. اختر أحد المسارات:
   - **مثال درس كامل محلي · ليس API**: يملأ الوصف ومسودة JSON فقط، لا المحرر أو الصوت.
   - **استيراد مسودة JSON**: حزمة محلية تحفظ الوصف ومحتوى المسودة وبصمتها. إذا كان
     الوصف فارغًا يطلب البرنامج تأكيد استيراده معها؛ وإلا يجب تطابق الوصف والمادة والصف.
   - **نسخ توجيه للدرس الكامل**: ينسخ التوجيه والوصف للحافظة فقط. لصقه في خدمة أخرى
     قرارك وتابع لشروطها؛ لا يعني أن لها API مجانية أو سياسة الخصوصية نفسها.
   - **اقتراح درس كامل مرسوم · مجاني فقط**: حساب مُعدّ بالغ 18+ مؤهل، ومفتاح في
     خانته داخل البرنامج، وموافقة جديدة على هذا الوصف تحديدًا. لا تُرسل مفتاحًا في
     المحادثة أو تضع بيانات طلاب/معلومات حساسة في الوصف.
3. راجع **الوصف الحرفي، النص الموسع، الحقائق، اللغة، الأسئلة والإجابات، العرض والنطق
   ووصف الرسوم**. افتح **معاينة مسودة بلا صوت**. المعاينة ملف مؤقت للمراجعة، ليست اعتمادًا.
4. يمكن تعديل **رد JSON الخام** المعروض في القسم؛ يعيد البرنامج التحقق وبناء البصمات
   محليًا. كل تعديل يحتاج مراجعة واعتمادًا جديدين. الحزمة المحفوظة ليست هذا المحرر:
   تغيير ملف حزمة موقّع ببصمته يدويًا يُرفض؛ لا تحذف البصمات لتجاوز التحقق.
5. اضغط **«راجعت المسودة · نقلها للمحرر للمراجعة النهائية»** وأكد الاستبدال.
   عندها فقط يستبدل البرنامج نص المحرر بالسكريبت الموسع ويختار **راويًا واحدًا**،
   **دون اختيار نموذج صوتي بدلًا منك**. لا يبدأ نطق أو تصدير.
6. من قسم **مشاهد ذكية** التالي، راجع خطة الرسوم واعتمدها صراحة. ثم استخدم
   **توليد السبورة بالنص والصوت معًا** بعد اختيار الصوت الصحيح، أو احفظ سبورة بلا
   صوت أولًا بالخطوة 1 ثم أضف صوتها من الملف المحفوظ بالخطوة 2.

التصدير النهائي HTML مستقل: الرسم والنص والصوت/التوقيت إن أضفته محليًا، بلا
طلبات صور/خطوط/تخطيط أو مفتاح في الصفحة. لا تحتاج خدمة الاقتراح أثناء عرض الدرس.

### ماذا يحدث بعد التعديل؟

- تعديل الوصف/المادة/الصف أو JSON المسودة يلغي صلاحية الارتباط المعتمد، حتى إن
  أعدت استيراد المحتوى نفسه. يلزم نقل المسودة واعتماد الرسوم من جديد.
- تعديل سكريبت المحرر أو وضع الراوي أو خطة المشاهد يلغي اعتماد الرسوم. لا يُعاد
  ربط وصف قديم بنص معدّل بمجرد تغيير بصمة؛ النص الموسع يجب أن يطابق المسودة تمامًا.
- **إلغاء «تضمين المشاهد» ليس اختصارًا لتجاوز مراجعة الدرس الكامل**: يمنع التصدير
  والنطق من ذلك المحرر إلى أن تعيد الاعتماد أو تختار **فصل الارتباط** بتأكيد صريح.
- لتعديل مضمون الدرس الموسع مع الحفاظ على أصله: عدّل رد JSON، راجعه ثم انقله واعتمد
  رسومه. لفك العلاقة والعمل بالطريقة القديمة: افصل الارتباط صراحة؛ لا تُحذف المسودة
  أو الوصف، لكن التصدير التقليدي بعد الفصل لا يضمن نسبتهما إلى ذلك النص.
- إعادة رسم درس معتمد، محليًا أو بطلب مستقل بإذنك، تحتفظ بالوصف وبصمة مسودته؛ لا
  تستبدل أصل خطة محفوظة مختلفة بصمت. يجب تطابق المادة والصف وبقاء رسم بكل مرحلة شرح.
- **الصوت فقط / إضافة الصوت لصفحة خارجية** في الدرس الموسع يستخدمان النطق المعتمد
  فقط، لا عناوين `#` أو وصف الطلب أو بيانات JSON. مصدر السكريبت العادي القديم لا يتغير.
- إضافة صوت إلى **سبورة محفوظة مستقلة** تبقى من نصها وخطتها المحفوظين، لا من مسودة
  محرر أخرى متقادمة؛ حماية النصوص المقدسة العامة باقية.
  ولأن ملف درس موسع قد يأتي من معاينة مسودة، تطلب الخطوة 2 تأكيدًا جديدًا لمراجعة
  **ذلك الملف المستقل** قبل نطقه؛ لا تتحول المعاينة الصامتة إلى اعتماد محفوظ أو التفاف تلقائي.

## المثال الكامل المرفق

[افتح الدرس الصامت](examples/complete-lesson-demo.html) ثم اضغط تشغيل. استخدم قائمة
الخطوات للتنقل بين الأهداف وأربع مراحل الشرح والأسئلة والإجابات والخلاصة. الإجابة
خطوة مستقلة لا تظهر في نص سؤالها؛ الانتقال التلقائي غير مفعّل عند الفتح.

- [الوصف الأصلي](examples/water-cycle-description.txt) محفوظ حرفيًا، بما فيه نهاية السطر.
- [حزمة المسودة](examples/complete-lesson-demo.json): للاستيراد والمراجعة/التحرير المتعمد.
- [السكريبت الموسع](examples/complete-lesson-demo-script.txt).
- 4 رسوم متدرجة، 50 عنصرًا في مجموع الخطوات الأربع، و16 سطر نطق عبر 10 خطوات.
- الوصف متاح في تفاصيل **«الوصف الأصلي · محفوظ ولا يُنطق»** داخل نص كل خطوة.
- النص والرسوم أُعدا أثناء التطوير، ولا توجد آلية تختار هذا المثال من كلمات وصف المستخدم.
  ليست نتيجة استدلال حي، ولا مثالًا على قراءة صورة مرفوعة أو OCR/رؤية حاسوبية.
- تبسيط قابل لمراجعة المعلم، لا اعتمادًا علميًا أو منهجيًا عامًا لكل صف.

احتفظ بحزمة JSON إذا أردت تعديل بنية المسودة لاحقًا. HTML يحفظ الوصف والسكريبت
والخطة والتوقيت، لكنه ليس بديلًا عن حزمة تأليف المسودة الأصلية.

## حدود الطلب والصيغة

- وصف حرفي ≤4000 حرف؛ المادة والصف ≤80 لكل منهما، وسياسة `general` فقط.
- عنوان، 2–6 أهداف، 2–8 مراحل شرح، وفي المجموع ≥4 سطور شرح.
- كل مرحلة: عنوان، وصف وصول للرسم، 1–6 صفوف `{display,speech}` و1–60 عنصرًا.
  السطر مستقل/plain ≤180 حرفًا بلا وسوم أدوار/عناوين مخفية أو نطق صامت.
- 1–4 أسئلة وإجابات منفصلة، 1–4 سطور خلاصة، وملاحظات للمراجعة. النص الموسع ≤12000 حرف.
- ≤180 عنصرًا للدرس الكامل، داخل مفردات الرسم العام نفسها: أشكال ومسارات وتسميات
  ورموز وحسابات محلية، لا قوالب مواد أو كود/روابط/SVG خام. ما زالت هذه **أشكالًا
  تظهر وتتحرك من إزاحات محدودة**؛ ليست تتبّعًا حيًا لضربات الرسم أو إعادة بناء صورة.
- حزمة JSON ≤512 KiB. تُرفض المفاتيح غير المعروفة/المكررة والأرقام غير المنتهية
  والتغيير غير المتسق، وتُحفظ الحزمة ذريًا دون مفاتيح أو موافقة محفوظة.
- يطلب النموذج المحتوى والرسوم، بينما ينشئ المحلل المحلي السطور وبصماتها ويشترط
  مطابقة التقسيم الفعلي. لا نخفف قاعدة ربط خطة السكريبت القديمة بصفوف أصلها.
- رد JSON الخام `schema=1`؛ حزمة المسودة `schema=1` تحوي `brief,draft,fingerprint`.
  خطة الرسم الممتدة `schema=2` تحوي `origin` إلزاميًا؛ الدرس النهائي يبقى في
  مخططات الدرس القديمة 1/2، ولا يوجد مخطط درس ثالث مخفي. الخطة القديمة 1 باقية.
- `origin` يحفظ الوصف وبصمته وبصمة المصدر وبصمة حزمة التوسيع. البصمات **اتساق لا
  توقيع مصدر أو شهادة صحة أو إثبات مراجعة بشرية**. المتصفح يفحص بصمة الوصف وربطه
  بالمصدر وصيغة بصمة المسودة؛ لا يعيد بناء حزمة تأليف غير موجودة في HTML.

## الإنترنت المجاني فقط والخصوصية

المسار هو نفس حد النقل المحروس في [دليل المشاهد](SMART-SCENES-AR.md): عنوان API ثابت،
`openrouter/free`، طلب واحد ≤8192 token، بلا redirects أو proxy تلقائي أو إصلاح/إعادة
محاولة أو نموذج مدفوع. حد السعر للطلب/الإدخال/الإخراج صفر، و`allow_fallbacks=false`،
و`data_collection=deny` و`zdr=true` و`plugins=[]`. لا يُقبل الرد دون تكلفة مؤكدة صفرًا
ومعرف نموذج مجاني ورد كامل وصيغة صحيحة. قد لا يوجد مزود يوافق هذه المرشحات.

يُرسل **الوصف والمادة والصف فقط** لتأليف الدرس، لا السكريبت القديم أو صوتًا/صورة.
يُمسح المفتاح من خانته وتُلغى موافقة الإرسال عند الطلب/تغير محتواه. لا يُحفظ المفتاح
أو يدخل JSON/HTML. لا استعلام فوترة/اكتشاف خدمات أو شراء رصيد، ولا ضمان لأهلية
حساب غير ممول أو حصة/توفر مجاني دائمين. سياسات حسابك والمزوّد خارج سيطرة التطبيق.

مهلة socket 20 ثانية، وفحص حد قراءة كلي بين الأجزاء، وحجم رد محدود. قد ينتظر
الإلغاء انتهاء نداء شبكة محجوب. إعادة رسم سكريبت بعد اعتماده طلب منفصل فقط إذا
اخترته وأذنت به؛ يبقى حده القديم 12 خطوة/12000 حرف، أو استخدم الاستيراد المحلي.

**القرآن والنصوص المقدسة:** لا توسعة من وصف، ولو عبر الاستيراد اليدوي في وضع
الحماية، ولا إرسال/اقتباس مولّد أو Piper كتلاوة. الوضع القديم لعرض نص مراجع باقٍ.
لا كشف ديني تلقائي أو توثيق آيات/تجويد. **الجغرافيا:** رسوم توضيحية لا خرائط/GIS
أو حدود موثقة. لا تُعد هذه المعاينة إنجازًا لكل المناهج والمواد والأعمار.

## تشغيل محلي بلا Qt أو API

من مجلد المصدر، للمراجعة أولًا دون كتابة ملف:

```sh
python -m nova_voice.lesson_draft examples/complete-lesson-demo.json full-lesson.html
```

يعرض الوصف والسكريبت والرسوم ويرفض التصدير. بعد مراجعتها صراحة:

```sh
python -m nova_voice.lesson_draft examples/complete-lesson-demo.json full-lesson.html --approve-lesson
```

هذا CLI للاستيراد المحلي فقط؛ لا وسيطة مفتاح ولا طلب شبكة. لا يغيّر ملفات المصدر
ولا يعتمد حقائق/منهجًا بدلًا منك.

## التحقق في هذه الجولة

- **649 اختبار Python ناجحًا، وتخطي وحدتي Qt** لغياب `libGL.so.1`. تشمل اختبارات النقل القديمة والجديدة ومقاومة الرد المدفوع/الفاسد
  وعدم إعادة المحاولة، التوسيع، الربط، حفظ الأصل، الإبطال، CLI والحفظ الذري والصوت الصامت.
- **164 اختبار DOM ناجحًا**. الصوت والقياسات في JSDOM محاكاة؛
  منها 20 حالة للدرس الكامل، بما فيها رفض ارتباط خاطئ وحفظ/إعادة استيراد توقيت مقاس.
- **36 فحص Chromium 153.0.8010.0** على 360/768/1366px: حدود تسميات SVG وعدم تصادم
  تسميات المثال، المراحل عند بداية سطرها، الإيقاف/السرعة، سؤال وإجابة منفصلان، الخلاصة،
  تقليل الحركة، تنزيل Blob فعلي أثناء المسح ثم Python وإعادة الفتح offline. اختُبر
  أيضًا فك WAV الصامت والتقديم/الترجيع عند 0.5×/1×/2× وحفظ توقيته وإعادة فتحه.
  صفر أخطاء صفحة/console وصفر طلبات HTTP خارجية، **لا صوت بشري أو استدلال AI**.
- Ruff وcompileall وJS syntax و`git diff --check`، مع بقاء ملفات ERP والترجمة/Workflows
  والنموذج التجريبي 1602 بايت والأرشيفات المنشورة دون تغيير.

لإعادة الاختبارات: `python -m pytest tests -q -rs`، ثم `npm ci --ignore-scripts` و`npm test`
داخل `web-tests`. الفحص الحقيقي الاختياري في `web-tests/browser-full-lesson.cjs` يحتاج
أدوات تطوير ومتصفحًا مثبتين مسبقًا؛ انظر README في مجلده. لا يثبّتان للتشغيل العادي.

**قبل الاعتماد اليومي:** يلزم اختبار واجهة Windows، مراجعة درس حي بحساب مؤهل إن أردت
الخدمة، والاستماع إلى صوتك الحقيقي وفحص ملاءمة المنهج. لا تجعل نتائج الاختبار المحلي
اليدوي أو الصامت بديلًا عنها.
