# تثبيت Nova Voice على ويندوز — من الصفر إلى اختصار على سطح المكتب

**جديد 0.16.0.dev1.** هذه هي النسخة القابلة للتثبيت: معالج Inno Setup عادي
(Next ← أوافق ← تثبيت)، اختصارات قائمة/سطح مكتب، ومُزيل تثبيت من «الإعدادات ←
التطبيقات» — **دون صلاحيات مسؤول (UAC) ودون إنترنت بعد التثبيت**. كل شيء يعمل
محليًا؛ Azure اختياري بموافقتك لكل عملية فقط.

> ملاحظة صريحة: ملف `NovaVoice-Setup-v0.16.0.dev1.exe` يُبنى على جهاز ويندوز لديك
> بأمر واحد، لا على سيرفر ولا بهذه الحزمة كما هي. بناء Windows لا يُنجَز على Linux.

## حجم الحزمة

اعتبارًا من 0.16 يشمل المحرك Chromium المضمّن (QtWebEngine) لأن زر «تحويل إلى فيديو»
في «مكتبة المنهج» يسجل السبورة داخل النظام دون متصفح خارجي — يزداد حجم `dist` وملف
Setup تقريبًا بـ200–250 ميجابايت مقارنة بما قبل. لا حاجة لأي تحميل إضافي عند البناء.

## ما تحتاجه مرة واحدة

1. **ويندوز 10/11 بمعمارية x64**.
2. **Python 3.11 أو 3.12 أو 3.13 (64-bit)** مع Python launcher (الخيارات المعتمدة:
   [python.org/downloads](https://www.python.org/downloads/windows/)). يكفي التأكيد
   على «Add the Python launcher» أثناء التثبيت.
3. **اتصال إنترنت مرة واحدة** للبناء فقط (لتنزيل الاعتماديات والبناء)، أو مجلد
   `wheelhouse` جاهز لو بناء دون إنترنت (نفس خاصية Setup-Windows.bat).
4. **Inno Setup 6** اختياري لكنه مطلوب للنسخة المثبتة (بدون يظل عندك التطبيق المحمول):
   `winget install --id JRSoftware.InnoSetup -e` أو من jrsoftware.org.

## من الحزمة إلى ملف التثبيت — ثلاث خطوات

1. فك **NovaVoice-Source-v0.16.0.dev1.rar** في مجلد، مثلًا
   `D:\NovaVoice-Setup\`. فك المجلد كاملًا؛ التطبيق يبحث عن ملفاته بجانبه.
2. انقر مزدوجًا **`Setup-Windows.bat`** — ينشئ البيئة ويثبت الاعتماديات (إنترنت
   مرة واحدة إن لم يوجد wheelhouse).
3. انقر مزدوجًا **`Build-Windows.bat`** — يشغّل الاختبارات ثم بناء PyInstaller،
   ثم — إن وُجد Inno Setup — يبني تلقائيًا:

```text
dist\NovaVoice\NovaVoice.exe            ← التطبيق المحمول (يعمل فورًا)
dist\NovaVoice-Setup-v0.16.0.dev1.exe   ← ملف التثبيت القابل للمشاركة
```

إن لم يكن Inno Setup مثبتًا، يخبرك البناء بذلك ويتركْ `dist\NovaVoice` كاملًا —
انسخه أين تشاء وأضف اختصار `NovaVoice.exe` يدويًا.

## ماذا يفعل المثبت؟

- يثبّت لكل مستخدم في `%LOCALAPPDATA%\Programs\Nova Voice` (بلا مسؤول، بلا وصول
  إلى ملفات النظام).
- اختصارات: قائمة ابدأ (Nova Voice، دليل التشغيل، مكتبة المنهج، دليل «استدلال»)،
  ومهمة اختيارية لاختصار سطح المكتب.
- يعرض رخصة GPL-3.0 قبل التثبيت، ويُنشئ مُزيل تثبيت باسم «Nova Voice 0.16.0.dev1».

## بياناتك لا تُلمس عند التثبيت أو الإزالة

المثبت يملك مجلد التطبيق فقط. **أصواتك، إعداداتك، ومكتبة المنهج** تعيش في
`%LOCALAPPDATA%\NovaVoice` — لا يُحذف شيء منها عند التحديث أو إزالة التثبيت.
لحذفها نهائيًا احذف ذلك المجلد يدويًا بعد إلغاء التثبيت (انتبه: فيه نماذج الأصوات
والدروس المحفوظة في مكتبتك).

## أول تشغيل

1. شغّل **Download-Arabic-Voice.bat** و/أو **Download-English-Voice.bat** مرة
   واحدة لجلب نموذج صوتي، أو انقل ملفات `.onnx` من USB وأدرجها من «إضافة نموذج».
2. افتح Nova Voice ← تبويب **«النص والأصوات»** ← مثال → توليد. الكريم/Piper المحلي
   هو الافتراضي دائمًا؛ Azure اختياري من «النص والأصوات ← 2 · اختر الأصوات ←
   Azure Speech · سحابي بإذن لكل عملية» (المفتاح لا يُطلب في أي مكان خارج التطبيق).
3. بعد أي تصدير مكتمل ستجد **«مكتبة المنهج»** تعرض الفهرس لحفظه بالدولة/المرحلة/
   الصف/السنة/المادة/الترم — انظر [LESSON-LIBRARY-AR.md](LESSON-LIBRARY-AR.md).

## ملاحظات مهمة

- **SmartScreen:** ملف Setup غير موقّع رقميًا (لا شهادة توقيع لدينا)، لذا قد ترى
  «Windows protected your PC». للتحقق: طابِق SHA-256 في
  `deliverables/nova-voice/SHA256SUMS.txt` مع الملف، ثم More info ← Run anyway.
  لا تنزّل المثبت من أي مصدر آخر.
- **الصوت:** النماذج لا تُضمَّن في الحزمة المصدرية ولا في المثبت افتراضيًا؛
  `Download-*-Voice.bat` يجلب النموذج من مصدر Piper بترخيصه؛ راجع MODEL_CARD
  والإشعارات قبل إعادة التوزيع، لا تغيّر اسم النموذج.
- **البناء دخانٌ فقط دون إنترنت:** استخدم wheelhouse إن لم تتوفر الشبكة للبناء.
- **حد الأجهزة:** اهدف إلى 4GB RAM؛ Piper يعمل على CPU. لا وعود أداء على كل جهاز.
- **PR2 مفتوح بلا دمج؛ هذا البناء محلي على جهازك** ولا يُنشأ Release أو Actions.

## استكشاف سريع

- «Please run Setup-Windows.bat first» ← شغّل `Setup-Windows.bat` أولًا ثم أعد البناء.
- فشل pip ← تحقق من الإنترنت أو جهّز `wheelhouse`؛ ثم أعد المحاولة.
- `pytest` فشل ← راجع الخطأ؛ على ويندوز يجب أن تعمل اختبارات Qt (توجد PySide6).
- Inno غير موجود ← `winget install --id JRSoftware.InnoSetup -e` ثم أعد البناء،
  أو انقر مزدوجًا `installer\NovaVoice.iss` بعد فتحه في Inno Setup.
- التطبيق لا يُقلع ← تأكد أنك تنسخ/تثبت **المجلد كاملًا** (لا EXE فقط)، وأن
  `_internal` بجانبه.
