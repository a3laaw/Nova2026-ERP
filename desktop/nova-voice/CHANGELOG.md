# سجل التغييرات

## 0.7.0.dev1 — معاينة مصدر لدرس كامل مرسوم · 2026-11-07

- مرحلة تأليف مستقلة من وصف قصير إلى أهداف و2–8 مراحل مرسومة وأسئلة وإجابات منفصلة
  وخلاصة؛ طلب مجاني واحد بموافقة المُعدّ البالغ، أو توجيه/استيراد محلي دون مفتاح.
  لا اختيار قوالب مواد أو تحويل السكريبت القديم بصمت إلى نص آخر.
- وصف حرفي غير منطوق وحزمة immutable ببصمة، مع محرر رد JSON خام للتعديل المتعمد
  وإعادة بناء البصمات محليًا. لا حفظ لمفاتيح/موافقة أو اعتماد تلقائي عند وصول الرد.
- قسم مراجعة/معاينة صامتة، ثم تأكيد نقل المسودة لراوٍ واحد ثم اعتماد رسومها.
  استكمال HTML موسع محفوظ بالصوت يطلب مراجعة جديدة لمصدره المستقل، حتى لو كان معاينة مسودة.
  إبطال عند تغير الوصف/المسودة/المصدر/الوضع/الخطة/التلميحات، ومنع تجاوز الحماية
  بإلغاء الرسوم أو مسارات الصوت فقط/الاختصارات؛ فصل ارتباط صريح يعيد التحرير العادي.
- خطة رسم schema 2 مع origin إلزامي تربط الوصف وبصمة حزمة التوسيع والمصدر، مع
  إبقاء خطط schema 1 ودروس schema 1/2. إعادة الرسم تحتفظ بالأصل؛ البصمات اتساق لا توثيق.
- مثال كامل يدوي من 10 خطوات و16 سطرًا، 4 مراحل مرسومة و50 عنصرًا، وسؤالين وإجابتيهما.
  CLI محلي يرفض التصدير دون --approve-lesson، ودليل FULL-LESSON-AR.md.
- نقل مشترك محروس بلا تخفيف للسعر/الخصوصية أو محاولات إصلاح. **لا استدلال حي مجرب**.
  649 اختبار Python/تخطي وحدتي Qt، و164 DOM، و36 فحص Chromium فعليًا؛ الصوت اصطناعي صامت.
- مصدر فقط، بلا EXE/Actions/أوزان بشرية/تغييرات ERP أو تعديل الأرشيفين السابقين.
  واجهة Qt/Windows/4GB، جودة النموذج/الصوت، صحة المنهج/الخرائط/التلاوة غير مثبتة.

## 0.6.0 التجريبية — مشاهد قابلة للمراجعة · 2026-11-07

- اقتراح دلالي اختياري من السكريبت، دون اختيار قالب درس، عبر free-only OpenRouter
  أو استيراد خطة محلية. حساب المُعدّ البالغ وموافقة لكل طلب؛ لا مفتاح محفوظ أو مسار مدفوع.
- JSON محدود ومربوط بالأصل، مع مراجعة منفصلة للعرض والنطق ومعاينة صامتة واعتماد صريح.
  تعديل المصدر/الخطة يلغي الاعتماد. لا تنفيذ HTML/SVG خام أو كود أو روابط موارد.
- أشكال ومسارات ورسوم رمزية محلية، حسابات أربع محسوبة ومثلث قائم مقياسي؛
  توقيت العناصر من ساعة السطور المقاسة، مع التقديم والترجيع والممحاة وتقليل الحركة.
- schema 1 الأصلي وبصماته باقية للدرس العادي؛ schema 2 يربط الخطة والنطق والتوقيت.
  صوت الدرس المرئي يرفض خريطة غير سليمة بدل الانتقال لتقدير قد يخالف النطق.
- مثال محلي يدوي بثلاث خطوات، ودليل SMART-SCENES-AR.md، وأمر CLI للاستيراد
  لا يصدر دون --approve-scenes. لا نموذج حي مجرّب/خرائط موثقة/تلاوة معتمدة.
- لا اعتماد تشغيل جديد أو أوزان أو EXE/Actions أو تعديل ERP/الترجمة/معالجة النطق.
  Windows/4GB واستماع كريم/RP ما زالت غير مثبتة.

## 0.5.1 — مسح السبورة واختيار الإنجليزي البريطاني

- يد وممحاة SVG محليتان: مسح فعلي للكتابة بثلاث تمريرات خلال 560ms قبل تغيير الخطوة
  وبدء مقطعها. لا تعديل للصوت أو مخطط التوقيت؛ لا autoplay جديد عند التوقف/فتح الملف.
- آخر تنقل سريع يفوز، مع إبطال callbacks القديمة وتنظيف الحركة عند الحفظ/مغادرة الصفحة
  وتجاوزها مع reduced motion. عرض المظهر/الشاشة الضيقة لا يترك قناع مسح عالقًا.
- اختيار English صريح يعرض UK Alan/Cori أولًا ويحفظ US Lessac/Amy كبديل اختياري،
  مع تسميات UK/US في القوائم، دون تبديل النموذج القديم تلقائيًا أو اختيار جنس المستخدم.
- إعداد Alan الرسمي `en-gb-x-rp` يخص محوّل النطق؛ ليس إثباتًا سمعيًا لجودة RP.
  لم يُعلن إصلاح ح في كريم، ولم يضف تحويل لاتيني أو قاموس نطق أو محرك ثقيل/سحابي.
- المثالان أُعيدا بالقالب الجديد دون تغيير السكريبت/المظهر. حزمة مصدر فقط، دون Actions/EXE.
- التفاصيل والتحقق: `FINAL-RELEASE-AR.md` و`BRITISH-ENGLISH-AR.md`.

## 0.5.0 — تحديث توقيت السطور · 2026-11-07

  الفقرات وفواصل الردود، وملف/مرمّز متدفق واحد لكل خطوة؛ لا دمج ملفات سطور.

  التوزيع داخل الصف تقريبي. خريطة ناقصة/تالفة أو ملف قديم يستخدم التقدير السابق.

  وWAV أدق. مفكك الاختبار اعتماد تطوير فقط، لا تغيير لمحرك التشغيل أو نماذج الصوت.

  وواجهات `render`/`render_dialogue`. تحديث قالب النسخة الصوتية من الدرس الموثق.
- اختبارات Python وDOM ودليل يدوي عربي؛ لا بناء EXE أو GitHub Actions أو ادعاء
  باختبار Windows/متصفح حقيقي/طبيعية صوت عربي. رقم الإصدار يظل **0.5.0**.
