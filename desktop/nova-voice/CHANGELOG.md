# سجل التغييرات

## 0.5.0 — تحديث توقيت السطور · 2026-11-07

- خريطة توقيت فعلية لكل صف محفوظ في السبورة من عينات PCM بعد توحيد التردد، مع
  الفقرات وفواصل الردود، وملف/مرمّز متدفق واحد لكل خطوة؛ لا دمج ملفات سطور.
- معرّفات الصفوف قبل تقسيم TTS، وJSON بإصدار schema وبصمة مرتبطة بالدرس ومهرب بأمان.
- كتابة من `audio.currentTime` عند الإيقاف/التقديم/الترجيع وإعادة التشغيل و0.5×–2×؛
  التوزيع داخل الصف تقريبي. خريطة ناقصة/تالفة أو ملف قديم يستخدم التقدير السابق.
- قياس MP3 فعلي: 1105 عينة مع lameenc 1.9.0/miniaudio 1.72؛ لا تعويض متصفح تخميني،
  وWAV أدق. مفكك الاختبار اعتماد تطوير فقط، لا تغيير لمحرك التشغيل أو نماذج الصوت.
- الحفاظ على الألوان ومكتبة الأطفال والاتجاهات وحدود الحجم والإلغاء والحفظ الذري
  وواجهات `render`/`render_dialogue`. تحديث قالب النسخة الصوتية من الدرس الموثق.
- اختبارات Python وDOM ودليل يدوي عربي؛ لا بناء EXE أو GitHub Actions أو ادعاء
  باختبار Windows/متصفح حقيقي/طبيعية صوت عربي. رقم الإصدار يظل **0.5.0**.
