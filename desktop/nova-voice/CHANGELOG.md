# سجل التغييرات

## 0.5.0 — تنظيم الواجهات وبحث الصوت المصري · 2026-11-07

- فصل إعداد الدرس والأصوات والتخصيص والملفات المحفوظة والتصديرات الأخرى في تبويبات،
  مع بقاء التوليد والإلغاء والتقدم خارجها والنتيجة تفتح بعد النجاح.
- طي السرعة والفواصل وألوان الجملة المتقدمة دون تصفير القيم؛ كل الأزرار القديمة باقية.
- تشغيل السبورة قبل الأطفال، قائمة خطوات قابلة للطي، ومجموعات مظهر واضحة، دون تغيير
  محرك الصوت أو بيانات الدرس أو التوقيت أو مكتبة الأطفال.
- صفحة تسليم مرتبة: تحميل واحد واضح، التجهيز، المعاينة، ثم بحث الصوت المصري.
- تقرير VoiceTut/NAMAA/XTTS والتوافق والترخيص وحدود 4GB؛ بحث فقط، لا نموذج جديد.


## 0.5.0 — زر موحّد للنص والصوت · 2026-11-07

- زر **توليد السبورة بالنص والصوت معًا**: اسم حفظ واحد وHTML نهائي بالنص والصوت
  وخريطة التوقيت والتخصيصات. يستخدم المحرر الحالي والأصوات المختارة، دون HTML مسبق.
- يعيد استخدام المسار المرحلي نفسه في مجلد مؤقت يُنظّف؛ ملف/مرمّز واحد لكل خطوة،
  وخلفية وتقدم وإلغاء آمن وحماية الأصل. لا تغيير لمحرك الصوت أو متحكم HTML.
- إبقاء الزرين 1 و2 والمصدر الصامت المحدد كما هما، مع فتح الناتج النهائي فقط.
- اختبارات إضافية للتطابق مع المسار القديم، التوقيت والألوان، الإلغاء والفشل
  والتنظيف؛ اختبارات Qt مكتوبة لكنها غير منفذة هنا لتعذر تحميل libGL.so.1.


## 0.5.0 — تحديث توقيت السطور · 2026-11-07

- خريطة توقيت فعلية لكل صف محفوظ في السبورة من عينات PCM بعد توحيد التردد، مع
  الفقرات وفواصل الردود، وملف/مرمّز متدفق واحد لكل خطوة؛ لا دمج ملفات سطور.
- معرّفات الصفوف قبل تقسيم TTS، وJSON بإصدار schema وبصمة مرتبطة بالدرس ومهرب بأمان.
- كتابة من `audio.currentTime` عند الإيقاف/التقديم/الترجيع وإعادة التشغيل و0.5×–2×؛
  التوزيع داخل الصف تقريبي. خريطة ناقصة/تالفة أو ملف قديم يستخدم التقدير السابق.
- قياس MP3 فعلي: 1105 عينة مع lameenc 1.9.0/miniaudio 1.72؛ لا تعويض متصفح تخميني،
  وWAV أدق. مفكك الاختبار اعتماد تطوير فقط، لا تغيير لمحرك التشغيل أو نماذج الصوت.
- الحفاظ على الألوان ومكتبة الأطفال والاتجاهات وحدود الحجم والإلغاء والحفظ الذري
  وواجهات `render`/`render_dialogue`. تحديث قالب النسخة الصوتية من الدرس الموثق.
- اختبارات Python وDOM ودليل يدوي عربي؛ لا بناء EXE أو GitHub Actions أو ادعاء
  باختبار Windows/متصفح حقيقي/طبيعية صوت عربي. رقم الإصدار يظل **0.5.0**.
