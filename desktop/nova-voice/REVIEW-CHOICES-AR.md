# هل هذا المطلوب؟ — معاينة ثم اختيار · 0.13.0.dev1

هذه أزرار فعلية في **«مشاهد ذكية» داخل التطبيق**، أسفل المراجعة والمعاينة. تفتح المعاينة الصامتة في متصفحك كالسابق؛ ارجع للتطبيق للاختيار. ملفات HTML المستقلة تظل بلا اتصال أو مفتاح أو جسر تحكم في التطبيق. ليست هذه إضافة PDF/OCR أو بحث إنترنت مفتوح أو نموذجًا لغويًا محليًا.

## الاختيارات الثلاثة

1. **«نعم، هذا المطلوب · اعتماد بعد المراجعة»**: راجع النص والعرض والنطق ووصف الرسم والمعاينة، ثم أكد الاعتماد. لا يبدأ صوت أو تصدير عند الضغط؛ تستخدم أزرارهما المعتادة بعد ذلك.
2. **«اعمل اقتراحًا آخر»**: طلب مجاني واحد لمخطط المشاهد، من **السكريبت نفسه والخطة المرئية السابقة** وملاحظة اختيارية منك. يقترح رسومات أصلية مختلفة بدل مكتبة ملفات تختار منها. لا تغيير للنص أو الأدوار أو النطق أو المادة/الصف؛ رد يحاول تغييرها يُرفض. ثم تتحقق الخطة وتفتح معاينة صامتة جديدة بلا اعتماد تلقائي.
3. **«جرّب مصدرًا خارجيًا مجانيًا · بإذني»**: البرنامج يختار ويجهّز، **لا اختيار ملف أو معرّف أو موقع منك**. إذا كانت في الخطة موارد مقترحة غير مجهزة، ومن دون ملاحظة تغيير، يُجهّزها مباشرة من الذاكرة أو ينزّلها بإذنك؛ لا يحتاج نموذجًا لغويًا أو مفتاحًا لهذا الفرع. وإلا يطلب اقتراحًا مجانيًا واحدًا مع قائمة الرسوم المدققة، ثم يجهّز الموارد المقترحة تلقائيًا في المهمة نفسها. يستبعد الموارد المضمّنة السابقة من الاقتراح الجديد حتى لا يُعرض المورد نفسه كبديل جديد.

يمكن كتابة ملاحظة مثل «قلل التفاصيل ووضّح الأجزاء المتحركة»؛ **اختيارية** وحتى1000حرف، لا تدخل في النطق ولا تُحفظ في الإعدادات. وجود ملاحظة مع مورد غير مجهز يطلب إعادة التخطيط بدل تجاهل ملاحظتك. نجاح الرد يظل اقتراحًا، لا ضمانًا أن النتيجة أفضل أو صحيحة. إذا لم يتغير الرسم يبين ذلك ولا يسميه بديلًا جديدًا. كل محاولة تحتاج ضغطًا منك؛ لا سلسلة طلبات أو إصلاحات أو إعادة محاولة تلقائية.

## ما معنى «خارجي بدون تدخلي»؟

يعني **الاختيار والفحص والتنزيل والتجهيز آليًا بعد إذنك لهذه المحاولة**، وليس فتح ملفات ومواقع أو اختيار حيوان من كتالوج. ما زالت الحدود **16 رسمًا ثابتًا مدققًا من Game-icons**، حتى6معرّفات/24استخدامًا بالخطة، لا بحثًا حرًا عن أي صورة أو أنيميشن. لا تثبيت مكتبة/كود أو مصدر مدفوع. الصور الظلية ليست أطرافًا مفصلية أو نماذج علمية معتمدة.

إن لم يناسب شيء، لا ينزّل ملفًا ويبين أن الرسم المحلي باقٍ. فشل ملف يترك بديله الأصلي. تظل النسبة والمصدر وCC BY3.0 والتغييرات في JSON وHTML والطباعة وبطاقات الفيديو الصامتة. التفاصيل في [SECONDARY-SOURCES-AR.md](SECONDARY-SOURCES-AR.md).

## الإعداد مرة، والإذن لكل محاولة

- **الفرع الذي يحتاج فهمًا/اقتراحًا جديدًا** يحتاج حساب معلم بالغ ومفتاح OpenRouter مؤهلًا للخيار المجاني الموجود. لا تضع المفتاح في السكريبت أو الملاحظة أو الدردشة. المجانية والأهلية والحصة وتوافر مزوّد يطابق الخصوصية غير مضمونة؛ عند الرفض يتوقف بلا دفع أو تخفيف القيود.
- افتراضيًا يُمسح حقل المفتاح بعد الطلب ولا يُحتفظ به للجلسة. لتجنب إدخاله لكل بديل يمكنك اختيار **«إبقاء المفتاح في ذاكرة هذه الجلسة لتجربة البدائل»** قبل الطلب. هذا اختيار مستقل، **موقوف افتراضيًا**: في ذاكرة العملية فقط، مرتبط بالسكريبت، **30دقيقة كحد أقصى من إدخاله** لا تتجدد بمجرد استخدامه. لا ملف أو تفضيلات أو HTML أو حافظة. سلاسل Python لا تضمن محو البايتات من الذاكرة فعليًا؛ النسيان يسقط المراجع.
- **«نسيان مفتاح جلسة البدائل الآن»** أو إلغاء اختيار إبقائه أو تغيير السكريبت/المادة/الصف/السياسة أو إغلاق التطبيق يزيله من الجلسة. نسيان المفتاح لا يلغي طلبًا بدأ بالفعل؛ زر الإلغاء العام هو الذي يلغي المهمة.
- كل ضغط طلب/مصدر يعرض موافقة جديدة افتراضيها «لا». إذا احتاج المخطط تُذكر صراحةً بياناته المرسلة: النص والخطة السابقة والملاحظة إلى OpenRouter ومزوّده، بسعرصفر ومرشحات عدم التدريب/ZDR كما هي. لا مسارات المورد أو نسبته أو بياناته الخام في الطلب؛ فقط معرفات/بدائل الخطة والقائمة المقيدة.
- الإذن الخارجي يذكر **إذن تنزيل مستقل** في الموافقة نفسها؛ يشمل موارد هذه المحاولة التي يختارها المخطط، لا ملفات مجهولة أو موافقة دائمة. مصدر الرسوم يرى عنوان الاتصال وتوقيت الطلب ومعرّفات الملفات، لا السكريبت أو الملاحظة أو الصوت أو المفتاح. التنزيلات من عناوين GitHub المثبتة فقط.

## حماية المراجعة والأصل

طلب بديل يلغي الاعتماد السابق عند بدء المحاولة، دون حذف المقترح أو تغيير المحرر والأصوات. الرفض أو الإلغاء يبقيان الخطة السابقة، وقد تبقى موارد مكتملة ومدققة في الذاكرة بعد إلغاء التنزيلات. لا خطة جزئية تُعتمد. لا صوت أو تصدير تلقائي حتى عند نجاح التحويل.

النتيجة مرتبطة ببصمة السكريبت والخطة السابقة ورقم المراجعة والاختيار والملاحظة. تعديل النص/الخطة/الملاحظة أو استيراد الخطة نفسها أثناء المهمة يمنع تطبيق نتيجة قديمة. عند إعادة الرسم لدرس كامل من وصف، يبقى أصل الوصف وبصمته وكل رسوم مراحل الشرح ضمن180عقدة؛ لا فصل أو تبديل أصل بصمت.

وضع **النصوص المقدسة** يمنع الاقتراح والموارد كالسابق، ولا يتجاوزه زر خارجي. لا API أو رسوم أو إعادة صياغة أو تلاوة آلية لهذا الوضع.
