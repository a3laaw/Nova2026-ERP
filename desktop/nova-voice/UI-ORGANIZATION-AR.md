# تنظيم الواجهات والتحقق — Nova Voice 0.5.0

تحديث 7 نوفمبر 2026، بناءً على اختيار تنظيم **البرنامج والسبورة وصفحة التحميل**.
الإصدار ما زال 0.5.0؛ تنظيم الاستخدام لا يعني تحسين طبيعية الصوت أو تغيير المحرك.

## ما تغير

### برنامج Windows

- تبويبات **النص والأصوات**، **ألوان وشخصيات**، **سبورة محفوظة**، **صوت فقط / HTML**.
- زر التوليد الموحّد وفتح السبورة والإلغاء والتقدم خارج منطقة التبويبات والتمرير،
  كي لا تختفي أدوات المهمة عند الانتقال. النتيجة والاستماع قسم يفتح بعد النجاح.
- إعدادات السرعة والفواصل، وألوان الجملة المتقدمة، قابلة للطي دون تصفير قيمها.
- النص والاختيارات لا تُنقل أو تُعاد كتابتها عند تبديل التبويب. المصدر المحفوظ
  للخطوة 2 يظل منفصلًا عن المحرر الحالي؛ الزران القديمان وبقية التصديرات باقية.
- تغلق التبويبات للتحرير أثناء المهمة، والإلغاء يظل خارجها ومتاحًا.

### HTML السبورة

- التشغيل والإعادة والسابق/التالي والصوت والسرعة **قبل** شريط الأطفال.
- روابط للأقسام وتخطٍّ إلى التشغيل بلوحة المفاتيح، وقائمة خطوات قابلة للطي.
- الانتقال التلقائي في تفاصيل اختيارية؛ **لا** تخفي الصوت أو السرعة. حالة التشغيل
  وأخطاؤه تبقى ظاهرة خارج التفاصيل، فلا تختفي رسالة تعذّر تشغيل الصوت.
- ترتيب اللغتين، الألوان، والأطفال في ثلاث مجموعات مسماة. النص المقروء في قسم مستقل.
- لم تتغير هندسة الكتابة أو محاذاة اللغتين أو توقيت الصوت أو وسوم الحوار أو
  الشخصيات الست. أُعيد توليد ملفّي HTML التجريبيين من الدرس والمظهر نفسيهما؛
  ملف `greetings-lesson.txt` وسكريبت المستخدم لم يُعدلا.

### صفحة التحميل

- تحميل RAR أساسي واحد، مع توضيح أنه **مصدر وليس EXE**.
- تجهيز في أربع خطوات، معاينة بلا صوت، بحث الصوت المصري، وأسئلة قابلة للطي.
- RTL وشاشات ضيقة، دون خطوط أو صور أو JavaScript خارجي. الروابط للمصادر
  والعينات لا تُفتح تلقائيًا، وليست نماذج مثبتة أو خدمة مضافة إلى التطبيق.
- أضيف **تقرير الصوت المصري فقط** إلى قائمة ملفات خادم التسليم العامة؛ لا فتح
  لشجرة المصدر أو `.git` أو قوائم المجلدات. أُعيد تشغيل الخادم نفسه على 8766
  لتحديث قائمة السماح، دون خادم ثانٍ.

## ما لم يتغير

`engine.py` و`whiteboard.py` و`timing.py` ومتحكمات JavaScript والكاتب المتدفق
والحفظ الذري والإلغاء وحدود 25MiB/256MiB كلها باقية. لا تحويل إلى ملفات لكل سطر،
ولا تغيير لـPCM clock أو تعويض MP3، ولا ترجمة أو تأليف نص أو إجابات تمارين.
لا نماذج مصرية أو PyTorch أو GGUF أو خدمة سحابية أو اعتماد تشغيل ثقيل جديد.
ملفات ERP وملف اللغة المقفل غير معدلة. تعديل `.spec` لإدراج الأدلة فقط؛ لم يُبنَ EXE.

## نتائج الاختبارات المنفذة

- الأساس قبل التعديل: **387 pytest للتطبيق / تجاوز ملف Qt واحد، و77 DOM**.
- بعد التعديل: **387 pytest للتطبيق + 14 للتحميل والخادم = 401 ناجح**، مع تجاوز
  ملف Qt نفسه: `libGL.so.1: cannot open shared object file`.
- **81 DOM ناجح**: الأربع الجديدة تتحقق من الأقسام والروابط والمعرفات الفريدة،
  ترتيب التشغيل قبل الأطفال، طي القائمة دون تغيير الخطوة، بقاء الصوت والسرعة
  خارج الإعدادات الاختيارية، ومجموعات المظهر دون تغيير بيانات الدرس.
- **4 اختبارات Qt جديدة مكتوبة لكن غير منفذة هنا**: أبوة التبويبات وبقاء الإلغاء
  خارجها، حفظ القيم والتنقل، حالة العمل، وفتح النتيجة دون تغيير المحرر.
- لم تُحذف أو تُضعف assertions قديمة. في اختبار إلغاء Qt السابق للزر الموحّد
  أُنشئ `QSignalSpy` قبل الإلغاء مع فحص الإشارة المسجلة قبل الانتظار، لمنع سباق
  اكتمال المهمة؛ شرط اكتمالها وإعادة تفعيل الزرين لم يتغير. الاختبار الجديد يفعل
  الشيء نفسه. امتدت قائمة مستندات fixture الخادم لتشمل البحث الجديد. بقيت اختبارات تطابق الأمثلة بالقالب الحالي
  كما هي؛ تجديد HTML التجريبي ليس تغييرًا للنص أو شروط الاختبارات.
- Ruff lint/format ناجح؛ 43 ملف Python داخل التطبيق، و3 ملفات الخادم واختباراته.
  فحص صياغة JavaScript ناجح.

## فحص متصفح حقيقي — ليس Windows أو استماعًا

شُغّل **Chromium 153.0.8010.0 headless على Linux** لأغراض التطوير فقط:

1. صفحة التحميل والسبورة عند عروض **360 و768 و1366px**: 6 حالات صفحة/مقاس، دون
   تجاوز عرض الصفحة. الروابط المحلية تعمل، وتحميل أساسي واحد، وفتح التفاصيل بـEnter.
2. أولوية أدوات التشغيل، طي الخطوات، فتح تخصيص المظهر بلوحة المفاتيح، مرشح البنات
   ومجموعات الإعدادات، وعدم تجاوز العرض حتى بعد فتح التخصيص.
3. HTML محلي مستقل، مع الشبكة مفصولة، بصوت **WAV فعلي من نموذج الاختبار الصامت**:
   قراءة مدة الصوت وتشغيل/إيقاف و0.5× والتقديم وفتح التفاصيل دون تصفير الموضع والإعادة.
4. لم تُسجل أخطاء JavaScript أو طلبات موارد خارجية من الصفحتين.

Chromium وخط Noto العربي المستخدم في بيئة الفحص أدوات تطوير مؤقتة، **غير موجودة
في الحزمة أو متطلبات التشغيل**. تُستخدم خطوط النظام المعتادة في HTML. أُخذت
لقطات للفحص الداخلي؛ لا يعني ذلك اختبار نافذة Windows أو كل متصفحات المستخدم.
لا اختبار جديد لتشذيب MP3 في المتصفح أو لمواءمة كلمة بكلمة أو استماع بصوت مدرّب.

## بحث الصوت المصري

التفاصيل والمصادر في [EGYPTIAN-VOICES-AR.md](EGYPTIAN-VOICES-AR.md): VoiceTut وNAMAA
مرشحان لمحرك آخر، وXTTS المفحوص مقيّد بالبحث. لم يُنزّل نموذج أو يُرسل نص المستخدم
إلى تجربة مستضافة. لا ضمان جودة أو RAM 4GB، ولا استبدال مصري بصوت أردني/إماراتي.

## تجربة يدوية مطلوبة على Windows

1. فك الحزمة المحدّثة كاملة وافتح `Run-Windows.bat` بعد التجهيز.
2. جرّب التبويبات الأربعة؛ تحقق من عدم فقد النص أو اختيار الصوتين أو الألوان.
3. افتح إعدادات السرعة والفواصل، غيّرها، أغلِقها وافتحها؛ يجب بقاء القيم.
4. افتح مثال التحيات دون إعادة كتابته؛ اختر 1 عربي و2 إنجليزي وWAV ثم الزر الموحّد.
   يجب ظهور مربع اسم واحد وHTML واحد، وفتح النتيجة تلقائيًا كقسم داخل البرنامج.
5. في الصفحة افتح/اطوِ الخطوات والمظهر والإعدادات، وجرّب السرعة والتقديم والإيقاف؛
   لا قفز للصوت عند مجرد طي قسم. التخصيص يظل قابلًا للحفظ وإعادة الفتح.
6. جرّب الخطوتين 1 و2، والصوت فقط وHTML الخارجي، ثم الإلغاء أثناء عمل طويل والتأكد
   من بقاء النتيجة السابقة والأصل؛ الإلغاء متاح دون الرجوع إلى تبويب آخر.
7. جرّب مقاس نافذة صغيرًا وشاشة 1366×768 قبل اعتماد توزيع البرنامج على جهازك.

لم تُنفذ هذه الخطوات بواجهة Windows أو أصوات بشرية هنا. لا GitHub Actions أو EXE،
ولا اختبار أداء أو استماع على جهاز 4GB. لا يُنسب تغيير جودة العربية إلى التنظيم.
