# المشاهد الذكية — Nova Voice 0.6.0 التجريبية

**تاريخ هذه المراجعة: 7 نوفمبر 2026.** هذه أول شريحة تنفيذية، وليست نظامًا مثبتًا
لفهم جميع المناهج أو توثيق الخرائط والقرآن. لا تحتاج اختيار قالب تفاح/خريطة/مثلث
لكل درس: يقرأ النموذج السكريبت ويقترح تركيب الأشكال والمسارات والتسميات بحرية
داخل صيغة بيانات محدودة، ثم يرسمها البرنامج محليًا.

## ما نُفّذ

- سكريبت أصلي محفوظ، مع مادة وصف/عمر **اختياريين بالنص الحر**، بما فيهما الإعدادي.
- اقتراح شبكي اختياري → **مسودة JSON** → تحقق → مراجعة الفروقات والمعاينة → اعتماد.
- رسم SVG محلي: مستطيل ودائرة وقطع ناقص وخط وسهم ومضلعات ومسارات حرة وتسميات،
  وعشرة رموز متجهية أصلية قابلة للعد؛ ليست قائمة قوالب دروس يختارها المعلم.
- عنصر حساب للعمليات الأربع على أعداد صحيحة محدودة، بنتيجة محسوبة محليًا
  والقسمة ككسر مبسط؛ لا `eval` ولا نتيجة رقمية يُمليها النموذج على هذا العنصر.
- مثلث **قائم فقط** بضلعي طول صحيحين، بنسبة طول موحدة وعلامة زاوية قائمة.
  المضلعات والمسارات الأخرى توضيحية وليست حلّال هندسة عامًّا.
- تغيير اختياري مقترح لكل سطر: **العرض** مستقل عن **النطق**، مع إظهار الأصل
  والدور والفروقات للمعلم. مثلًا يظهر `2` بينما ينطق «لدينا تفاحتان».
- الرسوم تدخل عند بداية سطرها، ويمكن أن تتحرك من إزاحة `dx/dy` أو تختفي قبل
  سطر لاحق بـ`until`. الصوت المقاس هو الساعة، لا مؤقت مستقل أو فيديو مولّد.
- الإيقاف والتقديم والترجيع والسرعة والمسح وإعادة الخطوة والحفظ بالتخصيصات تعمل
  مع الرسم. تقليل الحركة يلغي انتقال الأجسام، ولا يكشف أجوبة السطور المستقبلية.
- HTML نهائي مستقل، بلا مفتاح أو طلبات تخطيط/صور/خطوط خارجية أثناء عرضه.

**هذا لا يثبت صحة السرد أو التدريس أو النطق.** الحساب المحلي يتحقق من مدخلات
عنصره فقط؛ لا يثبت توافق إجابة مكتوبة بحرية في التسمية أو الصوت مع المسألة.
راجع الفروقات والرسم. ولا توجد هنا نتيجة استدعاء حي تثبت جودة نموذج مجاني معيّن.

## جرّب دون حساب أو اتصال

1. افتح **النص والأصوات**، ثم قسم **مشاهد ذكية** الاختياري أسفل المحرر والأصوات.
2. اضغط **مثال رسوم محلي**. سيطلب الاستبدال إن كان لديك نص. المثال **مكتوب يدويًا
   لاختبار المحرك**، وليس نتيجة ذكاء اصطناعي حي؛ ينشئ ثلاث خطوات: جمع ومثلث وطبيعة.
3. استخدم **تحقق واعرض الفروقات** و**معاينة الرسم بلا صوت**. المعاينة HTML مؤقتة
   محلية، وتشغيلها يحرك الرسم والكتابة افتراضيًا دون صوت. لا تعتمد الخطة تلقائيًا.
4. بعد المراجعة اضغط **راجعت الخطة والنطق · اعتماد للتصدير**، وأكد السؤال.
5. **1. توليد السبورة HTML** ينشئ نسخة نهائية بلا نموذج صوتي. أو اختر أصوات Piper
   المناسبة واضغط **توليد السبورة بالنص والصوت معًا**، كما في النسخة السابقة.

[معاينة المثال الجاهز](examples/visual-scenes.html) ·
[السكريبت](examples/visual-scenes.txt) · [الخطة](examples/visual-scenes.json).
الرسوم الطبيعية توضيحية غير مقياسية، ولا تمثل خريطة مكان حقيقي.

## سكريبتك أنت، مع اقتراح مجاني اختياري

1. الصق السكريبت؛ عناوين `#` و`##` اختيارية للتنظيم، والوسوم للأدوار كما كانت.
   تقسيم النص الحالي إلى خطوات/سطور يبقى مصدر المعرّفات؛ النموذج لا يغيّرها.
2. المادة والصف اختياريان، وليسا اختيار قالب. اكتب مثلًا «جغرافيا، أول إعدادي»
   أو اتركهما ليُستنتج المحتوى. ليس هناك ضمان تطابق منهج أو مستوى تعليمي.
3. افتح **اقتراح عبر الإنترنت** واقرأ ما سيُرسل، وشروط الحساب والمزوّد والبلد.
   هذا القسم للمُعدّ **البالغ 18+**، لا لطلب حساب/مفتاح من طالب.
4. استخدم حسابك ومفتاحك من OpenRouter **داخل خانة البرنامج السرية فقط**؛ لا ترسلهما
   في المحادثة ولا تلصقهما في السكريبت. المفتاح يُمسح من الخانة عند أخذ طلبه،
   ويظل في ذاكرة عملية الشبكة لحين انتهائها؛ لا يُحفظ في الإعدادات/السجل/الخطة/HTML.
5. أكد الأهلية، ثم وافق على إرسال **هذا الدرس الآن**. تعديل المصدر/الوضع أو
   معلومات الطلب يمسح موافقة الإرسال، وكل طلب يستهلك موافقته. لا إرسال في الخلفية.
6. اضغط **اقتراح مشاهد · طلب مجاني واحد**. النجاح يعرض مسودة فقط؛ افحص واعتمد
   بنفسك. الخطأ/الحصة/عدم صلاحية JSON يوقف العملية؛ لا إصلاح أو محاولة جديدة تلقائية.

**ما يُرسل:** السكريبت الأصلي، تقسيمه ومعرّفاته، المادة والصف، وتعليمات الصيغة.
لا تُرسل أصوات أو ملفات أخرى. لا تُدخل أسماء الطلاب أو معلومات شخصية/سرية.
البرنامج لا يستطيع معرفة جميع البيانات الحساسة تلقائيًا. النموذج لا يرى مفتاح
الحساب داخل التوجيه؛ المصادقة في رأس HTTPS فقط.

### معنى «مجاني فقط» هنا

- نقطة HTTPS ثابتة: `https://openrouter.ai/api/v1/chat/completions`؛ النموذج ثابت
  **`openrouter/free`**، لا `auto` أو نموذج مدفوع ولا قائمة بدائل مدفوعة.
- طلب واحد، دون إعادة محاولات، أو إعادة توجيه HTTP تحمل المفتاح، أو SDK/إضافات
  بحث/صور/أدوات. لا شحن حساب أو تسجيله أو تعديل إعدادات الفوترة بواسطة البرنامج.
- مرشحات `max_price` للإدخال والإخراج والطلب = **صفر**؛ مع منع fallback، وطلب
  دعم المعلمات و`data_collection=deny` و`zdr=true`. إذا لم يوجد مزود مجاني يوافقها،
  يفشل الطلب **دون تخفيف الخصوصية أو السعر**. لذلك قد لا تتوفر خدمة لهذا الحساب.
- لا يُستخدم الرد إلا إذا ذكر نموذجًا مجانيًا وتكلفة استعمال صفرية، وردًا مكتملًا
  وخطة صحيحة مرتبطة بالنص. هذا تحقق لاحق إضافي، وليس قدرة على إلغاء فاتورة المزود.
- الحصة والتوفر والشروط قد تتغير. لا وعد بمجانية دائمة أو غير محدودة، ولا شراء
  أرصدة لزيادة الحصة. اترك حسابك بلا وسيلة دفع/إعادة شحن تلقائي إن لم ترغب بدفع.
  سياسات الحساب والفوترة لدى المزود خارج سيطرة التطبيق؛ راجعها قبل إدخال مفتاحه.
- مرشحات المزود لا تعني ضمانًا قانونيًا أو عدم تسجيل بيانات اتصال/حساب لدى الوسيط؛
  راجع خصوصية OpenRouter وإعدادات تسجيل التوجيهات وسياسات مزودي النماذج أيضًا.
  توثيق المجاني يختلف عن الشروط العامة التي تتناول أيضًا الحسابات المدفوعة.

حد الطلب الشبكي الأول **12000 حرف و12 خطوة**؛ عند تجاوزهما قسّم الدرس أو استخدم
الاستيراد المحلي. مهلة socket عشرون ثانية، وحد قراءة كلي مفحوص بين أجزاء الرد،
وحجم رد محدود. قد ينتظر الإلغاء انتهاء عملية الشبكة المحجوبة؛ لا محاولة أخرى بعدها.

**لم يُجرَ هنا طلب استدلال حقيقي** أو إنشاء حساب أو استخدام مفتاح، ولا اختبار إتاحة
في الكويت/مصر أو ضمان قبول شروط المزود لهذا الاستخدام. اختبارات النقل كلها محاكاة.

## الاستيراد اليدوي دون API

**نسخ توجيه لخدمة تختارها** ينسخ التعليمات والسكريبت إلى الحافظة فقط. لا يرسل شيئًا؛
لصقه في خدمة أخرى قرارك وتابع لشروطها. يمكن استخدام محادثة مجانية تسمح بذلك، ثم
استيراد JSON الناتج أو لصقه في محرر الخطة. مجانية المحادثة ليست API مجانية.

**استيراد خطة JSON** و**حفظ خطة JSON** لا يحتاجان إنترنت. الخطة مرتبطة ببصمة
النص والوضع والتقسيم؛ لا تُطبّق على سكريبت آخر بالتخمين. تُحفظ ذريًا ولا تحفظ
موافقة الإرسال أو الاعتماد؛ إعادة استيرادها تصبح مسودة تحتاج اعتمادًا جديدًا.

للمطور أو الاستخدام المحلي دون Qt:

```sh
python -m nova_voice.whiteboard examples/visual-scenes.txt demo.html --scene-plan examples/visual-scenes.json
```

يعرض المراجعة ويخرج دون كتابة HTML. بعد مراجعة الخطة/معاينتها واعتمادها صراحة:

```sh
python -m nova_voice.whiteboard examples/visual-scenes.txt demo.html --scene-plan examples/visual-scenes.json --approve-scenes
```

لا مسار شبكي أو وسيطة مفتاح سرّي في هذا الأمر؛ لا تضع مفتاحًا في أوامر shell.

## الاعتماد وما يبقى من النسخة القديمة

- استيراد أو اقتراح الخطة **لا يعتمدها**. تبقى أزرار تصدير السبورة غير متاحة
  عندما يكون «تضمين المشاهد» مفعّلًا ومسودتها غير معتمدة/متقادمة.
- تعديل النص أو وضع الأصوات أو JSON أو سياسة حماية النص يلغي الاعتماد. إلغاء
  اختيار **تضمين المشاهد** يعيد التصدير التقليدي بوضوح، دون حذف الأصل أو الخطة.
- الألوان والشخصيات والصوتان والمسار الموحّد والمسار ذو الخطوتين باقية. الخطوة 2
  تستخدم بيانات الأصل الصامت المحفوظ، بما فيها النطق المعتمد، لا نص المحرر الحالي.
- **الصوت فقط/إضافة صوت إلى HTML عام** لا يستخدمان هذه الخطة؛ مصدرهما القديم باقٍ.
- لا خطة: **schema 1 وبصماتها القديمة كما كانت**. مع خطة: schema 2 يحتفظ بالأصل
  حرفيًا ويضم الخطة، وبصمته الكاملة تربط توقيت الصوت بها. ليست البصمة توقيع مصدر
  أو شهادة أن بشرًا وثّق الحقيقة؛ إنها تحقق اتساق/كشف تغيير غير متسق.
- لا تبديل للصوت أو تعديل لعلاج ح في كريم أو ضمان RP، ولا إثبات Windows/4GB أو
  اختبار استماع. داخل سطر النطق ما زال التوزيع تقريبيًا، وتأخير MP3 السابق باقٍ.

## صيغة البيانات وحدود الأمان

انظر [الخطة الصغيرة المرفقة](examples/visual-scenes.json) للتطبيق الكامل. يبدأ
ترقيم الخطوات والسطور من **صفر**. كل خطة تحتوي `schema`, `source_fingerprint`,
`subject`, `grade`, `policy`, `notes`, `steps`. لكل خطوة `index`, `description`,
`rows`, `elements`. تغييرات السطر تحتوي فقط `index`, `display`, `speech`.

الأشكال لا تحمل SVG/HTML خامًّا: النوع والموضع واللون والقياسات وبيانات مسار محدودة
فقط. النص يُرسم بـ`textContent`، ولا يُعامل كـHTML. لا `href` أو صور وروابط موارد
أو `onclick` أو كود أو SMIL. الأرقام البنيوية **integers** لتوافق بصمات Python/JS؛
كسور المسار مسموحة داخل نص `d` المحدود. العمليات محصورة في أربع دوال، لا تفسير كود.

الحدود: خطة 512 KiB، 600 عنصر إجمالًا و60/خطوة، مساحة رسم 1000×420، حتى 20 رمزًا
في مجموعة، نص عرض 180 حرفًا ونطق 480/سطر، دون سطر نطق صامت أو تغيير متحدث. يُرفض
JSON المكرر/غير المنتهي في الاستيراد. الـ120 خطوة و6 سطور/خطوة وحدود الدرس القديمة
مستمرة؛ حد الشبكة الأصغر منفصل. المعاينة البشرية ضرورية لاكتشاف التصادم أو الخطأ.

المتصفح يتحقق من الخطة والارتباط والبصمة. درس مرئي بصوت يحتاج خريطة توقيت مقاسة
سليمة؛ لا يعود بصمت إلى توقيت تخميني قد ينطق نصًا مغايرًا. العبث بخطة/خريطة غير
متسقة يمنع تشغيله، مع عرض رسالة والنص، لا تنفيذ بياناته ككود.

## القرآن والجغرافيا والمراحل التالية

**النصوص المقدسة** وضع حماية محلي: لا إرسال API، لا رسوم أو إعادة صياغة سطور،
ولا توليد Piper كتلاوة. وصف الخطوة يبقى عنوان المصدر، بلا تعليق ديني مولّد.
اختيار الحماية يوقف التوليد الصوتي الآلي في الواجهة، حتى «صوت فقط»؛ ولا يقبل العارض
تسجيلًا مضافًا لهذا النوع. يعرض نص المعلم كما هو؛ ليس مصدر آيات موثّقًا.
لا يوجد بعد إدخال تلاوة بشرية موثقة أو تجويد/مصاحف مراجَعة. لا تستخدم هذه النسخة
لتوثيق نص ديني أو أحكامه، ولا يُعد هذا إنجازًا كاملًا لمطلب القرآن.

الجغرافيا حاليًا رسوم طبيعية/مسارات توضيحية. لا مصدر حدود جغرافية موثّق أو GIS
أو إسقاط خرائطي أو قبول سياسي للحدود. الرسوم الحرة لا تثبت دقة خريطة أو تجربة علمية.

التوسعة التالية تحتاج مصادر علمية ومصحفية/تلاوة معتمدة، وإخراجًا آليًا أدق لتجنب
التصادم، وتقسيمًا دلاليًا أوسع من صفوف المصدر، واختبار نماذج حقيقيًا بحساب مؤهل
واختبار Windows وذاكرة 4GB. لا تُقدَّم كميزات منجزة الآن.
