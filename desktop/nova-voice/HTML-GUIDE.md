# ملف HTML + السكريبت ← صفحة بصوت وتحكم في السرعة

الميزة في **Nova Voice 0.3** تعمل داخل تطبيق Windows دون رفع النص أو HTML إلى خادم.
تختار ملف HTML من جهازك، وتدخل السكريبت، وتختار الراوي أو صوتي الحوار. ينشئ البرنامج
**نسخة HTML جديدة فيها الصوت مضمّنًا**، ولا يغيّر الملف الأصلي.

## الاستخدام

1. افتح البرنامج، وأدخل السكريبت في محرر النص.
2. اختر **راوٍ واحد** أو **حوار بين صوتين**، واضبط النماذج ولغات المتحدثين.
3. من قسم **أضف الصوت إلى ملف HTML** اضغط **اختيار ملف HTML**.
4. اختر صفحة `.html` أو `.htm` موثوقة من جهازك.
5. اختر صيغة الصوت؛ **MP3 موصى به** لتقليل حجم الصفحة. WAV متاح أيضًا.
6. اضغط **توليد صفحة HTML بالصوت**، واحفظ النسخة باسم جديد، مثل `lesson-with-voice.html`.
7. يفضّل حفظها **بجانب الملف الأصلي** حتى تبقى روابط الصور وملفات CSS/JS النسبية صحيحة.
8. بعد اكتمال الحفظ اضغط **فتح صفحة HTML الناتجة**، ثم شغّل الصوت بنفسك في المتصفح.

يوجد مثال خفيف في [`examples/animated-page.html`](examples/animated-page.html).
يمكن استخدامه مع أي سكريبت، أو مع [`examples/bilingual-dialogue.txt`](examples/bilingual-dialogue.txt)
بعد تجهيز نموذجي العربية والإنجليزية. صفحة المثال الأصلية لا تحتوي صوتًا تجريبيًا
أو نموذجًا حقيقيًا؛ الصوت يُولَّد عند التصدير.

## تقليل السرعة

داخل النسخة المصدّرة تظهر لوحة صغيرة قابلة للتصغير:

- مشغّل صوت أصلي من المتصفح، فيه تشغيل/إيقاف وتقديم وتحكم بالصوت.
- شريط سرعة **0.5× إلى 2×** وزر **1×** للعودة إلى السرعة الطبيعية.
- يحاول المتصفح الحفاظ على طبقة الصوت عند تغيير سرعة الاستماع.
- خيار **طبّق السرعة نفسها على حركات الصفحة** (مفعّل افتراضيًا).
- خيار **اربط إيقاف/تشغيل الحركات بالصوت أيضًا** (اختياري، غير مفعّل افتراضيًا).
- مؤشر يوضح عدد الحركات المتاحة للتحكم، أو يبيّن عدم وجود حركة مدعومة.

خفض السرعة إلى 0.5× يجعل الاستماع أبطأ، ومع تفعيل ربط السرعة تتباطأ حركات الصفحة
المدعومة بالنسبة نفسها. عند تعطيل التحكم بالحركات تعود سرعاتها الأصلية. لا تُستأنف
الحركات التي أوقفها مؤلف الصفحة أصلًا؛ الربط يستأنف فقط الحركات التي أوقفتها اللوحة.

**سرعة التوليد** في تطبيق Windows تُطبَّق عند صنع الصوت، أما سرعة لوحة HTML فهي
**سرعة الاستماع** ويمكن تعديلها لاحقًا دون إعادة التوليد. تتضاعف النسبتان: صوت مُولَّد
بسرعة 0.8× ثم مُشغَّل بــ0.5× يُسمع بسرعة تقارب 0.4× من السرعة الأصلية.

## ما الذي يمكن التحكم به في HTML؟

يتحكم المصدّر بالحركات التي تعرضها `document.getAnimations()` في المتصفحات الحديثة:
**CSS Animations وCSS Transitions وWeb Animations API**. يحفظ سرعة كل حركة الأصلية
ويطبّق معامل السرعة عليها، بدل تغيير مدة الحركة في ملفاتك أو تعديل المؤقتات العامة.
تُكتشف الحركات الجديدة أثناء بقاء الصفحة مفتوحة.

لا يمكن ضمان التحكم العام تلقائيًا في:

- مؤقتات JavaScript الخاصة مثل `setTimeout` و`setInterval` أو حلقات الرسم المخصصة.
- رسوم Canvas، مكتبات العرض ذات خط زمني خاص، فيديوهات الصفحة، أو صفحات iframe.
- صفحات تعيد كتابة المستند كله بعد التحميل أو تعيد بناء اللوحة نفسها.
- مطابقة جمل السكريبت مع الشرائح والمشاهد أو تمييز الجملة المنطوقة.

هذه الحالات تحتاج فحص HTML وربطًا مخصصًا. **تقديم الصوت لا يقدّم مشاهد HTML تلقائيًا**،
وربط التشغيل/الإيقاف ليس مزامنة دقيقة للجمل. لا يدّعي البرنامج أنه يبطئ أي كود
JavaScript كيفما كان، ولا يبدّل `Date.now` أو `requestAnimationFrame` أو مؤقتات الصفحة.

للمطورين، ترسل اللوحة حدث `nova-voice:state` على `window` عند تغير الوقت/السرعة/الحالة،
وتتضمن `detail` القيم التالية:

```js
window.addEventListener('nova-voice:state', ({ detail }) => {
  // Feed these values into YOUR existing animation/timeline controller.
  // detail: rate, currentTime, duration, playing, applyToAnimations, linkTransport
});
```

لا يستخدم التطبيق هذا الحدث لتعديل كود صفحتك تلقائيًا؛ هو نقطة ربط اختيارية فقط.

## الملف الأصلي، الملفات المرتبطة والخصوصية

- الملف الأصلي لا يُستبدل، حتى لو اخترته للحفظ بالخطأ أو عبر رابط رمزي.
- يتم الحفظ مؤقتًا ثم الاستبدال عند النجاح فقط؛ الإلغاء أو الخطأ لا يترك نسخة نهائية ناقصة.
- يقرأ التطبيق HTML كنص فقط؛ **لا يشغّل سكريبتاته ولا يجلب ملفاته أثناء التوليد**.
- فتح الصفحة الناتجة في المتصفح قد يشغّل سكريبتات الصفحة الأصلية؛ استخدم ملفات موثوقة.
- يُضمّن الصوت بصيغة base64 داخل HTML، ويزيد حجمه تقريبًا بثلث حجم الصوت الخام.
- لا يُضاف نص السكريبت إلى الصفحة كنص ظاهر أو مخفي؛ يُستخدم فقط لتوليد الصوت.
- الصوت المضمّن **ليس مشفّرًا**. أي شخص يستلم HTML يستطيع الاستماع إليه أو استخراجه.
- تضمين الصوت لا يضمّن تلقائيًا صور الصفحة أو مكتباتها أو خطوطها الخارجية؛ إذا كانت
  الصفحة تعتمد الإنترنت أصلًا فستحتاج تجهيز تلك الملفات للعمل دون اتصال.
- عند نقل HTML، انقل ملفاته النسبية أيضًا إن كانت مطلوبة؛ وضع الصوت نفسه لا يحتاج ملف MP3 مجاورًا.
- لوحة الصوت معزولة في Shadow DOM، فلا يعاد تنسيق محتوى صفحتك أو تغيير اتجاهه.

## الأمان والحدود

- HTML بترميز **UTF-8 أو UTF-16 مع BOM**، حتى **25 ميغابايت** قبل إضافة الصوت.
- الصوت المضمّن حتى **256 ميغابايت**؛ اختر MP3 أو قسّم السكريبت للملفات الأكبر.
- الناتج UTF-8 مع BOM للحفاظ على العربية حتى لو احتوى الأصل تصريح ترميز قديمًا.
- الصفحات ذات **CSP داخل meta** غير مدعومة في الدمج التلقائي الحالي. لا يحذف المصدّر
  سياستها أو يضعفها؛ يلزم دمج مخصص يراعي CSP. لا تلغِ سياسة الأمان لمجرد تجاوز الخطأ.
- عند نشر الناتج على خادم له CSP في ترويسات HTTP، قد يحتاج دمجًا مخصصًا أيضًا؛ لا يمكن
  معرفة ترويسات خادم من ملف محلي.
- إن احتوى HTML مشغّل Nova Voice سابقًا، اختر الأصل لإعادة التصدير، بدل تكديس المشغّلات.
- يُرفض بعض HTML غير المكتمل (مثل script أو textarea غير مغلق) حتى لا تبتلع الصفحة المشغّل.
- لا يوجد تشغيل صوت تلقائي؛ المتصفحات عادة تتطلب ضغطة من المستخدم.

## التحقق

اختبارات Python تتحقق من ملفات WAV/MP3 المضمّنة فعليًا، وترميز العربية، وحماية الأصل،
والحفظ الذرّي والإلغاء، وإدراج اللوحة دون الخلط بين وسم body وسلسلة نصية داخل script.
اختبارات DOM في `web-tests/` تتحقق من الأزرار والسرعة واستعادة سرعات الحركات الأصلية.
jsdom لا يفك ترميز الصوت ولا يرسم الحركات؛ هذه الاختبارات **ليست اختبار استماع أو
عرض في متصفح حقيقي**. راجع دليل المشروع لاختبار Windows وبناء EXE.
