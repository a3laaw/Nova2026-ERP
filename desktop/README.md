# تطبيقات سطح المكتب

## Nova Voice

- **للتنزيل والتشغيل:** [حزمة RAR الحالية وشرح التشغيل](../deliverables/nova-voice/README.md).
- **للتعديل والتطوير:** [مجلد مصدر التطبيق](nova-voice/README.md).

```text
nova-voice/
├── nova_voice/     محرك الصوت وواجهة Windows ومولّد السبورة
├── assets/         القوالب والأنماط والأيقونات
├── examples/       سكريبتات وصفحات للتجربة
├── tests/          اختبارات Python
├── web-tests/      اختبارات لوحة HTML والسبورة للتطوير فقط
├── tools/          تنزيل النماذج وتحزيم المصدر
├── voices/        موضع نماذج المستخدم؛ لا نماذج بشرية مرفقة
├── RUN-FIRST-AR.html  شرح التشغيل
└── *-Windows.bat  ملفات التجهيز والتشغيل والبناء المحلي
```

الحزم الحالية في `deliverables/nova-voice/` من جذر المستودع، والنسخ السابقة
في `deliverables/archive/`. لا تُخلط الحزم بكود التطبيق. مشروع ERP في جذر
المستودع و`src/` مستقل، ولم يُنقل أو يُعدّل هيكله أثناء هذا الترتيب.
